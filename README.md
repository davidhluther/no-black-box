# No Black Box

Free, plainly written kits for small businesses, nonprofits, and in-house marketing teams.

So much of how technology and business works is kept in a black box. Part of that is real complexity. Part of it is that people profit from holding the knowledge and selling it back to you. The internet was supposed to be a web of sharing, and it has turned into a commercial utility, like the power company. You end up buying something that doesn't fit because the seller offers the same thing to everyone, or you hire an expert who applies the same template to every customer.

There is no reason a hair salon or a small food bank should pay someone to answer simple questions about the technology that serves their people. When they can't afford the answers, they help fewer people, and some never learn the tools exist. These kits explain things in simple terms and give you the complete method. Nothing is held back to sell you something.

## Free, low cost, and full

Every kit comes in up to three versions, and you can move between them later without starting over.

- **Free.** Uses only free tools. You paste ready-made prompts into a free AI model such as ChatGPT, Claude, or Gemini, and keep your records in Google Sheets and Google Docs. It accepts less depth in exchange for costing nothing.
- **Low cost.** Adds one AI plan of roughly $20 a month and a small automation inside Google Sheets (Google Apps Script). Claude Pro is $20 a month billed monthly (checked 11/13/2026). See the current price of any other plan on its maker's page.
- **Full.** David's own setup. It runs in Claude Code (a program you type instructions into, which can read and write files on your computer), with scripts, connected tools, and sometimes paid data services. It does the most and takes the most setup.

If your organization is eligible, Google Workspace for Nonprofits is $0 per user per month for its base edition (checked 11/13/2026). Each kit's shopping list says which accounts it needs and links to the [keys and accounts guide](guides/keys-and-accounts.md).

## How to install

Start with the free version and you need no install at all. You only need to download a few files from this page, and the [get the files guide](guides/get-the-files.md) shows how. For the other versions, pick the place you already work.

1. **Claude Code.** In a Claude Code session (see the [glossary](guides/glossary.md) for each term), run `/plugin marketplace add davidhluther/no-black-box`, then `/plugin install <kit>@no-black-box`, for example `/plugin install grants@no-black-box`. Steps are in the [Claude guide](guides/install-claude.md).
2. **Claude.ai.** Download a skill's zip from the [Releases page](https://github.com/davidhluther/no-black-box/releases), then upload it under Customize, Skills. It works on every plan once code execution is on. The [Claude guide](guides/install-claude.md) walks through it.
3. **ChatGPT.** ChatGPT reads the same skill format (a skill is one instruction file that tells an AI model how to do a job), and each kit also has a ready-made Custom GPT (your own saved version of ChatGPT) or Project setup. The [ChatGPT guide](guides/install-chatgpt.md) explains both.

Stuck on a word? The [glossary](guides/glossary.md) defines every term. Stuck on a step? Read [getting help](guides/getting-help.md).
