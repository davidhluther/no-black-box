# Get the Kit Files

Some steps in the free versions ask you to open a file from a [kit](glossary.md#kit) (one of the folders of instructions and tools), such as a spreadsheet template or a page of prompts. This guide shows how to get those files onto your computer. You do this once. It takes about 10 minutes.

Words in this guide are defined in the [glossary](glossary.md). The [step ID](glossary.md#step-id) at the start of each numbered step starts with NB (for "no black box"), then FR for free, then the guide number. If you get stuck, [getting help](getting-help.md) explains the [check-up](glossary.md#check-up) and the [support code](glossary.md#support-code).

The kits live on GitHub (a website where people share project files) at https://github.com/davidhluther/no-black-box. You do not need a GitHub account to download.

## Download everything

1. **NB-FR-07-1.** Open https://github.com/davidhluther/no-black-box in your web browser.
   You'll know it worked when you see a page titled "no-black-box" with a list of folders and a short description below it.
2. **NB-FR-07-2.** Find the green button labelled "Code" near the top right of the file list. Click it, then click "Download ZIP" at the bottom of the small menu that opens.
   You'll know it worked when your browser shows a download starting, usually a small bar or arrow at the top right. If nothing downloads, check whether your browser blocked it and allow the download.
3. **NB-FR-07-3.** Find the downloaded file. It is named no-black-box-main.zip, and it sits in your Downloads folder (the folder your browser saves files into). Where that is depends on your device.
   - Windows: open File Explorer (the yellow folder icon on the taskbar) and click "Downloads" in the list on the left.
   - Mac: click the Finder icon (the blue smiling face in the Dock), then "Downloads" in the list on the left. You can also click the Downloads stack near the right end of the Dock.
   - Chromebook: click the Launcher (the circle at the bottom left), open the Files app, and click "Downloads" in the list on the left.

   You'll know it worked when you see no-black-box-main.zip in the list. If you can't find it, look in your browser's download list (Ctrl+J on Windows and Chromebook, Command+Shift+J on a Mac in Chrome) and click the file name there.
4. **NB-FR-07-4.** Unzip it. A [ZIP file](glossary.md#zip-file) is one file that holds many files packed together, like a box with a lid. Opening the box is called unzipping.
   - Windows: right-click no-black-box-main.zip, choose "Extract All", then click "Extract".
   - Mac: double-click no-black-box-main.zip.
   - Chromebook: double-click no-black-box-main.zip. It opens as a drive in the left list. Click it, select everything inside, right-click, choose "Copy", then go to "Downloads", right-click an empty spot, and choose "Paste".

   You'll know it worked when a normal folder appears beside the ZIP file. If a Windows window shows the files but no "Extract All" button, you are looking inside the ZIP without unzipping it, so close it and use the right-click route.
5. **NB-FR-07-5.** Open the new folder. It is named "no-black-box-main". (GitHub adds "-main" to the name. It is the same kit, not a different one.)
   You'll know it worked when you see folders named kits, guides and support, plus a few files.
6. **NB-FR-07-6.** Find the free files for your kit. Open "kits", then the kit's folder (for example "grants", "board-packet", "books" or "plain-writing"), then "free". The path looks like this: no-black-box-main, kits, grants, free.
   You'll know it worked when you see the kit's free files, such as prompts.md or a set of files ending in .csv. Each guide that needs a file tells you its exact name.

## Grab one file instead

If a guide asks for only one file, you can skip the big download.

1. **NB-FR-07-7.** On the GitHub page, click "kits", then your kit's folder, then "free", and click the name of the file you want.
   You'll know it worked when you see the file's contents on the page.
2. **NB-FR-07-8.** Look at the small row of icons at the top right of the file's contents. Click the one with a downward arrow. Its label ("Download raw file") appears when you rest your pointer on it.
   You'll know it worked when the file lands in your Downloads folder, with the same name it has on GitHub. If the file opens as plain text in your browser instead, press Ctrl+S (Command+S on a Mac) and save it from there, keeping the name and the ending (such as .csv) unchanged.

## Where next

Go back to the guide you came from. If you are stuck, see [getting help](getting-help.md).

> **How to get help.** Write down the step ID where you got stuck (it looks like NB-FR-07-4). If your kit has a check-up button or command, run it and copy the support code it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
