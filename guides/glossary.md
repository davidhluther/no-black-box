# Glossary

Plain meanings for the terms used in the guides and kits. Each kit also has its own glossary for words only it uses.

**AI model.** A program trained on large amounts of text that writes answers to what you type. ChatGPT, Claude, and Gemini are products built on AI models.
**API.** A way for two programs to talk, like a waiter carrying orders between you and the kitchen.
**API key.** A long password that lets a program use a service for you, like a hotel key card.
**Apps Script.** Google's built-in way to add small automations to a Google Sheet or Doc.
**Check-up.** A button in a Google Sheet or a command that tests your setup and prints one support code.
**Claude Code.** Anthropic's program for working with files on your computer by typing instructions.
**Clipboard.** The place your computer holds what you last copied.
**Code execution.** A feature that lets Claude run small programs to make files for you.
**Command line.** A way to control your computer by typing instructions instead of clicking.
**Custom GPT.** Your own saved version of ChatGPT with fixed instructions.
**.env file.** A plain text file that holds your keys, one line each, in the form NAME=value.
**Encrypt.** Scramble information so only the right reader can open it.
**Environment variable.** A named setting your computer keeps for programs to read, such as a key.
**Firmware.** The built-in software of a device such as a router.
**Guest network.** A second Wi-Fi name for visitors, kept apart from your work devices.
**Kit.** A folder of instructions and tools for one job, such as the Grants kit.
**Knowledge file.** A document an AI model reads before it answers, so it can use your material.
**Marketplace.** A catalog that Claude Code can install add-ons from, like an app store for one publisher.
**Plugin.** A bundle of skills that Claude Code installs in one step. Each kit is one plugin.
**Project.** A folder in ChatGPT or Claude that keeps instructions and files together for one job.
**Prompt.** The words you type to an AI model to tell it what you want.
**Python.** A programming language. Some kit scripts need it installed.
**Rotate a key.** Make a new key and delete the old one.
**Router.** The box that connects your devices to the internet, like a switchboard operator routing calls.
**Skill.** One instruction file, named SKILL.md, that tells an AI model how to do a job. It loads only when your request fits.
**Step ID.** The code at the start of each numbered step, such as GR-FR-01-3 (kit, version, guide, step).
**Support code.** One short code the check-up prints so a helper knows which step failed and why.
**Terminal.** The window where you type commands.
**Token.** A key that allows only certain actions, such as adding posts.
**VPN.** A protected tunnel between your device and another network, like an armored car between your door and the bank.
**Whisper.** A speech-to-text program that runs on your own computer.
**Zip file.** One file that holds several files packed together.
