# Glossary

Every technical term used in this kit, in plain words.

**AI model.** <a id="ai-model"></a>A program such as ChatGPT, Claude, Gemini, or Perplexity that answers questions in ordinary sentences.

**API.** <a id="api"></a>A way for one program to ask another for something, like a waiter carrying orders between you and the kitchen. AI companies offer one so your own script can ask their model a question.

**API key.** <a id="api-key"></a>A long secret password that tells an AI company's service which account to bill. Treat it like a bank card number.

**Apps Script.** <a id="apps-script"></a>A built-in Google tool that lets a spreadsheet run small programs you paste in.

**Baseline.** <a id="baseline"></a>Your first run. It has nothing to compare with yet, so it makes no claim about trends.

**Brand check.** <a id="brand-check"></a>The questions in group BV that are allowed to name your business. They test whether an AI model can find and describe you once handed the name. They stay out of the headline counts.

**Channel group.** <a id="channel-group"></a>Your own rule in GA4 for sorting visits into labeled buckets, such as "AI models".

**Check-up.** <a id="check-up"></a>The Help, Run check-up button in your sheet. It tests the sheet's setup and prints a support code.

**Citation.** <a id="citation"></a>A web address an AI answer lists as a source. Being cited means your website is one of them.

**Claude Code.** <a id="claude-code"></a>A program from Anthropic that runs on your computer and carries out multi-step tasks with your files.

**Command line.** <a id="command-line"></a>A window where you type instructions to your computer instead of clicking. The free and low-cost versions never need it.

**Control question.** <a id="control-question"></a>A question with no town in it (group CT), used to see what a model says when it cannot know where you are.

**Crawler.** <a id="crawler"></a>A program that visits web pages automatically to read them. AI products use crawlers to find pages.

**Crowded out.** <a id="crowded-out"></a>The answer names or cites other businesses or software and not you.

**CSV.** <a id="csv"></a>A plain file of spreadsheet rows separated by commas. Google Sheets can open and save them.

**Custom GPT.** <a id="custom-gpt"></a>A saved version of ChatGPT with your own instructions and files.

**Dry run.** <a id="dry-run"></a>A practice run that checks everything and sends nothing, so it spends nothing.

**Environment variable.** <a id="environment-variable"></a>A setting stored on your computer outside any file, such as a key. Programs can read it, but it does not travel with your documents.

**Frozen.** <a id="frozen"></a>A question set you have started using and will not edit. This keeps months comparable.

**GA4.** <a id="ga4"></a>Google Analytics 4, Google's free tool that counts visits to your website.

**llms.txt.** <a id="llms-txt"></a>A proposed plain-text file at the top of a website that summarizes it for AI products. No major product has confirmed that it reads it.

**Noise audit.** <a id="noise-audit"></a>A cleaning pass on a run that removes same-name look-alikes and checks how much answers vary, before you quote any number.

**Preflight.** <a id="preflight"></a>The check you do before your first run, to list names that collide with yours and review the questions for mistakes.

**Project.** <a id="project"></a>A saved workspace in ChatGPT or Claude that keeps your instructions and files for every chat inside it.

**Python.** <a id="python"></a>A common programming language. The full version's scripts are written in it.

**Question set.** <a id="question-set"></a>The 28 fixed questions you ask every month.

**Referrer.** <a id="referrer"></a>The website a visitor came from, as reported to your analytics.

**Regex.** <a id="regex"></a>A small text pattern that matches many names at once, such as every AI product's address.

**robots.txt.** <a id="robots-txt"></a>A file on your website that tells crawlers which pages they may read.

**Same-name.** <a id="same-name"></a>A different business, person, place, or everyday word that shares your name. It is never counted as you.

**Search Console.** <a id="search-console"></a>Google's free tool that shows which searches led people to your website.

**Script.** <a id="script"></a>A short program, usually saved as a text file, that does a task for you.

**Support code.** <a id="support-code"></a>The short code the check-up prints, such as AV-FR-03-2-E06-v0.1.0-7KQ, that tells a helper where you are stuck.

**Step ID.** <a id="step-id"></a>The printed label at the start of each guide step, such as AV-FR-03-2.

**Terminal.** <a id="terminal"></a>A window where you type instructions to your computer instead of clicking. On a Mac it is an app called Terminal.

**VPN.** <a id="vpn"></a>A service that hides where your internet connection comes from. Turn it off when you collect answers.

**Web search.** <a id="web-search"></a>The feature that lets an AI model look things up on the web while it answers.
