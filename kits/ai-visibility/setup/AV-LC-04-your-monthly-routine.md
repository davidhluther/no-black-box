# AV-LC-04: Your Monthly Routine

Time, about one hour. This guide is the loop. It does not add new setup.

1. **AV-LC-04-1.** Confirm the [question set](../glossary.md#question-set) version on the Config tab has not changed. If it has, start a new series and do not compare with older months.
   You'll know it worked when the version matches the last row of your Runs tab.

2. **AV-LC-04-2.** Ask the 28 questions in fresh chats in each of the four products, outside your [Project](../glossary.md#project), following guide AV-FR-04. Use the Log an answer menu after each one.
   You'll know it worked when each answer produces a row on Results and a copy on the Answers tab.

3. **AV-LC-04-3.** Run Kit help, Run [check-up](../glossary.md#check-up). Fix anything it shows.
   You'll know it worked when the code shows E00.

4. **AV-LC-04-4.** Run the noise check with the Project (guide AV-LC-03). Then type this run's label in cell B1 of the Summary tab.
   You'll know it worked when your clean counts match what the Project said, or you know why not.

5. **AV-LC-04-5.** Compare with last month only if the version and method match. Ask the Project: "Compare these two runs. First list anything that differs in conditions: model names, signed in or out, question set version, and place. Only then give changes, cell by cell."
   You'll know it worked when it lists differences first. If it skips that, ask again.

6. **AV-LC-04-6.** Note the [GA4](../glossary.md#ga4) [AI models](../glossary.md#ai-model) count, from guide AV-FR-07.
   You'll know it worked when you have this month's number, even if it is zero.

7. **AV-LC-04-7.** Missed the month? Write "missed, and why" in your notes, and run it as soon as you can. Do not paper over a gap by filling the old month in later.
   You'll know it worked when the note exists.

> **How to get help.** Write down the [step ID](../glossary.md#step-id) where you got stuck (it looks like AV-LC-04-3). If your kit has a check-up button or command, run it and copy the [support code](../glossary.md#support-code) it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
