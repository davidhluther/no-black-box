# AV-FR-04: Run the Questions

Time, about two hours the first month. You will ask all 28 questions in each of four free AI products, and save every answer unedited. Do it in one sitting. Models change, and a run spread over a week can span a quiet update.

Before you start, read these rules once. They are what make a run valid.

- One fresh chat for every question. One question per chat, and no follow-ups.
- Paste the question exactly as written, with its lowercase letters and missing apostrophes.
- Stay signed out where the product lets you. Where you need an account, use a browser profile with no history and with memory and custom instructions turned off. You want to see what a stranger sees.
- Use your normal internet connection from your real location. Do not use a [VPN](../glossary.md#vpn).
- Never argue with the model, never ask "are you sure", and never name your business in a chat that is not a brand-check question.

1. **AV-FR-04-1.** Make the answer document. In Google Docs, create a new document named "AI visibility answers" followed by the month. Copy the text of `free/answer-log-template.md` into it. Fill in the run header at the top, and write down the date and the model name each app shows.
   You'll know it worked when the header has a date, a location, and a line for each product. If you cannot find a model name in an app, write "not shown", not a guess.

2. **AV-FR-04-2.** Add rows to the Runs tab, one per AI product. In column A write a run label such as `2026-11`, and in column D the version from the Config tab. Fill in the rest from your header.
   You'll know it worked when the Runs tab has four rows, all with the same version. If you see the [check-up](../glossary.md#check-up) report E09 later, a row has a different version.

3. **AV-FR-04-3.** Open your first product in a private or incognito window (a window that does not keep your history). Paste question LD-01 from column E of the Questions tab. Wait until the answer stops moving. Copy all of it, with any sources it lists, and paste it under the heading LD-01 in your answer document.
   You'll know it worked when the answer is in your document unedited and complete. If the product asks you to sign in or shows a "prove you are human" check, it's E15. If it refuses to answer, write `refused` in your notes and go on. That is E16.

4. **AV-FR-04-4.** Close that chat. Open a new one. Paste LD-02. Repeat until all 28 are done in that product. Keep the pace human, a minute or two per question. Do not use a program to paste for you.
   You'll know it worked when your answer document has 28 sections for that product. If an answer is clearly about the wrong town, it's E17. Do not retry the question, since a retry is a different measurement. Log it as it came.

5. **AV-FR-04-5.** Repeat steps 3 and 4 in the other three products. Do one product fully before the next. If you run short of time, drop the control questions (group CT) first, and write down what you skipped and why in the run header.
   You'll know it worked when all four products have their sections filled in, or a clear note on why a section is short.

6. **AV-FR-04-6.** Optional but recommended. Do the repeat test from Part 5 of `free/prompts.md`. Ask three questions three more times each in one product, in fresh chats, and note each time whether you were named.
   You'll know it worked when you know how often an answer repeats itself. If you are named in one of four tries, treat one "named" as weak evidence.
