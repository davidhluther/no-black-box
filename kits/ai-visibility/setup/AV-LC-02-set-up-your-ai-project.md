# AV-LC-02: Set Up Your AI Project

Time, about 25 minutes. A paid AI plan lets you keep a [Project](../glossary.md#project), a saved workspace where the instructions and files stay in place for every chat. You will make one that knows this kit's rules, so it can help you code answers, clean a run, and read results. It does not run the questions. You still ask those yourself, in fresh chats outside the Project, so the project's instructions do not shape the answers.

1. **AV-LC-02-1.** Choose one plan (ChatGPT, Claude, or Gemini) and sign in. See [Keys and accounts](../../../guides/keys-and-accounts.md) for what each one involves. Look at the vendor's own pricing page before you buy.
   You'll know it worked when you can see a Projects option (ChatGPT and Claude) or a Gem (Gemini's name for saved instructions). If you cannot find it, the plan may not include it, so check the plan page.

2. **AV-LC-02-2.** Create a new Project named "AI visibility coach". Open `chatgpt/instructions.md` from the kit, copy everything below the line, and paste it into the Project's instructions box.
   You'll know it worked when the instructions are saved and a new chat in the Project starts with them. If the box says the text is too long, it's E26.

3. **AV-LC-02-3.** Upload the knowledge files listed in `chatgpt/knowledge-files.md`. Do not upload your own results or answers.
   You'll know it worked when the file list shows eleven files. If an upload fails, upload fewer and check the list.

4. **AV-LC-02-4.** Test it. In a new chat inside the Project, type: "What counts as a [same-name](../glossary.md#same-name) answer, and why does it never count as named?"
   You'll know it worked when it answers in plain words and mentions look-alike businesses, not as you. If it gives a long general lecture about SEO, the instructions did not load. Recheck step 2.

5. **AV-LC-02-5.** Use it for coding. Paste one answer, with its question code and product, and ask for a Results row. Compare with what the logging menu guessed. Disagreements are where you read the answer yourself.
   You'll know it worked when its row quotes lines from the answer. If it does not quote, tell it to.
