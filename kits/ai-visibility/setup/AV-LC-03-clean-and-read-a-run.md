# AV-LC-03: Clean and Read a Run

Time, about 40 minutes a month. This is the noise check from the free version with your [Project](../glossary.md#project) doing the first pass. You still make every decision.

1. **AV-LC-03-1.** Export the Results tab. In the sheet, click the Results tab, then File, Download, Comma-separated values. Open the file and look at it. It holds only coded values and the websites and business names you typed, not the answers.
   You'll know it worked when the file opens as a table. Do not upload your answer document unless you are comfortable with that. The Project does not need it for this step.

2. **AV-LC-03-2.** In the Project, paste the Results export and say: "Run a [noise audit](../glossary.md#noise-audit) on this run. Here is my SameNames tab." Paste the SameNames rows after it. Ask it to give raw and clean counts per product, and to list every `y` that might be a look-alike.
   You'll know it worked when you get a table of raw and clean counts and a list of cells to check. If it gives a count without listing the cells behind it, ask again for the list.

3. **AV-LC-03-3.** Check each flagged cell yourself against the saved answer on the Answers tab. Change the row on the Results tab where you disagree. Keep a line of what you changed and why.
   You'll know it worked when the Project's list and your own readings agree, or you know where they differ.

4. **AV-LC-03-4.** Ask for a read of the run. Paste the final Results export and ask: "Summarize this run in counts, say who won the answers I was not in, and list the most cited sites. Separate what you can see from what you are guessing."
   You'll know it worked when it reports counts with how many cells they cover, and flags guesses. If it gives percentages of tiny numbers, ask it to use counts.

5. **AV-LC-03-5.** Ask for a hypothesis, never a promise. For example: "Give me three things I could try before next month, each with how I would know whether it worked."
   You'll know it worked when each suggestion has a test you can run on the same [question set](../glossary.md#question-set) next month. If one promises a result, discard it.
