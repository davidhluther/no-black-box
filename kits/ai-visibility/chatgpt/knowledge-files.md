# Knowledge files to upload

Upload these kit files as knowledge for your [Custom GPT](../glossary.md#custom-gpt) or [Project](../glossary.md#project). OpenAI states a limit of 20 knowledge files for a Custom GPT (confirm in the GPT builder). This list uses eleven.

| File | Why it helps |
|---|---|
| free/prompts.md | The 28 question templates, the [same-name](../glossary.md#same-name) probes, and the answer coding prompt |
| free/Questions.csv | The template with its column layout |
| free/Results.csv | The exact columns and allowed values for coding an answer |
| free/SameNames.csv | How to record names that collide with yours |
| free/ga4-ai-traffic-channel.md | The [GA4](../glossary.md#ga4) recipe |
| free/monthly-checklist.md | The monthly routine |
| glossary.md | Plain definitions of every term |
| fixes.md | Problem codes with plain causes and fixes |
| start-here.md | What the kit is for |
| choose-your-version.md | Free, low cost, and full compared |
| config.example.json | Which details belong in the one settings file |

Do not upload your own results, answers, or any file with your customers' names. The coach works from what you paste in the chat.
