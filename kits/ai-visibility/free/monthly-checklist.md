# Monthly checklist (free version)

Same day each month, about two hours the first time and less after. Tick each line.

- [ ] Open the Config tab. The [question set](../glossary.md#question-set) version is the same as last month. If it is not, stop. Do not compare this run with last month's.
- [ ] Add one row per AI product to the Runs tab (date, model name shown in each app, signed in or out, location note).
- [ ] Fresh chat for every question, all 28, in each of the four products. Paste each answer under its code in the answer document.
- [ ] Add one Results row per question and product. Use answer_status values not_run, refused, or failed when you could not collect an answer. Never leave a gap that reads as "not named".
- [ ] Check [same-name](../glossary.md#same-name) answers. Anything about a different business with your name gets `same-name`.
- [ ] Run Kit help, Run [check-up](../glossary.md#check-up). Fix anything it reports, then copy the [support code](../glossary.md#support-code) into your notes.
- [ ] On the Summary tab, type this run's label in cell B1. Read the counts.
- [ ] Compare with last month only if the question set version and the collection method match.
- [ ] Write three sentences about what changed and one about what could explain it. Mark the explanation as a guess.
- [ ] In [GA4](../glossary.md#ga4), note the [AI models](../glossary.md#ai-model) channel count for the month.
- [ ] Missed a month? Write down that you missed it and why. A gap you can see is better than a gap you forgot.
