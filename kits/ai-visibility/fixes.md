# Fixes

Find the code the [check-up](glossary.md#check-up) printed (or the one a step pointed to), read the row, and try the fix. If it does not work, send the [step ID](glossary.md#step-id) and the [support code](glossary.md#support-code) to Pigasus Group at https://pigasus.group/contact. Setup questions are free.

Codes E01 to E11 come from the check-up button in the sheet. Codes E12 to E26 cover the free and low-cost versions. Codes E30 to E39 cover the full version.

| Code | What you see | Why | The fix | Step |
|---|---|---|---|---|
| E01 | The check-up says a tab is missing or named differently | A tab name has a different spelling, a space, or the wrong capital letter | Rename the tab to exactly Config, Questions, Runs, Results, SameNames, or Summary | AV-FR-01-3 |
| E02 | The check-up says a tab's column headings do not match | A heading was edited, a column deleted, or the wrong file imported | Re-import the matching [CSV](glossary.md#csv) from the `free/` folder into a new tab, move your rows across, and delete the old tab | AV-FR-01-3 |
| E03 | The check-up says a setup cell is empty or still shows the example | One or more Config cells were not filled in | Fill every cell in column B of the Config tab with your own details | AV-FR-03-1 |
| E04 | A question shows curly brackets, `#NAME?`, `#REF!`, or `#VALUE!` | The formula in column E cannot find a Config value, or the Config tab was renamed or reordered | Check the Config tab is named Config and its rows are in the original order. Copy the formula from row 2 of the CSV into the broken cell | AV-FR-03-2 |
| E05 | The check-up says there are not 28 questions, or two share a code | A row was deleted or duplicated | Re-import `Questions.csv` into a fresh tab and copy your template edits across, or restore the missing row | AV-FR-03-2 |
| E06 | The check-up says a question that should not name you does name you | Your business or owner name appears in a non-brand question | Edit the placeholder text in column D so it does not contain the name. Only brand-check (BV) rows may | AV-FR-03-3 |
| E07 | The check-up says the [question set](glossary.md#question-set) is not [frozen](glossary.md#frozen) | No version or no freeze date on the Config tab | Type the version and the date in the two Config cells. Do it only after your final read of the questions | AV-FR-03-4 |
| E08 | The check-up says some results have codes not on the Questions tab | A typo in a question code, or a deleted question | Correct the code to match column A of the Questions tab, for example LD-01 | AV-FR-05-2 |
| E09 | The check-up says runs or results mix question set versions | A question was edited and the version changed, or old rows use another version | Do not compare those runs. Start a new series for the new version, and keep old runs as they are | AV-FR-06-3 |
| E10 | The check-up says a coded column holds a value the kit does not use | A typo such as `yes` instead of `y`, or a position that is not 1, 2, 3+, list, aside, or - | Use only the allowed values in guide AV-FR-05, step 2 | AV-FR-05-2 |
| E11 | The check-up says the SameNames tab is empty or has only the examples | The name check was skipped | Do guide AV-FR-02. Write "none found" in column A if you truly found nothing | AV-FR-02-3 |
| E12 | No Help menu after pasting the [script](glossary.md#script), or the editor will not save | The page was not reloaded, the paste is incomplete, or the code has a stray character | Reload the sheet and wait ten seconds. In the [Apps Script](glossary.md#apps-script) editor, delete everything, paste the whole file again, and save | AV-FR-01-4 |
| E13 | Google keeps asking for permission, or says the app is not verified | Google warns about every script you write yourself | Click Advanced, then "Go to ([project](glossary.md#project) name) (unsafe)", then Allow. The script only asks for this spreadsheet | AV-FR-01-5 |
| E14 | An import shows all data in one column, a greyed-out file, or formulas shown as text | The wrong separator, a file that was not uploaded, or "Convert text to numbers, dates, and formulas" was unticked | Import again with Convert ticked. If a formula still shows as text, click the cell and press Enter | AV-FR-01-2 |
| E15 | An AI product asks you to sign in, shows a "prove you are human" check, or will not start a chat | The product limits free or anonymous use, or sees unusual traffic | Sign in with a clean account if needed, finish the check yourself, slow down, and try later. Never use a program to get around it | AV-FR-04-3 |
| E16 | The AI product will not answer a question | A safety rule or an error | Write `refused` as the answer status and move on. Never rephrase the question | AV-FR-04-3 |
| E17 | The answer is about a different town | The product guessed your location from your connection | Check you are not on a [VPN](glossary.md#vpn), and note it in the run header. Log the answer as it came and add a note | AV-FR-04-4 |
| E18 | You cannot tell whether an answer means you or a look-alike | The answer lacks your town or website | Use `same-name` and add a note. If you are unsure, use `y` and write "check [same-name](glossary.md#same-name)" in the notes | AV-FR-05-3 |
| E19 | [GA4](glossary.md#ga4) has no Create new [channel group](glossary.md#channel-group) button, or the pattern is rejected | You lack editor access, or part of the pattern was left out | Ask the property's owner for the Editor role. Copy the whole pattern again | AV-FR-07-2 |
| E20 | The [AI models](glossary.md#ai-model) channel shows zero | No visits have arrived under those names, or sources were stripped | Look at Session source for the words chatgpt or perplexity. Zero can be true. Visits with stripped sources land in Direct | AV-FR-07-5 |
| E21 | The Summary tab shows errors or zeros, or the outcome column stays empty | The run label in B1 does not match column A of Results, a product name is spelled differently, or a formula was overwritten | Type the label exactly as it appears in Results column A. Spell products ChatGPT, Claude, Gemini, Perplexity. Copy the formula from the first row of the CSV into the cell | AV-FR-06-1 |
| E22 | The AI visibility menu does not appear | The second file was not saved, or the check-up file was replaced and no longer calls it | Make sure both files are in the Apps Script project and saved. Reload the sheet | AV-LC-01-3 |
| E23 | The form says "Problem:" when you click Log it | The question code is not on the Questions tab, the set is not frozen, or Config is missing a value | Read the message. Fix the code or the Config cell it names, then log again | AV-LC-01-5 |
| E24 | You go round and round at the Google sign-in | Several Google accounts are signed in at once | Use a private window with only one account signed in | AV-FR-01-1 |
| E25 | The logging form takes a long answer but the Results row is empty | The answer is longer than a spreadsheet cell can hold | Paste the first part only and note "cut" in the notes. The Answers tab keeps what fits | AV-LC-01-5 |
| E26 | The Project says the instructions are too long | The paste included extra text above the line | Paste only the text below the line in `chatgpt/instructions.md`. It is under 8,000 characters | AV-LC-02-2 |
| E30 | The [terminal](glossary.md#terminal) says "command not found" for claude or python3 | The program is not installed, or the terminal was open during install | Close the terminal, open a new one, and try again. Then follow the install guide again | AV-FU-01-1 |
| E31 | [Claude Code](glossary.md#claude-code) cannot find the kit or its marketplace | The repository address is wrong, or you are offline | Copy the address from the kit's GitHub page again, with no spaces. Check your internet | AV-FU-01-3 |
| E32 | A key appears in a file, a chat, or a screenshot | It was pasted somewhere shared | Delete that key in the company's account and make a new one. Never reuse a key that showed up in a file | AV-FU-02-4 |
| E33 | A script says "invalid JSON" or lists problems in your settings | A quotation mark or comma went missing in `config.json`, or a question names you | Compare your file with `config.example.json` line by line. Fix the line the message names | AV-FU-03-3 |
| E34 | The [dry run](glossary.md#dry-run) says "key: MISSING" | The key was set in a terminal window you have since closed | Set the key again with the `read -s` line, in the same terminal window you run the script from | AV-FU-04-3 |
| E35 | A run says the model was not found | The model name in `config.json` is out of date | Open the company's models page and copy a current name into `api_models` | AV-FU-04-4 |
| E36 | The dry run says it found no questions | `questions.md` is missing or its layout changed | Run `fill_questions.py` again. Each question needs a heading with its code and one fenced block below it | AV-FU-04-3 |
| E37 | Every question shows ERROR with 401, 403, or empty answers | A wrong key, a key without permission, or [web search](glossary.md#web-search) not allowed on that account | Check the key and the account's settings for web search. Make a new key if in doubt | AV-FU-05-1 |
| E38 | Errors with 429 or "quota" | Rate limit reached, or no credit left | Wait and rerun only the missing company, or add credit within your spending cap | AV-FU-05-1 |
| E39 | The diff says "Not comparable" | The two runs used different question set versions or methods | Do not override it. Compare the right pair, or start a new series | AV-FU-06-3 |

## When the fix is not in this table

Write down the step ID and the support code from the check-up. A person can usually read the code and tell you where you are stuck. Send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free. If you used a Project or [Custom GPT](glossary.md#custom-gpt) from this kit, it can also take the code and tell you what to try.
