# Glossary

Every technical term used in this kit, in plain words. Terms are listed alphabetically.

**AI model.** A computer program trained on huge amounts of text so it can write and answer questions, like a very well-read assistant who has never met your customers. ChatGPT, Claude, and Gemini are products built on AI models. <a id="ai-model"></a>
**API.** A way for two programs to talk, like a waiter carrying orders between you and the kitchen. <a id="api"></a>
**API key.** A password a program uses to prove it is allowed to use an API. This kit never asks for one. <a id="api-key"></a>
**Apps Script.** A tool built into Google Sheets that lets you attach small programs to a spreadsheet, like adding a custom button to a calculator. <a id="apps-script"></a>
**Autocomplete.** The suggestions a search box offers as you type, such as "food pantry hours near" finishing as "food pantry hours near me". They are a window into what many people type. <a id="autocomplete"></a>
**Check-up.** A menu item in your Sheet that tests whether the tabs and headings are set up correctly and gives you a short support code. <a id="check-up"></a>
**Coding.** Tagging each quote with a short label for what it is about, the way you might sort mail into piles. <a id="coding"></a>
**Config.** Short for configuration, the page of settings that holds your organization's details in one place. <a id="config"></a>
**CSV.** A plain file that holds a table, one row per line, which Google Sheets can import as a new tab. <a id="csv"></a>
**Custom GPT.** A version of ChatGPT you set up with your own instructions and files so it behaves the same way each time. <a id="custom-gpt"></a>
**Header row.** The first row of a tab, which names each column. <a id="header-row"></a>
**Knowledge file.** A document you attach to a Custom GPT or Project so the AI model can consult it. <a id="knowledge-file"></a>
**People Also Ask.** The box of related questions Google shows in some search results. <a id="people-also-ask"></a>
**Persona.** A short description of one kind of customer, built from real quotes, used to give the simulated panel a point of view. <a id="persona"></a>
**Pre-screen.** A quick first filter that narrows many options to a few, before the real test. <a id="pre-screen"></a>
**Project.** A saved workspace inside ChatGPT or Claude that keeps your instructions and files, so you do not paste them each time. <a id="project"></a>
**Prompt.** The message you type or paste to an AI model. <a id="prompt"></a>
**Reddit.** A website of public discussion boards where people describe problems and ask each other for advice. <a id="reddit"></a>
**Sample size.** How many quotes or people a finding rests on. Five quotes is a hint, and fifty is a pattern. <a id="sample-size"></a>
**Sentiment.** Whether a comment is positive, negative, mixed, or neutral. <a id="sentiment"></a>
**Share of voice.** The portion of all mentions in a space that belong to one name, such as yours against nearby competitors. <a id="share-of-voice"></a>
**Simulated respondent.** An AI model asked to answer as if it were a customer. The official term is "synthetic respondent". It is a guess about a customer, never a customer. <a id="synthetic-respondent"></a>
**Skill.** A saved folder of instructions that an AI model can load for one kind of job, the way a recipe card tells a cook what to do. <a id="skill"></a>
**Subreddit.** One discussion board on Reddit, such as one for a city or a hobby. <a id="subreddit"></a>
**Support code.** A short code the check-up prints so whoever helps you can see which step failed. <a id="support-code"></a>
**Tab.** One page inside a Google Sheet, shown along the bottom edge. <a id="tab"></a>
**Theme.** A group of quotes that are about the same thing. <a id="theme"></a>
**Trigger.** A setting that runs an Apps Script automatically on a schedule, such as the first of each month. <a id="trigger"></a>
**Validity.** How far you can trust that a method measures what it claims to. A simulated panel has low validity for predicting real behavior. <a id="validity"></a>
**Verbatim.** The customer's exact words, unedited. <a id="verbatim"></a>
