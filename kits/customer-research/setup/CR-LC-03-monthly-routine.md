# CR-LC-03: Monthly Routine

You will schedule the suggestion pull and set up a 30-minute monthly habit. Time: 15 minutes now, then 30 minutes a month.

1. **CR-LC-03-1.** Fill in the notify_email row of the [Config](../glossary.md#config) [tab](../glossary.md#tab) with the address that should hear about a failed pull. In the Sheet, choose Customer research, then "Schedule monthly pull", and allow the permissions.
   You'll know it worked when an alert says the pull is scheduled for the first of each month. If no menu appears, it's E11.

2. **CR-LC-03-2.** On the second of each month, open the RunLog tab and look at the newest row. Status ok means it ran. If there is no row for the month, or the status says FAILED, run "Pull search suggestions now" by hand and read the message.
   You'll know it worked when the log has one row for this month. A month with no row means the [trigger](../glossary.md#trigger) (a setting that runs a script on a schedule) did not run, which is E18. A missed month should never go unnoticed, so make the check part of the routine.

3. **CR-LC-03-3.** Do the 30-minute monthly pass. Read the new suggestions and add useful rows to the Quotes tab. Paste five to ten fresh quotes from your sources into [prompt](../glossary.md#prompt) P1. Add anything new to the [Themes](../glossary.md#theme) tab. Write one line about what changed.
   You'll know it worked when the Themes tab shows a date and one line of change for this month. If nothing changed, write that, because "nothing changed" is a result.

4. **CR-LC-03-4.** Each quarter, rebuild one [persona](../glossary.md#persona) card from the newest quotes and compare it to the old one.
   You'll know it worked when each card carries its date. A card older than six months is a guess about last year's customers.

> **How to get help.** Write down the step ID where you got stuck (it looks like CR-FR-01-3). If your kit has a [check-up](../glossary.md#check-up) button or command, run it and copy the [support code](../glossary.md#support-code) it prints.
