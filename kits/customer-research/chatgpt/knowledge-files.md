# Knowledge Files to Upload

A [knowledge file](../glossary.md#knowledge-file) is a document you attach to a [Custom GPT](../glossary.md#custom-gpt) or [Project](../glossary.md#project) so the [AI model](../glossary.md#ai-model) can consult it. Upload these from the kit. ChatGPT accepts up to 20 files for a Custom GPT.

| File | Why upload it |
|---|---|
| `free/prompts.md` | Holds the nine tested [prompts](../glossary.md#prompt) the instructions refer to. |
| `glossary.md` | Lets the AI model define terms in the kit's own words. |
| `fixes.md` | Lets the AI model help you diagnose a problem by its code. |
| `setup/CR-FR-03-find-themes.md` | The method for [themes](../glossary.md#theme), in steps. |
| `setup/CR-FR-04-test-your-wording.md` | The method and the limits for the simulated panel. |

Also upload two files of your own, once you have them: your [persona](../glossary.md#persona) cards as a Google Doc downloaded as .docx or .txt, and the Quotes [tab](../glossary.md#tab) downloaded as a [CSV](../glossary.md#csv). Replace them each research round. Never upload customer names, phone numbers, or email addresses.

## If you use the skills instead

Claude Code and Claude.ai can load the [skills](../glossary.md#skill) in `overrides/` once the kit is exported, and then the instructions text is optional. The prompts file still works.
