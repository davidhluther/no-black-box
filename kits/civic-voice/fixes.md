# Fixes

Find the code you were given (or the words closest to what you see) and follow the fix. Codes are the same in the [check-up](glossary.md#check-up), the guides, and the [support code](glossary.md#support-code). If a fix does not work, send the [step ID](glossary.md#step-id) and the support code to Pigasus Group at [pigasus.group/contact](https://pigasus.group/contact). Setup questions are free.

## Reading a support code

A support code looks like CV-FR-01-2-E01-v0.1.0-BBZ. Read it in pieces. CV is this kit. FR-01 is the free version, guide 1. The next number (2) is the step where the first problem was found. E01 is the problem. v0.1.0 is the kit version, and the last three characters are a check value, so a mistyped code is easy to spot.
