# CV-LC-01: Save the Kit in a Project

Low-cost version, guide 1. With one paid [AI model](../glossary.md#ai-model) plan, you can save the kit's instructions and files once, so you stop pasting the same rules. Pick one tool: a ChatGPT [Custom GPT](../glossary.md#custom-gpt) or ChatGPT Project, or a Claude Project. See the [shopping list](../shopping-list.md) for plan prices. Allow 30 minutes. You should have finished the free guides CV-FR-01 and one of CV-FR-02 to CV-FR-05 first, so you know what good output looks like.

1. **CV-LC-01-1.** Open your chosen tool and create a new Project (or a Custom GPT). Name it "Civic voice." Menu names change, so look for "Projects" in the side menu, or "Explore GPTs" then "Create" for a Custom GPT.
   You'll know it worked when you see an empty project with a place for instructions.

2. **CV-LC-01-2.** Open `chatgpt/instructions.md` in the kit. Copy everything below the line. Paste it into the instructions box. A Custom GPT limits the box to 8,000 characters, and this text fits.
   You'll know it worked when the box accepts the whole text. If it says the text is too long, it's E21, and the fix is to delete the sentences about jobs you do not use.

3. **CV-LC-01-3.** Open `chatgpt/knowledge-files.md`. Upload the files it lists into the project's files or the GPT's knowledge section.
   You'll know it worked when the file list shows all nine. If a file is rejected, it's E21.

4. **CV-LC-01-4.** Test with invented material. Start a chat in the project and type: "I'm a resident who wants to speak for three minutes about a sidewalk repair on item 5 of a planning board meeting. Walk me through the steps." Do not use real packets for this test.
   You'll know it worked when the reply starts by asking you for the body, the date, and the packet text, and says it will not choose a position for you. If it starts writing a comment with facts it made up, it's E08, and the fix is to remind it of the rules in the instructions.

5. **CV-LC-01-5.** Use it. Start each new task as a new chat inside the project. Tell it which of the four jobs you want. For records requests, still do the state-law lookup yourself on an official page, as in [CV-FR-03](CV-FR-03-request-public-records.md).
   You'll know it worked when the chat asks for the right inputs for your job.

6. **CV-LC-01-6.** (Optional, Claude only.) If your Claude plan lets you upload skills, you can upload the four kit [skill](../glossary.md#skill) folders instead of using project instructions. Follow Claude's current help pages for where the upload button is. Each skill folder is zipped with the folder name unchanged.
   You'll know it worked when Claude lists the skill names (public-comment-packet, records-request, census-county-table, and meeting-transcripts) in its skills list.

> **How to get help.** Write down the [step ID](../glossary.md#step-id) where you got stuck (it looks like CV-FR-01-3). If your kit has a [check-up](../glossary.md#check-up) button or command, run it and copy the [support code](../glossary.md#support-code) it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
