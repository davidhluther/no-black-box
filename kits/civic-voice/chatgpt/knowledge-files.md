# Knowledge files for the Custom GPT or ChatGPT Project

Upload these files from the kit as knowledge. ChatGPT allows up to 20 files; this list uses 9.

1. `free/prompts.md` (the paste-in prompts)
2. `free/checklists/meeting-prep-checklist.md`
3. `free/checklists/records-request-checklist.md`
4. `skills/records-request/references/state-law-lookup.md`
5. `skills/records-request/references/request-template.md`
6. `skills/public-comment-packet/references/prep-memo-template.md`
7. `skills/public-comment-packet/references/comment-templates.md`
8. `skills/census-county-table/references/margin-of-error.md`
9. `glossary.md`

Also add `fixes.md` if you want the GPT to help with problem codes.

Upload nothing that contains your own documents you would not want kept in a chat tool (for example private letters or personal details). Meeting packets are public, but check the file before you upload it.

Do not upload your Census key, and do not paste it into the chat. The key is only for the full version, on your own computer.
