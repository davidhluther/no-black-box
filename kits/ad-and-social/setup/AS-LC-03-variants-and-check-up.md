# AS-LC-03: Log Your Test Versions and Run the Check-Up

Time about 15 minutes. You'll keep a record of what you tested, so next month you aren't guessing.

1. **AS-LC-03-1.** If you haven't yet, finish guide AS-FR-02 so your Google Sheet has the Voice, [Variants](../glossary.md#variant) and Config tabs and the Help menu.
   You'll know it worked when the Help menu appears (E09 if not).
2. **AS-LC-03-2.** Ask your [Project](../glossary.md#project) for "three versions that differ in one thing each" (Prompt 3 in [prompts.md](../free/prompts.md)). Copy each version's row into the Variants tab. Write the metric you'll judge by before you run anything (for example "clicks to the sign-up page").
   You'll know it worked when each version has a row and a metric.
3. **AS-LC-03-3.** Run the versions at the same time, with the same audience and budget. Write the run dates down.
   You'll know it worked when the ad platform shows both versions running.
4. **AS-LC-03-4.** When enough time has passed, write the result in the sheet. Few clicks mean a small test, and a small test can't tell a real winner from luck. Write "too small to tell" when that's true.
   You'll know it worked when the Result column has a plain sentence.
5. **AS-LC-03-5.** Click Help, then "Run check-up," and keep the code if anything fails (see [fixes](../fixes.md)).
   You'll know it worked when the report shows all tabs found.

> **How to get help.** Write down the step ID where you got stuck (it looks like AS-LC-03-5). If your kit has a check-up button or command, run it and copy the support code it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
