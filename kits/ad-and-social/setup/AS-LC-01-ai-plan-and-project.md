# AS-LC-01: Set Up a Project on Your AI Plan

Time about 25 minutes. You'll finish with a saved workspace that already knows your voice, so you stop pasting it.

Before you start, finish guides AS-FR-01 and AS-FR-02. The low-cost version builds on your [voice sheet](../glossary.md#voice-sheet) and Google Sheet.

1. **AS-LC-01-1.** Choose one AI plan from one vendor (ChatGPT, Claude or Gemini). See the vendor's own pricing page for today's price, and pick the plan with a [Projects](../glossary.md#project) or saved-instructions feature. A Project is a saved workspace where the [AI model](../glossary.md#ai-model) keeps your files and standing instructions.
   You'll know it worked when you can see "Projects" or "Gems" or a similar item in the sidebar. If you don't, check the plan's feature list on the vendor's page (E18).
2. **AS-LC-01-2.** Create a Project named "Ad and Social." Open [instructions.md](../chatgpt/instructions.md) and paste its text into the Project's instructions box.
   You'll know it worked when the Project shows your instructions.
3. **AS-LC-01-3.** Upload the files listed in [knowledge-files.md](../chatgpt/knowledge-files.md), plus your voice sheet as a plain text or PDF file saved from your Voice tab.
   You'll know it worked when each file appears in the Project's file list. If a file is refused as too large, split it (E15).
4. **AS-LC-01-4.** Start a chat inside the Project and type "Which files do you have, and what is my organization's tone?"
   You'll know it worked when the model names your files and describes your tone from the voice sheet. If it answers generically, it's E18.
5. **AS-LC-01-5.** Ask for ad text with "Search ad text for [offer]. Here are today's limits from the ad screen: ..." Check the numbers against the ad screen yourself.
   You'll know it worked when the answer includes counts and a claims list. If it goes over the limits, it's E03.

> **How to get help.** Write down the step ID where you got stuck (it looks like AS-LC-01-4). If your kit has a check-up button or command, run it and copy the support code it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
