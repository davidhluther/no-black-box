# Picture shapes by platform

Use the official page as the source. The "checked" rows were read on the platform's own page on 11/13/2026. The others are starting points that other guides commonly cite, and each needs a look at the official page before you export.

| Platform and placement | Shape and size | Status | Official page |
|---|---|---|---|
| Facebook Feed image ad | 4:5, 1440 x 1800 pixels recommended, JPG or PNG, 30MB maximum, minimum width 600 pixels | Checked 11/13/2026 | https://www.facebook.com/business/ads-guide/image |
| Instagram Feed image ad | 4:5, 1440 x 1800 pixels recommended, JPG or PNG | Checked 11/13/2026 | https://www.facebook.com/business/ads-guide/image/instagram-feed |
| Google uploaded display ads | Fixed pixel sizes (for example 300 x 250), 150KB maximum for image ads | Checked 11/13/2026 | https://support.google.com/google-ads/answer/1722096 |
| Google image assets (Performance Max, Demand Gen, responsive display) | Square and landscape shapes are commonly used | Not verified | Search "image asset specifications" at https://support.google.com/google-ads/ |
| Instagram Stories and Reels | Tall 9:16 is commonly used, with text-safe areas | Not verified | https://www.facebook.com/business/ads-guide |
| Facebook link preview and blog header | 1200 x 630 pixels (1.91:1) is the common sharing size | Not verified | The platform's sharing debugger or help page |
| X in-feed image | Wide and square shapes are commonly used | Not verified | https://business.x.com/en/help/campaign-setup/creative-ad-specifications |

## Checking a size

1. Open the official page and find the row for your placement.
2. Copy its pixel size, shape and file limits into the brief.
3. Write today's date beside it.
4. If the page doesn't open or doesn't show the number, record "not verified" and ask the user to read it from the ad screen.
