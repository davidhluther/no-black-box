# Fixes

Find the code the [check-up](glossary.md#check-up) printed, or match what you see. Each row says what is going on, why, and what to do. [Step IDs](glossary.md#step-id) look like CE-FU-03-4: kit, version, guide, step. Shared codes from E90 up are explained in [getting help](../../guides/getting-help.md).

| Code | What you see | Why | The fix | Step |
|---|---|---|---|---|
| E01 | The [command line](glossary.md#command-line) says claude is not found, or a [skill](glossary.md#skill) is missing after install | [Claude Code](glossary.md#claude-code) isn't installed, the window was open during install, or the [plugin](glossary.md#plugin) install didn't finish | Open a new window and run `claude --version`. If it prints a version, run the two `/plugin` lines again, restart Claude Code, and ask it to list its skills. | CE-FU-01-1, CE-FU-01-3 |
| E02 | A message about config.json missing, unreadable, or a key not found | The file wasn't copied, or a comma or quote was lost | Copy config.example.json again and re-enter your values. Check commas and quote marks. Keys never go in this file. | CE-FU-01-4, CE-FU-01-5 |
| E03 | A skill says a folder is missing, such as briefs or ops | The work folders weren't made, or you're in the wrong folder | Run the folder command from the kit folder, then retry from the same place. | CE-FU-01-6 |
| E04 | [Python](glossary.md#python) is missing or older than 3.9 | The computer has an old version, or the window needs reopening | Install the current Python from python.org, open a new window, and run `python3 --version`. | CE-FU-01-2 |
| E05 | The weekly [feed](glossary.md#feed) bundle has a source marked empty or FAILED | The address changed, the site blocks automated readers, or the site was down | Open the address in a browser. If it shows a page of code it works, so retry. Otherwise fix the address or drop the source, and say so in the note. A source that fails two weeks running belongs in the note's first paragraph. | CE-FU-03-3 |
| E06 | The daily check says a job is MISSED or FAILED, or the log has no line for a scheduled day | The [scheduler](glossary.md#scheduler) entry was removed, the computer was asleep or off, the job name differs from the one in the config, or a path changed | Run the job by hand now through the wrapper, write down why it missed, and fix the scheduler entry. Check that `--job` matches the name in `schedule.jobs`. Tell the job's owner the same day. | CE-FU-03-1, CE-FU-03-3, CE-FU-03-5, CE-FU-03-6 |
| E07 | [Search Console](glossary.md#search-console), Bing, [GA4](glossary.md#ga4), and a paid platform disagree on direction | Different date windows, country filters, sampling, and sources | Don't average them. Put each source's date range and filters side by side, find the reason, and grade the finding unverified until the reason is checked. Act only when at least two sources agree. | CE-FU-02-4, CE-FU-04-4 |
| E08 | An AI-answer check gives a different result each time you run it | AI answers change from run to run, by model, date, and wording | Repeat the check several times, record the date and model with each, and treat a single run as a hypothesis. Never change a page on one run. | CE-FU-04-4 |
| E09 | A Search Console pull fails, returns nothing, or returns fewer rows than the export | Missing access, the wrong property name, a new property, or a row limit on the pull | Confirm you can open the property and export it by hand. Copy the property name exactly. For a pull that is capped, use the export instead and write down that the pull was partial. | CE-FU-02-2, CE-FU-02-3 |
| E10 | A brief carries READ INCOMPLETE for a platform, or a platform call is refused for [quota](glossary.md#quota) | The plan's monthly calls or credits are spent | Don't treat the brief as clean. Re-run the brief after the quota resets, or use Search Console and Bing data and say so in the brief. Add the platform's remaining quota to the weekly ops check. | CE-FU-02-5 |
| E11 | A [CMS](glossary.md#cms) call rejects a field or fails to save a draft | A required field is empty, a value isn't in the allowed list, or the key lacks permission | Read the field the message names, fix it in the article's field table or in the site profile, and run the [dry run](glossary.md#dry-run) again. Confirm the key can create drafts. | CE-FU-02-6, CE-FU-04-6 |
| E12 | Publish reports deploy_unconfirmed, live_check_failed, or merge_uncertain | The merge happened but the live deployment wasn't confirmed, the live page didn't show the post's title, or GitHub didn't answer | Treat it as not published. Open the live page, check the title, and read the script's explanation. Never retry a merge blindly; re-read the [pull request](glossary.md#pull-request)'s state first. | CE-FU-04-6 |
| E13 | draft-queue refuses to start and names the [handoff note](glossary.md#handoff-note) | The note is missing, unreadable, over three weeks old, or BLOCKED | Run content-handoff, fix what it lists as blocked or stale, then run draft-queue again. A stale note often means a [scheduled job](glossary.md#scheduled-job) missed (see E06). | CE-FU-03-7 |
| E14 | The tell-score [gate](glossary.md#gate) fails every draft, or passes drafts you know are weak | The thresholds don't match your own writing, or the rules changed | Re-score five to ten of your best pages, reset the ceilings above them, and keep a record of the change. Read the emerging-phrases report before banning anything new. | CE-FU-04-2 |
| E15 | Two writers drafted the same Planned item | Nobody claimed it, or the [queue](glossary.md#queue) has no owner column | Add the owner column, claim an item before starting, and let one operator run draft-queue at a time. Merge the two drafts by choosing one. | CE-FU-03-8 |
| E16 | The paid platform key isn't found, or the skill asks you to paste it | The variable isn't set in the window Claude Code started from, or is misspelled | Set the variable, open a new window, and restart Claude Code. Never paste the key into the chat. | CE-FU-02-5 |
| E17 | A key appeared in a chat, a config file, a document, or a commit | It was pasted somewhere it shouldn't be | Revoke the key at its service, make a new one, and store it as in guide CE-FU-02. Check any shared place it reached. | CE-FU-02-1 |
| E18 | The tell-score output has lines starting EXTRACTION PROBLEM | The selector that picks the article text is wrong for that site | Check the selector on two or three pages before trusting any number. A wrong selector quietly poisons the scores. | CE-FU-03-4, CE-FU-04-2 |
| E19 | The topic screen says a source is INCOMPLETE | A sitemap, queue export, or briefs folder wasn't set or couldn't be read | Set the missing path in the config. A source that didn't run is never a clean result. | CE-FU-03-7 |
| E20 | The brief check says BRIEF PARTIAL | The brief lacks a required section or has too few words | Re-run content-brief for that topic. Never edit a brief by hand to pass the check. | CE-FU-03-7 |

## When none of these fit

Write down the [step ID](glossary.md#step-id) where you got stuck and the [support code](glossary.md#support-code) from `python3 support/doctor.py content-engine`. Then send both to Pigasus Group through the [contact page](https://pigasus.group/contact). Setup questions are free. New problems get added to this table so the next team doesn't hit them.
