# Choose Your Version

This kit is the full team version, and it is the only version of the content engine. It assumes [Claude Code](glossary.md#claude-code), a shared work folder, named owners, and at least one site you can publish to. There is no free or low-cost edition of this kit, because the things a team needs (a schedule, a log, several sites, an approval line) don't fit in a spreadsheet and a pasted [prompt](glossary.md#prompt).

If you are one person, a volunteer group, or a small organization, run the same method with the matching small-business kit.

| | Small team or one person | In-house team (this kit) |
|---|---|---|
| Where to go | [Idea to live post](../idea-to-post/choose-your-version.md), free and low-cost versions | You are here |
| What runs it | A chat tool and Google Sheets, or one paid AI plan with small Google scripts | Claude Code, [Python](glossary.md#python) scripts, a shared work folder |
| Sites and markets | One | Several, one config file each |
| Schedule | Weekly reminder and a Log tab | Job log, retries, and a check that flags a missed slot |
| Quality gates | A pasted checklist and a word check | Four gates run by script, plus an evidence review |
| Publishing | A person pastes the post | Git [pull request](glossary.md#pull-request) with an exact-words approval, or a [CMS](glossary.md#cms) draft |
| Who owns what | The one person | Named owners per role, with backups |
| Reporting | A Measure tab | A one-page leader summary, graded for evidence |
| Cost | See each small-business kit's shopping list | See the [shopping list](shopping-list.md) |

For writing rules without the pipeline, [Plain writing](../plain-writing/choose-your-version.md) has its own free, low-cost, and full versions.

## Switching later

Moving from a small kit to this one carries over most of what you built: your [queue](glossary.md#queue) columns, your briefs, your style guide, and your banned-words list. Copy the folders into this kit's work folders, add the extra queue columns named in [CE-FU-03](setup/CE-FU-03-run-the-weekly-cycle-on-a-schedule.md), and fill in the owner table. Moving the other way is just as easy. Every brief and draft is a plain [markdown](glossary.md#markdown) file, so nothing here locks you in.

## Not sure?

If more than one person touches a page before it goes live, or leaders ask you to show what the program produced, use this kit. If one person does it all and nobody asks for a report, start small.
