# Glossary

Every technical term used in this kit, in plain words. Each page of the kit links the first use of a term here. Terms from the shared guides are in the [main glossary](../../guides/glossary.md).

**API.** A way for two programs to talk to each other, like a waiter carrying orders between you and the kitchen. <a id="api"></a>

**API key.** A long secret that proves a program may use a service. Treat it like a house key. <a id="api-key"></a>

**Bing Webmaster Tools.** Microsoft's free service that shows how your site performs in Bing search, the way Search Console does for Google. <a id="bing-webmaster-tools"></a>

**Cannibalization.** Two or more of your own pages competing for the same search, so neither ranks as well as one stronger page would. <a id="cannibalization"></a>

**Check-up.** A built-in test that looks at your setup and prints a short support code, so a helper can see where a step went wrong. <a id="check-up"></a>

**Claude Code.** A program from Anthropic that runs on your computer, takes typed instructions, reads and writes files, and runs tools for you. <a id="claude-code"></a>

**CMS.** Short for content management system, the software where your team writes, edits, and publishes pages. WordPress and Contentful are examples. <a id="cms"></a>

**Command line.** A plain text window where you type instructions instead of clicking. Also called the terminal. <a id="command-line"></a>

**Content brief.** A one- or two-page plan for a single page. It names the search it answers, the reader, the outline, the sources, and the links, so the writer doesn't guess. <a id="content-brief"></a>

**CRM.** Short for customer relationship management, the system where leads, accounts, and pipeline are tracked. Salesforce and HubSpot are examples. <a id="crm"></a>

**Cron.** The built-in scheduler on Mac and Linux computers. One line of text says what to run and when. <a id="cron"></a>

**CSV.** A plain table saved as text, one row per line with commas between columns. Spreadsheets open and save them. <a id="csv"></a>

**Dry run.** A practice pass that shows what would happen without doing it. <a id="dry-run"></a>

**Environment variable.** A named setting stored outside your files, where a key can live without appearing in a document. <a id="environment-variable"></a>

**Feed.** A web address that publishes a site's newest posts in a form programs can read, so you can collect news without visiting each site. Also called an RSS feed. <a id="feed"></a>

**GA4.** Short for Google Analytics 4, Google's free tool for counting visits to your site and what visitors do there. <a id="ga4"></a>

**Gate.** A check that must pass before something moves on. A failed gate stops the page and says why. <a id="gate"></a>

**Handoff note.** A one-page note that rates each planning input fresh, stale, or missing, lists priorities, and says what changed since the last note. Drafting skills read its header first and refuse to run on a blocked one. <a id="handoff-note"></a>

**Looker Studio.** Google's free reporting tool for dashboards built from spreadsheets, files, and analytics sources. <a id="looker-studio"></a>

**Markdown.** A plain text format where a pound sign makes a heading and an asterisk makes a list. Files end in .md. Every brief and draft in this kit is one. <a id="markdown"></a>

**Plugin.** An add-on that gives a program new abilities. In Claude Code, a plugin bundles this kit's skills so they install in one step. <a id="plugin"></a>

**Prompt.** The instructions you type to an AI model. <a id="prompt"></a>

**Pull request.** A proposed change to a site's files that waits for review before it joins the live version. Publishing here means one pull request per post. <a id="pull-request"></a>

**Python.** A programming language. The gate scripts and the job log are small Python programs, and the steps show exactly how to run each. <a id="python"></a>

**Queue.** The list of every page in flight and the stage each is at, kept in a spreadsheet or a project tool and exported to CSV so scripts can read it. <a id="queue"></a>

**Quota.** The number of calls or rows a service lets you use in a period. Past it, calls fail until the period resets. <a id="quota"></a>

**Scheduled job.** A task your computer or a service runs by itself at set times, such as every Monday morning. <a id="scheduled-job"></a>

**Scheduler.** The part of a computer or a service that starts scheduled jobs at their times. Cron is one. <a id="scheduler"></a>

**Search Console.** Google's free tool that shows which searches bring people to your site, how often you appear, and how often people click. <a id="search-console"></a>

**Search intent.** What a person wants when they type a search: to learn something, compare options, do a task, or find a price. <a id="search-intent"></a>

**Skill.** A folder of instructions (and sometimes small programs) that teaches an AI model one job. The official file name inside is SKILL.md. <a id="skill"></a>

**Slug.** The last part of a page's web address, such as "approval-workflows" in example.org/blog/approval-workflows. <a id="slug"></a>

**Step ID.** The printed label on each numbered step, such as CE-FU-01-3, that you can quote when you ask for help. <a id="step-id"></a>

**Support code.** A short code the check-up prints. It tells a helper which step failed, the problem, and the kit version. <a id="support-code"></a>

**Validator.** A checker that reads a draft and lists rule breaks, the way a spell checker lists misspellings. <a id="validator"></a>

**Verdict.** The decision a brief records about its topic: new post, refresh, hold, or skip. <a id="verdict"></a>
