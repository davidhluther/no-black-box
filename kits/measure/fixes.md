# Fixes

Find the code the guide or the check-up gave you. If your code is not here, send it to Pigasus Group (see the box at the end of any guide) and we will add the fix for the next person.

| Code | What you see | Why | The fix | Step |
|---|---|---|---|---|
| E01 | The check-up says a tab is "missing" | The tab was not imported, or its name has a different spelling or capital letter | Import the matching [CSV](glossary.md#csv) from the kit's `free/` folder and rename the tab to match exactly, for example "Search queries" with a capital S and a space | MM-FR-01-2 |
| E02 | The check-up says "headers do not match", or everything sits squashed in column A | A header was edited, a column moved, or the CSV imported with the wrong separator | Compare row 1 with the CSV template. Re-import with File, Import, "Replace current sheet" and "Comma" as the separator, then re-enter your rows | MM-FR-01-2 |
| E03 | The check-up says a Config cell is "empty" | One of the four values in Config column B is blank | Fill in organization name, site address, [GA4](glossary.md#ga4) property number and report month. The check-up never shows what you typed | MM-FR-01-3 |
| E04 | Google keeps asking you to sign in, shows the wrong account, or says "You don't have access" | Several Google accounts are signed in, or the account lacks permission | Open a private browser window and sign in with only the account that manages the site. Ask the owner to add you as Viewer (or Editor to add [events](glossary.md#event)) | MM-FR-01-1 |
| E05 | No Kit help menu appears in the sheet | The page was not reloaded, or the script was saved without the opening function, or it was never allowed to run | Reload the page and wait ten seconds. If still missing, open Extensions, [Apps Script](glossary.md#apps-script), and confirm `checkup.gs` is pasted in whole, saved, and run once with permission granted | MM-FR-01-5 |
| E06 | GA4 shows no property, or "no analytics accounts" | GA4 was never set up for your site, or you are in the wrong account | Check you are signed in with the right account. If no property exists, click Admin, "Create", "Property", follow Google's prompts, and add a data stream for your website. Add Google's measurement code through [Tag Manager](glossary.md#google-tag-manager) or have your site editor add it | MM-FR-02-1 |
| E07 | [Search Console](glossary.md#search-console) says "not verified" or the site is not listed | Ownership was not proved, or the domain setting was never added | Add the property again with "Domain" and add the text line Google gives you to your domain's settings (whoever manages your domain name can do this in minutes). Wait a day and check again | MM-FR-02-2 |
| E08 | GA4 reports show "no data" | The tracking code is not on the site, or the date range is too early, or a filter hides everything | Pick a recent date range. Open Admin, Data streams, and look for "Receiving data" (it can take a day). If it never receives data, the measurement code is not installed | MM-FR-02-4 |
| E09 | [Clarity](glossary.md#clarity) shows no recordings after a day | The Clarity code is not on the pages | Check the project's address spelling. Confirm the code was added in Tag Manager and published, or pasted on every page by whoever edits the site | MM-FR-02-5 |
| E10 | Tag Manager has no Submit button | You have read-only access | Ask the [container](glossary.md#container) owner to give your account "[Publish](glossary.md#publish)" access under Admin, User management | MM-FR-03-2 |
| E11 | Google says the app is "not verified" and blocks you | Scripts you write yourself are not submitted to Google for review | Click "Advanced" and then "Go to (project name) (unsafe)". Read the permission list first; it should be only your sheet and, for the pulls, read-only Search Console or Analytics. If your organization's Google admin blocks this, ask them to allow it | MM-FR-01-4 |
| E12 | [Preview mode](glossary.md#preview-mode) never shows the "Connected" badge | A pop-up blocker, a privacy extension, a cookie banner covering the screen, or the site address has a typo | Allow pop-ups for tagmanager.google.com, turn off ad blockers for the test, type the address exactly as it appears in your browser, and try a private window | MM-FR-03-6 |
| E13 | DebugView stays empty | Preview is not connected, the GA4 stream's measurement ID in the tag is wrong, or an ad blocker blocks Google | Re-connect preview, compare the ID in the tag to Admin, Data streams, and test in a window without extensions | MM-FR-03-7 |
| E14 | An event count looks doubled | Two tags fire for the same click, or an old tag counts the same thing | In preview, click once and count the tags fired. Do not turn the older tag off yourself; report only the canonical event and write down the duplicate | MM-FR-03-9 |
| E15 | The AI Traffic row shows zero or very little | Either your site really gets few visits from AI tools, or most AI visits arrive with no [referrer](glossary.md#referrer) | Check the pattern in the [channel group](glossary.md#channel-group) has no stray spaces, and that AI Traffic sits above Referral. If both are right, zero is a true floor. Say so in your report | MM-FR-04-3 |
| E16 | [Looker Studio](glossary.md#looker-studio) shows "Data set configuration error" or an empty list | The sheet moved, was renamed, lost sharing permission, or the tab is empty | Reconnect the data source: Resource, Manage added data sources, Edit. Confirm you can open the sheet yourself | MM-FR-04-5 |
| E17 | Two sources disagree about up or down | A data feed that started late, address variants (www, trailing slash, `#` fragments), different day boundaries, filters, or measures that are not comparable | Match the date windows exactly, compare like pages and channels, and check each source's first date of history. Until it is explained, write "direction disputed" and do not act on the figure | MM-FR-05-4 |
| E18 | The editor underlines the manifest file in red | A comma is missing or extra in appsscript.json | Put a comma after every entry except the last in each list and re-save | MM-LC-01-2 |
| E19 | An error mentions 403, "permission" or "no access" | The account running the script cannot see the Search Console property or GA4 property | In Search Console, Settings, Users and permissions, confirm the account is listed. In GA4, Admin, Property access management, confirm at least Viewer. For the full version, confirm the [service account](glossary.md#service-account) email was added as "Restricted" | MM-LC-01-4 |
| E20 | "AnalyticsData is not defined" | The Google Analytics Data [API](glossary.md#api) service was not added to the script project | In the Apps Script editor click "+" beside Services and add "Google Analytics Data API" with the identifier AnalyticsData | MM-LC-02-1 |
| E21 | The AI plan gives generic answers and ignores the kit's method | The instructions or files were not saved, or the question did not ask for the metric check | Re-paste the instructions, confirm the files are listed in the Project, and begin the chat with "Run the metric check on this move" | MM-LC-03-4 |
| E22 | "command not found" or a [skill](glossary.md#skill) is missing in Claude Code | The tool was not installed, the terminal needs reopening, or the kit was not added | Close and reopen the terminal, run the version check from the shared install guide, and add the kit again | MM-FU-01-1 |
| E23 | A menu name in a guide does not exist on your screen | Google renamed or moved it | Search Google's help for the task name in quotes (for example "GA4 custom channel group") and use the newest page. Tell us the step ID so we update the guide | any |
| E24 | You cannot create a Google Cloud project | Your organization's admin restricts new projects, or you are not signed in to the right account | Ask the admin to create the service account for you, or to give you the project creator role | MM-FU-02-1 |
| E25 | The Clarity script says no [token](glossary.md#token) was found | The token file name does not match the project name, or the [environment variable](glossary.md#environment-variable) has a different name | Name the file `<project>.token` in `~/.config/clarity/`, or set `CLARITY_TOKEN_<PROJECT>` with letters and underscores only | MM-FU-02-4 |
| E26 | The Clarity script says the daily limit is used | Clarity allows 10 requests per project per day and the script counts them | Wait until tomorrow. Plan the day's calls: one by channel, one by source and medium and channel, the rest for questions | MM-FU-02-5 |
| E27 | The check-up says the site address "shape looks wrong" | The Config site_url is not `sc-domain:name` and not a full address ending in a slash | Use `sc-domain:example.org` or `https://www.example.org/` with the final slash | MM-FR-01-3 |
| E28 | The check-up says the GA4 property number "shape looks wrong" | It holds the measurement ID (starts with G-) or other text instead of the property number | Use the number of six or more digits from GA4, Admin, Property details | MM-FR-01-3 |

Code E00 is not a problem. It means the check-up looked at everything it checks and found nothing wrong.
