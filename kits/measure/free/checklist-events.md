# Checklist: add events without breaking anything

Copy this into a Google Doc and tick as you go. Date format mm/dd/yyyy.

## Before

- [ ] I wrote down three to six questions the events will answer.
- [ ] I wrote what counts as a lead in one sentence.
- [ ] I opened [Tag](../glossary.md#tag) Manager and made a new workspace (a draft copy) with today's date in its name.
- [ ] I took a note of the live version number so I can go back to it.

## While building (additive only)

- [ ] Every new tag, [trigger](../glossary.md#trigger) and [variable](../glossary.md#variable) starts with the same prefix (for example "Add |").
- [ ] I edited, renamed, paused and deleted nothing that already existed.
- [ ] [Event](../glossary.md#event) names are lowercase with underscores, under 40 characters.
- [ ] No event carries a name, email address, phone number or form answer.

## Test in preview mode

- [ ] I clicked Preview and connected to my site.
- [ ] Each event fired once, on the right action.
- [ ] Each event carried the right extra facts.
- [ ] Two tags did not fire for the same action.

## Publish and watch

- [ ] The owner said yes to publishing.
- [ ] I published with a version name and a note saying what was added.
- [ ] Next day, the events show in [GA4](../glossary.md#ga4) under Admin, Events.
- [ ] I marked only real "someone took the step" events as key events.
- [ ] I wrote the date of the change somewhere reports can see it, because it can change comparisons.
