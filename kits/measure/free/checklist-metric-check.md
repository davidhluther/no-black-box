# Checklist: check a number before explaining it

- [ ] I can say in one sentence what the number counts.
- [ ] Same time window on both sides. Same length. Date it runs through written down.
- [ ] No tracking, [tag](../glossary.md#tag), form or definition change inside the window (or I compared like with like).
- [ ] I listed causes: our changes, rankings and pages, AI answers, other people's changes, outside forces, tracking, chance.
- [ ] Each cause has evidence for, evidence against, and a grade: holds, weakened or refuted.
- [ ] I confirmed the direction on a second independent source. Sources that read the same upstream data count as one.
- [ ] If the sources disagree, I wrote "direction disputed" and did not act on it.
- [ ] If there is only one source, I wrote "[single-source](../glossary.md#single-source)".
- [ ] Missing data is written as missing, never zero.
- [ ] I ended with one action, one owner and a bottom line.
