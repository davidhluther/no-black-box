# Use Your AI Plan as Your Analyst (Low Cost, Guide 3)

You will load the kit's method into one AI plan so it checks your numbers the same way each month. The paid part is one plan at roughly 20 dollars a month from ChatGPT or Claude; see each company's own price page for the current price. A free plan can do the same job with more pasting, which the free guides cover. About 30 minutes.

1. **MM-LC-03-1.** Choose one. Both work. Read [Install ChatGPT](../../../guides/install-chatgpt.md) or [Install Claude](../../../guides/install-claude.md), whichever you will use, and sign up for the plan there. Make a new Project (a named [workspace](../glossary.md#workspace) inside ChatGPT or Claude that remembers files and instructions for one job) called "Website measurement".
   You'll know it worked when you see an empty Project with a place for instructions and files.

2. **MM-LC-03-2.** Paste the instructions. Open the kit's `chatgpt/instructions.md`, copy everything below the line, and paste it into the Project's instructions box. They are under 8,000 characters so they fit either product.
   You'll know it worked when the instructions save without a "too long" message.

3. **MM-LC-03-3.** Upload the reference files listed in `chatgpt/knowledge-files.md`. In Claude, you can instead upload each [skill](../glossary.md#skill) folder as a zip so the skill itself runs; the shared Claude guide shows how. A [skill](../glossary.md#skill) is a folder of written instructions an AI tool follows to do one job the same way each time.
   You'll know it worked when the Project lists twelve files. Do not upload data exports that contain names or email addresses.

4. **MM-LC-03-4.** Try it on a real move. Paste last month's totals (never customer details) and write: "My organic [sessions](../glossary.md#session) fell 15 percent. Run the metric check." The Project should ask what changed, define the measure, list causes with grades, name a second source to confirm and end with one action.
   You'll know it worked when each cause carries a grade (holds, weakened or refuted) and the answer names a second source. If it states a cause as fact without a grade, remind it of the rule in its instructions. If answers look generic, it did not read the files; it's E21.

5. **MM-LC-03-5.** Make it a monthly habit. After your [Apps Script](../glossary.md#apps-script) pulls run on day 3, open the sheet, copy the new rows (and only those) into the Project, and ask for the monthly report. Use the free guide 5 steps for the checks. Keep the report where your board or team can open it.
   You'll know it worked when you have a finished report with a bottom line, sources, graded causes and next actions.

> **How to get help.** Write down the step ID where you got stuck (it looks like MM-LC-01-3). If your kit has a check-up button or command, run it and copy the support code it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
