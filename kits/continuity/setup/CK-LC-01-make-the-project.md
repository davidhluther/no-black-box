# CK-LC-01 Make the AI Project

You will set up a saved workspace where an [AI model](../glossary.md#ai-model) interviews you and scores the [bus test](../glossary.md#bus-test). You need a paid plan from ChatGPT or Claude that includes Projects. See the [shopping list](../shopping-list.md) for prices and the [keys and accounts guide](../../../guides/keys-and-accounts.md) for signing up.

1. **CK-LC-01-1.** Sign in to ChatGPT at chatgpt.com or Claude at claude.ai on a plan that includes Projects. Look for Projects in the left sidebar.
   You'll know it worked when you can see a Projects item. If you only see a plain chat box, check your plan. If you cannot sign in, it's E08.
2. **CK-LC-01-2.** Click New project and name it Continuity. An [AI Project](../glossary.md#ai-project) is a saved workspace where standing instructions and files stay put between chats.
   You'll know it worked when an empty project page opens.
3. **CK-LC-01-3.** Open `chatgpt/instructions.md` from the kit, copy everything below the line of dashes, paste it into the project's Instructions box and save. It is under 8,000 characters, so it fits a ChatGPT Project, a Claude Project or a [Custom GPT](../glossary.md#custom-gpt).
   You'll know it worked when the box begins "You help the owner of a small business". If it says the text is too long, you pasted more than the instructions.
4. **CK-LC-01-4.** Upload the files listed in `chatgpt/knowledge-files.md`. A [knowledge file](../glossary.md#knowledge-file) is a document the AI model can read every time. Do not upload your own [runbooks](../glossary.md#runbook).
   You'll know it worked when the project lists the files by name.
5. **CK-LC-01-5.** Test with the invented example. In a new chat in the project, type Run the bus test on my business. Say you run an example food pantry with one coordinator, and answer the questions with the answers in `free/examples-bus-test.md`.
   You'll know it worked when the AI model asks one question at a time, stops at the first no for each function, and finishes with a total out of 15 and a band. If it skips a question or scores without asking, it's E10.
6. **CK-LC-01-6.** Optional. If you want the Sheet too, follow [CK-FR-01](CK-FR-01-run-the-bus-test.md) steps 1 to 3 so you have a place to keep the scores.
   You'll know it worked when the Help menu appears in your Sheet.

> **How to get help.** Write down the step ID where you got stuck (it looks like CK-LC-01-3). If your kit has a [check-up](../glossary.md#check-up) button or command, run it and copy the [support code](../glossary.md#support-code) it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
