# CK-FR-03 Test and Score Again

A page nobody has used is a guess. You will have a stand-in do real work from it, then score again.

1. **CK-FR-03-1.** Choose a stand-in who does not already know how you work. Ask them for one hour. Tell them you will stay out of it and will only answer a question if they are completely stuck.
   You'll know it worked when someone has said yes and you have a date.
2. **CK-FR-03-2.** Give them one task from each [runbook](../glossary.md#runbook) you wrote. For example, find where cash stands from the money runbook, walk one normal cycle of work from the operations runbook, and get into one critical account using only the access runbook.
   You'll know it worked when they have a task for each document. Keep each task small.
3. **CK-FR-03-3.** Watch without helping. Write down each place they get stuck, each question they ask and each thing they guess.
   You'll know it worked when you have a list. An empty list means the task was too easy, so try a harder one.
4. **CK-FR-03-4.** Fix every gap on the list. Each place they were stuck is the next blank to fill, and each guess is a step to write down. Then have them try the same task again.
   You'll know it worked when they finish a task with no questions.
5. **CK-FR-03-5.** Go back to the BusTest [tab](../glossary.md#tab) and change the answers. A function earns "yes" on question 3 only after someone other than you has run it from the page. Then read the new total and band. Add a repeating reminder to your calendar to score again in three months.
   You'll know it worked when the score has moved or you can say why it has not. If it did not move, the work did not land, so say so plainly and try again.
6. **CK-FR-03-6.** Choose Kit help, then Run [check-up](../glossary.md#check-up) and keep the [support code](../glossary.md#support-code).
   You'll know it worked when the box says everything checked out. If something fails, the code and step ID point at the fix in [fixes.md](../fixes.md).

> **How to get help.** Write down the step ID where you got stuck (it looks like CK-FR-03-3). If your kit has a check-up button or command, run it and copy the support code it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
