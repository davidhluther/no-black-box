# CK-FR-01 Run the Bus Test

You will score your business on five functions and see one number out of 15. Plan on about an hour, with a pen nearby.

1. **CK-FR-01-1.** Open [Google Sheets](../glossary.md#google-sheets) (Google's free spreadsheet app) at sheets.google.com and sign in. For help with accounts, see the [keys and accounts guide](../../../guides/keys-and-accounts.md).
   You'll know it worked when you see a page of blank or recent spreadsheets. If you loop back to the sign-in page, it's E08.
2. **CK-FR-01-2.** Click Blank spreadsheet and name it [Bus Test](../glossary.md#bus-test). Choose File, then Import, then Upload, and drag in `free/templates/BusTest.csv` from the kit. Under Import location pick "Replace current sheet". Rename the [tab](../glossary.md#tab) at the bottom to exactly BusTest. Then choose File, Import again with `Churn.csv`, pick "Insert new sheet(s)", and rename that tab Churn. A [CSV](../glossary.md#csv) is a plain text table, and a [tab](../glossary.md#tab) is one of the labeled pages along the bottom.
   You'll know it worked when two tabs named BusTest and Churn show along the bottom, and BusTest lists the five functions in column A. A misspelled tab is E01, and a header row that looks different is E02.
3. **CK-FR-01-3.** Add the [check-up](../glossary.md#check-up). Choose Extensions, then [Apps Script](../glossary.md#apps-script). ([Apps Script](../glossary.md#apps-script) is Google's way of adding a small program to a Sheet.) Delete the sample code, open `free/checkup.gs` in a text editor, copy all of it, paste it in, click the save icon, and name the project Continuity Check-Up. Close that tab, reload the Sheet, and wait a few seconds.
   You'll know it worked when a Help menu appears. If it does not, it's E09.
4. **CK-FR-01-4.** Read the [questionnaire](../free/bus-test-questionnaire.md) once, all the way through, including the paragraph on target scores.
   You'll know it worked when you can say in one sentence what the three questions are. If you cannot, read the scoring table again.
5. **CK-FR-01-5.** Answer the questions in the BusTest tab for each function. Type yes or no in columns B, C and D. Answer in order and stop at the first no, leaving the rest blank. If you are unsure, type no. Writing "it's in my head" means not written down, so type no.
   You'll know it worked when column E shows a score from 0 to 3 for each row. A blank question that needed an answer is E03. Anything other than yes or no is E04.
6. **CK-FR-01-6.** In columns G, H and I, write two sentences for each function in your own words. If you vanished, what would stop first and how many days until it hurt. Then one next step. Also pick a target score in column F, such as 3 for money and 2 for the rest.
   You'll know it worked when every row has text in G and a number in F. Keep the sentences plain. A first draft is fine.
7. **CK-FR-01-7.** Read the summary under the five rows. It shows the total out of 15, the band, the weakest function, the strongest, and a verdict line.
   You'll know it worked when the total is a number and the band is one of four phrases. If you see "answer all five," a function is still unanswered. If a summary or score cell is empty, a formula was deleted. That is E06 or E07. Copy it back from the template.
8. **CK-FR-01-8.** Choose Help, then Run check-up. Google asks you to authorize the program the first time. Click Continue, pick your account, click Advanced, then "Go to Continuity Check-Up", then Allow. The program only works on this one Sheet.
   You'll know it worked when a box opens with a [support code](../glossary.md#support-code) and a plain-text report. The code never includes your sentences. Keep it.

> **How to get help.** Write down the step ID where you got stuck (it looks like CK-FR-01-3). If your kit has a check-up button or command, run it and copy the support code it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
