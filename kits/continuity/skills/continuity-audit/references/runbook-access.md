# Access Runbook Template

Nobody loses the business because the one person who could log in is unreachable. This is the getting-back-in half of access. It adds the part a list of accounts leaves out, which is the recovery path (the steps for getting back into an account when the normal login fails) for each account that matters.

## Start with the list of what you own

Write down who owns what: the domain name registrar (where your web address is bought), the web host, the Google Business Profile, the social accounts and the analytics account. Each should be held in the business's name, with a recovery path noted. Make that list first if you have not. This page covers the recovery path for the accounts on it that would hurt to lose.

## Use a password manager, not this page

Never write a password on this page or in any shared document. A password manager (a program that keeps your logins behind one strong password) owned by the business is the right place. Record here only where it is and who can reach it in an emergency.

## Recovery paths for the accounts that matter

For each account you could not run the business without, write down how someone gets back in when the normal login fails. The password is not the hard part. The recovery path is.

Copy this block for each critical account, such as the bank, email, domain registrar (the company where your web address is bought), payment processor, Google Business Profile and the main operating tool.

## The email that everything resets through

Most recovery runs through one email address. If someone controls that inbox, they can reset almost everything. If it is lost, almost nothing else can be recovered. Treat it as the master key.

## The two-week test

Ask the person who would cover for you to get into one critical account using only what is written here, without calling you. If they cannot, the recovery path for that account is the next blank to fill.
