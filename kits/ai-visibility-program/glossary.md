# Glossary

Every technical term used in this kit, in plain words. Each page also links a term the first time it appears there. Terms the single-site kit defines the same way are repeated here so this kit stands alone.

**AEO.** <a id="aeo"></a>Answer engine optimization, the habit of making your brand easy for AI answers to find, cite and describe correctly.

**AI model.** <a id="ai-model"></a>A program such as ChatGPT, Claude, Gemini or Perplexity that answers questions in ordinary sentences.

**API.** <a id="api"></a>A way for one program to ask another for something, like a waiter carrying orders between you and the kitchen. AI companies offer one so your own script can ask their model a question.

**API key.** <a id="api-key"></a>A long secret password that tells an AI company's service which account to bill. Treat it like a company card number.

**Baseline.** <a id="baseline"></a>A site's first run in a series. It has nothing to compare with yet, so it makes no claim about trends.

**Bing Webmaster Tools.** <a id="bing-webmaster-tools"></a>Bing's free report on how a site appears in Bing search and which queries lead to it. Several AI products draw on Bing's index.

**Brand check.** <a id="brand-check"></a>The questions in group BV that are allowed to name your brand. They test whether an AI model can find and describe you once it has the name, and they stay out of the headline counts.

**Channel group.** <a id="channel-group"></a>Your own rule in GA4 for sorting visits into labeled buckets, such as "AI models".

**Citation.** <a id="citation"></a>A web address an AI answer lists as a source. Being cited means your site is one of them.

**Claude Code.** <a id="claude-code"></a>A program from Anthropic that runs on your computer and carries out multi-step tasks with your files.

**CMS.** <a id="cms"></a>Content management system, the software your team uses to publish and edit web pages.

**Control question.** <a id="control-question"></a>A question with no place named (group CT), used to see what an AI model says when it cannot know where you are.

**Cron.** <a id="cron"></a>The scheduler built into Mac and Linux computers. You give it a time and a command, and it runs the command at that time.

**Crowded out.** <a id="crowded-out"></a>An answer that names other businesses and leaves you out.

**CSV.** <a id="csv"></a>A plain table saved as text, with commas between the columns. Every spreadsheet program can open one.

**Dry run.** <a id="dry-run"></a>A practice run that checks keys, model names and question files and sends nothing.

**Environment variable.** <a id="environment-variable"></a>A setting stored on your computer outside any file you share, such as an API key. Programs read it by name.

**Frozen.** <a id="frozen"></a>A question set you no longer edit. Freezing is what keeps months comparable, because a change in the answers cannot be blamed on a change in the questions.

**GA4.** <a id="ga4"></a>Google Analytics 4, Google's website analytics. It counts visits and can sort them by where they came from.

**Ledger.** <a id="ledger"></a>The file `program-ledger.csv`, one row per run attempt per site, written whether the attempt worked or not. It is how the daily check knows what happened.

**llms.txt.** <a id="llmstxt"></a>An optional plain-text file at the top of a website that points AI products to the pages you most want them to read. No AI company has promised to honor it.

**Noise audit.** <a id="noise-audit"></a>A check on a scored run before anyone quotes it. It removes look-alike names from the counts, shows raw and clean numbers side by side, and measures how much one question varies on its own.

**Preflight.** <a id="preflight"></a>The same-name check you do before the first run, and again when you add a brand, product or competitor.

**Question set.** <a id="question-set"></a>The fixed list of 28 customer-style questions asked the same way every run, with a version label.

**robots.txt.** <a id="robotstxt"></a>A small file at the top of a website that tells crawlers which pages they may read.

**Same-name.** <a id="same-name"></a>Another business, person, place or everyday word that shares your name. If it is counted as you, the numbers are wrong.

**Script.** <a id="script"></a>A small program that does one job over and over. The runner and the comparison tool are scripts.

**Search Console.** <a id="search-console"></a>Google's free report on how a site appears in Google search and which queries lead to it.

**Series.** <a id="series"></a>A set of runs that used the same question set version and the same collection method. Only runs in the same series are compared.

**Slot.** <a id="slot"></a>The month a run is due, such as 2026-11. A site has either a good run for its slot or a miss.

**Support code.** <a id="support-code"></a>A short code the check-up prints. It tells a helper which step failed and holds none of your information.

**Step ID.** <a id="step-id"></a>The label at the start of every numbered step, such as AP-FU-03-2: kit AP, full version, guide three, step two.

**Terminal.** <a id="terminal"></a>A window where you type instructions to your computer instead of clicking.

**Web search.** <a id="web-search"></a>A feature that lets an AI model look things up on the internet while it answers. Some AI companies bill for it on top of the text.

**Webhook.** <a id="webhook"></a>A private web address that lets a script post a message into a chat channel. Anyone who has the address can post, so keep it secret.
