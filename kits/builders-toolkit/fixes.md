# Fixes

Find your code in the first column. Each guide names the code when a step goes wrong. A few terms recur below. A [command](glossary.md#command) is a line you type in the [terminal](glossary.md#terminal). Plugins ([plugin](glossary.md#plugin)) bundle [skills](glossary.md#skill) for [Claude Code](glossary.md#claude-code), and a [marketplace](glossary.md#marketplace) is the list they install from. Your project folder with tracked history is a [repository](glossary.md#repository), managed by [git](glossary.md#git). A [slot](glossary.md#slot) is one scheduled run time of a [scheduled job](glossary.md#scheduled-job), a [retry](glossary.md#retry) runs it again, and the [scheduler](glossary.md#scheduler) starts it. The [design gate](glossary.md#design-gate) checks a page in a browser using [Playwright](glossary.md#playwright), and its settings live in a [JSON](glossary.md#json) file and it measures your [development server](glossary.md#development-server), a copy of your site running on your own computer. [Python](glossary.md#python) runs the kit's programs, and [compaction](glossary.md#compaction) is the summary Claude Code makes of a long conversation. If your problem is not here, write to Pigasus Group at https://pigasus.group/contact with the [step ID](glossary.md#step-id) and your [support code](glossary.md#support-code). Setup questions are free.

| Code | What you see | Why | The fix | Step |
|---|---|---|---|---|
| E01 | "claude: command not found" | Claude Code is not installed, or the terminal was open before it was installed | Follow the shared install guide again, then close the terminal, open a new one and type `claude --version` | BT-FU-01-2 |
| E02 | "python3: command not found" | Python is not installed | Install Python 3 from python.org, then open a new terminal and retry | BT-FU-01-3 |
| E03 | git says it is not installed, or refuses to start | Git is missing, or this computer has never been told your name | Accept the offer to install git, then run `git config --global user.name "Your Name"` and `git config --global user.email "name@example.org"` with your own details | BT-FU-01-4 |
| E04 | "No such file or directory" when copying or reading `config.json` | The kit folder path was typed wrongly, or the file is in another folder | Find where you saved the kit, copy its real path, and retry. Run `ls` to see what the folder holds | BT-FU-01-5, BT-FU-02-5 |
| E05 | "marketplace not found", "invalid" or "plugin not found" | The repository address was copied incompletely, or the plugin name differs | Copy the address again from the repository's front page. Type `/plugin`, open the list and install the toolkit from there | BT-FU-02-2, BT-FU-02-3 |
| E06 | A skill is missing, or Claude Code answers without using it | The plugin needs a restart, or the request did not name the skill | Type `/exit`, start `claude` again, and say "use the capability-ledger skill" (or the one you need) by name | BT-FU-02-4, BT-FU-03-1, BT-FU-05-1 |
| E07 | The ledger checker says "missing header line" | The first lines of `CAPABILITIES.md` do not match the form | The line must read `Last verified against repo: 2026-11-13 by your name` with a real date, written year-month-day | BT-FU-03-2 |
| E08 | The checker says "proof path not found" | The proof column names a file that is not in the folder the checker is looking at | Fix the file name, or run the checker with `--root` pointing at the right folder | BT-FU-03-3 |
| E09 | The brief checker reports a missing header line or section | Purpose, Session, Compactions or the "Settled, never re-ask" heading is missing | Put the three header lines in the first few lines and keep the heading text exactly as the template has it | BT-FU-03-5, BT-FU-03-6 |
| E10 | The inventory finds 0 repositories | The projects folder setting points at the wrong place, or the folders are not git repositories | Set `projects_folder` in `config.json` to the folder that holds your projects, and check that each project has a `.git` folder | BT-FU-04-1 |
| E11 | "No module named playwright", or the browser is not found | The gate's packages or browser are not installed for the Python you are running | Run the two lines in BT-FU-04-3 again. Use the same `python3` for both | BT-FU-04-3 |
| E12 | The design gate exits with code 2 and prints "could not run" | Nothing was measured: no browser, an address that does not answer, or a bad config | Read the one line it prints before the exit. Start your development server, check the port, and check the JSON for a missing comma or quote | BT-FU-04-4 |
| E13 | The design gate exits with code 2 and says the marker did not match | The server on that port is showing a different copy of the site from the one you meant | Stop other development servers, start yours on a port you pick, run the gate with the same port, and rerun | BT-FU-04-5 |
| E14 | The runner says the registry is not found | You ran it from a folder without `jobs.json` | Move into the folder that holds `jobs.json`, or pass `--registry /full/path/jobs.json` | BT-FU-05-2 |
| E15 | A job hangs, then fails with "timed out" | The script waited for input, or took longer than `timeout_minutes` | Make the script run without prompts, or raise `timeout_minutes` in `jobs.json` | BT-FU-05-3 |
| E16 | The watcher reports missed slots for jobs that did run, or its log never grows | The schedule in `jobs.json` does not match when the job really runs, or the scheduler line has the wrong folder | Match the registry's time and weekday to the real schedule, and use full paths in the scheduler line | BT-FU-05-4, BT-FU-05-5 |
| E17 | A stuck slot is flagged in the file but no message arrives | The alert address is not set in the terminal that runs the watcher, or the chat tool rejected it | Set `JOB_ALERT_WEBHOOK` where the scheduler can see it. Cron does not read your login settings, so put the variable in the crontab. Test the address with the chat tool's own test button | BT-FU-05-6 |
