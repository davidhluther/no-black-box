# Choose Your Version

Every kit in this [repository](glossary.md#repository) comes in up to three versions. This one comes in one, and the table says why.

| | Free | Low cost | Full |
|---|---|---|---|
| What it is | Not planned for this kit | Not planned for this kit | The only version. [Skills](glossary.md#skill) for [Claude Code](glossary.md#claude-code), a few small programs written in [Python](glossary.md#python), and a browser check |
| Who it is for | People who do not build with Claude Code. Use the other kits instead | People who do not build with Claude Code. Use the other kits instead | People who run a website, a data job or an automation with Claude Code |

| Skills included | None | None | `capability-ledger`, `session-brief`, `scheduled-jobs`, `design-gate`, `workstream-inventory` |

## Why there is no free or low-cost edition

These skills exist for one situation, which is a person and an AI model that edit files, run programs and keep going across many sessions. The problems they solve (a conversation filling up, a scheduled run dying quietly, a page that looks wrong in a browser) only appear in that situation. A paste-in prompt in a chat window cannot check a browser, read a folder or write a log line on a schedule.

If you do not build with Claude Code, you are not missing anything here. The other kits cover grant tracking, board packets, treasurer books and plain writing, and each has a free version that runs on Google Sheets and free AI chat tools. Start there.

## What you can take without Claude Code

The two templates are plain text files. You can use them in any document and ignore the rest of the kit.

- The capability file template, `skills/capability-ledger/assets/CAPABILITIES.template.md`, works as a shared note in any editor.
- The [session brief](glossary.md#session-brief) template, `skills/session-brief/assets/BRIEF.template.md`, works the same way.

Neither needs the paid plan. You only lose the checkers and the automatic reading by Claude Code.

## Switching later

Nothing here locks you in. If you start with one skill and add the others later, each guide stands alone. If you stop using Claude Code, your ledger, briefs and outcome logs are ordinary text files and keep their value.
