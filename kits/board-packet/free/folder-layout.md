# Drive Folder Layout

Two separate trees. The shared one is for the board. The private one is for recordings and transcripts, and it sits outside the shared one on purpose.

```
Board Secretary Files            shared: the board members you name can view (or anyone with the link, if you choose)
  2027                           one folder per year
    2027 January                 one folder per month, made ahead of time
    2027 February
    ...
    2027 December
  Standing documents             optional: bylaws, board contact list, policies

Board Meeting Transcripts (private)     NOT shared: secretary and chair only
  Board meetings
  Committee meetings
```

## Why two trees

Anyone who holds the link to a shared folder can open everything inside it, including folders you add later. Transcripts carry unfiltered discussion about people, money, and clients. Keeping them in a separate, unshared tree means a forwarded packet link can never expose them.

## What goes in a month folder

Everything for that month's meeting.

- The agenda and each report, as the owner sent it.
- The prior meeting's minutes, for approval at this meeting. Minutes always go in the next month's folder, because that is the packet where the board approves them. The January meeting's minutes go in the February folder.
- The combined packet PDF (made in step 4 of the monthly checklist).
- Financial reports, if you share them by their own link instead of inside the combined packet.

## Naming

- Month folders use the pattern "year, space, month name", for example 2027 January. The [tracker sheet](../glossary.md#tracker-sheet) and the scripts look for this exact pattern, so do not improvise.
- Name each report so its filename holds the keyword in your Reports tab. A file named "Directors report January" is matched by the keyword "director".
