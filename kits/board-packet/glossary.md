# Glossary

Every technical term used in this kit, in plain words. Terms are listed alphabetically.

**AI model.** <a id="ai-model"></a>A computer program trained on huge amounts of writing so it can read, summarize, and draft text. ChatGPT, Claude, and Gemini are products that let you talk to an AI model. Think of a very fast assistant who has read a lot but sometimes gets facts wrong, so a person checks everything it writes.

**AI Project.** <a id="ai-project"></a>A saved workspace inside ChatGPT or Claude where you keep standing instructions and reference files, so every new chat starts already knowing how your board works. It is like a folder with a note on the front that says 'always do it this way'.

**Apps Script.** <a id="apps-script"></a>A free tool from Google that lets small programs run inside your Google Sheets, Docs, Drive, and Gmail. It is the same idea as a macro in Excel. You open it from the Extensions menu in a Google Sheet.

**Bcc.** <a id="bcc"></a>Short for blind carbon copy. People you put in Bcc receive the email, but nobody can see their addresses. A board email uses it so addresses stay private and nobody replies to everyone by accident.

**Check-up.** <a id="check-up"></a>The kit's built-in test, found under the Help menu of your tracker sheet. It looks at the shape of your setup and prints a support code. It never reads what you typed into cells.

**Claude Code.** <a id="claude-code"></a>A program from Anthropic that runs on your own computer and lets Claude, an AI model, read and change files in a folder you choose and run tools for you. The full version of this kit uses it.

**Command line.** <a id="command-line"></a>A way to run a computer by typing short instructions instead of clicking. The free and low-cost versions of this kit never need it. The full version needs it only to install a few programs once.

**Connector.** <a id="connector"></a>A permission you give an AI tool so it can reach one outside service, such as Google Drive or Gmail, and read or write there on your behalf. You can switch it off at any time.

**Digest.** <a id="digest"></a>A short, structured record of one meeting that keeps the numbers, deadlines, and promises the minutes leave out. It is a finding aid, and the transcript always wins if the two disagree.

**Drive for desktop.** <a id="drive-for-desktop"></a>A free app from Google that shows your Drive files as an ordinary folder on your computer and keeps the two in step.

**Google Workspace for Nonprofits.** <a id="google-workspace-for-nonprofits"></a>Google's program that gives eligible nonprofits Gmail with your own address, Drive, Docs, Sheets, and Meet at no charge. You apply through Google for Nonprofits and your organization must be verified first.

**JSON.** <a id="json"></a>A plain-text way of writing a list of settings so a program can read it. Your config file is written in it. You only ever change the words inside quotation marks.

**LibreOffice.** <a id="libreoffice"></a>A free office program. The full version of this kit uses it in the background to turn Word and Excel files into PDFs.

**Prompt.** <a id="prompt"></a>The instructions you type or paste into an AI model. A good prompt says what you want, what to use, and what not to do.

**pypdf.** <a id="pypdf"></a>A free add-on for the Python language that can merge and tidy PDF files. The full version's packet-pdf skill uses it.

**Skill.** <a id="skill"></a>A folder of written instructions, and sometimes small helper programs, that teaches an AI tool how to do one job the same way every time. The full version of this kit is a set of five.

**Support code.** <a id="support-code"></a>A short code such as BP-FR-02-2-E01-v0.1.0-7KQ that the check-up prints. It names the step where trouble starts, the problem, the kit version, and a check value, so someone helping you can see what is wrong without seeing your data.

**Terminal.** <a id="terminal"></a>The window where you type commands on your computer. On a Mac the app is called Terminal. Only the full version needs it.

**Tracker sheet.** <a id="tracker-sheet"></a>The one Google Sheet at the center of the free version. It lists your reports and contacts and holds your settings. The kit's check-up lives inside it.

**Transcript.** <a id="transcript"></a>A written, word-for-word record of what was said at a meeting, made from a recording.

**Whisper.** <a id="whisper"></a>A free, open-source program from OpenAI that turns spoken audio into written text on your own computer, without sending the recording anywhere.
