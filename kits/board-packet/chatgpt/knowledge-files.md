# Knowledge Files to Upload

Upload these files from the kit to your Project or Custom GPT as knowledge files. Both tools accept a limited number of files, and the kit needs only a handful.

| File in the kit | Why it helps |
|---|---|
| `free/minutes-style.md` | The house style for minutes. The instructions point to it. Edit your copy first. |
| `free/prompts.md` | The six prompts, so the model can follow the same method you do. |
| `overrides/meeting-digest/references/digest-format.md` | The exact [digest](../glossary.md#digest) headings and rules. |
| `free/email-template.md` | The board email layout. |
| `free/monthly-checklist.md` | The monthly cycle, so the model can tell you what comes next. |
| `config.example.json` | Your organization's details, after you fill in a copy and rename it `config.json`. Remove anything you would not want the model to see. |
| `glossary.md` | Plain definitions of every term in the kit. |
| `fixes.md` | The problem codes, so the model can explain a [support code](../glossary.md#support-code) you paste. |

Do not upload real transcripts as knowledge files. Paste a [transcript](../glossary.md#transcript) into a chat only when you are ready to use it, and delete the chat when the minutes are done if your tool allows it.
