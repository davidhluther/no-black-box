# Add Your Checklist, Email Template, and Prompts

This guide takes about 10 minutes. You will end with three Google Docs in a "Standing documents" folder. Each is a plain copy of a kit file, which you can then edit to fit your board.

Each step has an ID. If you get stuck, note the ID. Once the [check-up](../glossary.md#check-up) from guide BP-FR-04 is installed (the full version uses a command named `doctor` instead), it prints a [support code](../glossary.md#support-code) you can send along with the ID.

A Google Doc is Google's free word processor. Pasting kit text into one gives you a copy that belongs to you.

1. **BP-FR-03-1.** In Drive, open `Board Secretary Files` and make a folder inside it called `Standing documents`. Open it. Click **New**, then **Google Docs**, then **Blank document**. Click "Untitled document" at the top and type `Monthly board packet checklist`.
   You'll know it worked when you see a blank page with that title. If Docs will not open, check that your browser lets pop-ups from google.com (E26 covers sign-in trouble).

2. **BP-FR-03-2.** Open [monthly-checklist.md](../free/monthly-checklist.md) on GitHub, click the **Copy raw file** button (two overlapping squares, at the top right of the file), go back to your Doc, and paste with Ctrl+Shift+V (on a Mac, Command+Shift+V), which pastes without formatting.
   You'll know it worked when the checklist text fills the page. You will see the marks the file uses, such as `#` and `- [ ]`. That is fine. For a tidier Doc, select each group of items, then click **Format**, **Bullets & numbering**, **Checklist**, and delete the `- [ ]` marks.

3. **BP-FR-03-3.** Make a second Doc named `Board packet email template`. Paste [email-template.md](../free/email-template.md) into it the same way.
   You'll know it worked when you can read the template with its [square brackets] to fill in.

4. **BP-FR-03-4.** Make a third Doc named `Board packet prompts and style guide`. Paste [prompts.md](../free/prompts.md) into it, then add a page break (**Insert**, **Break**, **Page break**) and paste [minutes-style.md](../free/minutes-style.md) after it.
   You'll know it worked when both texts are in one Doc. Edit the style guide to match how your board likes its minutes written. You will paste it into [Prompt](../glossary.md#prompt) 2 each month.

5. **BP-FR-03-5.** Put the Doc links where you will find them. In the Settings tab of your [tracker sheet](../glossary.md#tracker-sheet), you can paste the link to the checklist into the Notes column of any row, or add a new row. Open the checklist Doc once a month.
   You'll know it worked when you can get from the tracker sheet to the checklist in one click.

> **How to get help.** Write down the step ID where you got stuck (it looks like BP-FR-03-2). If your kit has a check-up button or command, run it and copy the support code it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
