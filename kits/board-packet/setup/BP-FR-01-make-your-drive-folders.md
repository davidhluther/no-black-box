# Make Your Drive Folders

This guide takes about 10 minutes. You will end with two sets of folders in Google Drive: a shared set the board can open, and a private set for recordings and transcripts.

Each step has an ID. If you get stuck, note the ID. Once the [check-up](../glossary.md#check-up) from guide BP-FR-04 is installed (the full version uses a command named `doctor` instead), it prints a [support code](../glossary.md#support-code) you can send along with the ID.

You need a Google account for your organization. [Google Workspace for Nonprofits](../glossary.md#google-workspace-for-nonprofits) is free for eligible nonprofits and is the setup this kit assumes, but a free personal Google account works for every step in this guide too. If your nonprofit's application to Google is still waiting for approval, use a personal account for now and move the folders later.

You will need some of the kit's files from guide BP-FR-02 onward. You can download them now or when you get there. The shared guide [get the kit files](../../../guides/get-the-files.md) shows how to download them from https://github.com/davidhluther/no-black-box and unzip them on Windows, Mac or a Chromebook.

Folder names matter. The [tracker sheet](../glossary.md#tracker-sheet) and the check-up look for these exact names, so type them as shown, or type your own names and then use the same ones in the Settings tab in guide BP-FR-02.

1. **BP-FR-01-1.** Open Google Drive (Google's online file cabinet) at drive.google.com and sign in with your organization's account.
   You'll know it worked when you see "My Drive" on the left and a list of your files. If Google keeps sending you back to the sign-in page, it's E26.

2. **BP-FR-01-2.** Click the **New** button at the top left, choose **New folder**, type `Board Secretary Files`, and click **Create**.
   You'll know it worked when the folder appears in your list. If it is not there, refresh the page and look again.

3. **BP-FR-01-3.** Open that folder by double-clicking it. Make one new folder inside it named for the coming year, such as `2027`. Open that, then make twelve month folders, each named with the year, a space, and the month, like this: `2027 January`, `2027 February`, and so on through `2027 December`.
   You'll know it worked when you see twelve folders inside the year folder. If a name has a typo, right-click the folder, choose **Rename**, and fix it. A wrong name is the most common cause of E21.

4. **BP-FR-01-4.** Click **My Drive** at the top to go back to the main level. Do not be inside the shared folder. Click **New**, then **New folder**, and type `Board Meeting Transcripts (private)`. Open it and make two folders inside: `Board meetings` and `Committee meetings`.
   You'll know it worked when the private folder sits beside "Board Secretary Files" in My Drive, not inside it. If it ended up inside by mistake, drag it back out to My Drive. The check-up flags this as E18.

5. **BP-FR-01-5.** Share the packet folder with the board members by name. Right-click `Board Secretary Files` and choose **Share**. Leave **General access** on **Restricted**, which means only the people you list can open it. Under **Add people**, type each board member's email address (it must belong to a Google account), make sure the role beside it says **Viewer**, and click **Send**. Google emails each person a link.
   You'll know it worked when each board member's name appears in the list under "People with access". Everything inside the folder, including new year and month folders, is shared with them automatically. If a member can't open it, check that you typed the address they use to sign in to Google (E27).
   Optional, with the risk first: you can change **General access** to **Anyone with the link** (role **Viewer**). Then anyone who gets the link, including someone you never meant to share it with, can read every file in the folder, and you can't see who did. Choose it only if some board members can't or won't sign in with a Google account. If the choice is greyed out, your organization's Google administrator has switched it off (E27). The rest of the kit works either way.

6. **BP-FR-01-6.** Test the link the way a board member would. Click **Copy link** in the Share box, then open a private browser window (in Chrome, File > New Incognito Window; in Safari, File > New Private Window) and paste the link.
   You'll know it worked, if you kept Restricted, when Google asks you to sign in and the folder opens after you sign in with a board member's address (or says you need access if you sign in with another address). If you chose Anyone with the link, it worked when the folder opens without asking you to sign in. If it behaves differently, go back to step BP-FR-01-5 (E27).

7. **BP-FR-01-7.** Check the private folder is still private. Right-click `Board Meeting Transcripts (private)`, choose **Share**, and look under **General access**.
   You'll know it worked when it says **Restricted** and lists only you. If it shows anything else, change it to Restricted.

> **How to get help.** Write down the step ID where you got stuck (it looks like BP-FR-01-3). If your kit has a check-up button or command, run it and copy the support code it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
