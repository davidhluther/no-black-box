# Make Your AI Project

This guide takes about 15 minutes. It assumes you finished free setup (guides BP-FR-01, BP-FR-02, and BP-FR-04). You will end with an [AI Project](../glossary.md#ai-project), a saved workspace in ChatGPT or Claude that already knows your board's rules, so you stop pasting the style guide and prompts every month.

Each step has an ID. If you get stuck, note the ID. Once the [check-up](../glossary.md#check-up) from guide BP-FR-04 is installed (the full version uses a command named `doctor` instead), it prints a [support code](../glossary.md#support-code) you can send along with the ID.

The low-cost version is "one roughly $20 a month AI plan plus Google [Apps Script](../glossary.md#apps-script)". Claude Pro is $20 a month billed monthly (claude.com/pricing, checked 11/13/2026). ChatGPT Plus is $20 a month (OpenAI's help center, checked 11/13/2026). Both companies also list Projects on their free plans (checked 11/13/2026), so you can start without paying. A paid plan mostly buys higher usage limits, which matters when you paste a long [transcript](../glossary.md#transcript). See each company's pricing page for the current limits. Some AI companies offer nonprofit pricing. This kit has not verified any, so ask before you pay full price.

Pick one tool. Everything below works the same in either.

1. **BP-LC-01-1.** Sign in to chatgpt.com or claude.ai. In ChatGPT, find **Projects** in the left menu and choose **New project**. In Claude, choose **Projects**, then **Create project**. Name it `Board packet`.
   You'll know it worked when you see an empty project page with a box for instructions and a place for files. If you cannot find Projects, look at the plan comparison on the company's pricing page (E45).

2. **BP-LC-01-2.** Open [chatgpt/instructions.md](../chatgpt/instructions.md) on GitHub and click **Copy raw file**. Paste everything between the two lines into the project's instructions box. Replace each word in [square brackets] with your own details. Save.
   You'll know it worked when the instructions show your organization's name and the chair's and secretary's names. If the box says the text is too long, you pasted the lines around it too. Paste only the part between the lines.

3. **BP-LC-01-3.** Add the knowledge files. Download the files listed in [knowledge-files.md](../chatgpt/knowledge-files.md) from GitHub (Download raw file) and upload them to the project's files area.
   You'll know it worked when all the listed files show in the project. If an upload is refused, remove the largest and carry on without it. The instructions already carry the key rules.

4. **BP-LC-01-4.** Test it with the practice meeting. Open [sample-transcript.md](../free/sample-transcript.md), copy the transcript block, and start a chat in your project. Type: "Pull notes from this part of a transcript. Attendance is Alex Rivera (Chair), Pat Morgan, Robin Shah, Chris Lowell, Dana Whitfield, Lee Park. Staff are Sam Okafor and Casey Martin." Then paste the transcript.
   You'll know it worked when the notes show the corrected playground grant amount and a freezer motion that carried five to one with Chris voting no. If the model says the vote was unanimous or makes up a name, tell it to re-read the transcript, and see E42.

> **How to get help.** Write down the step ID where you got stuck (it looks like BP-LC-01-3). If your kit has a check-up button or command, run it and copy the support code it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
