# Glossary

Every technical term used in this kit, in plain words. Terms that only the shared guides use are in the [repository glossary](../../guides/glossary.md).

**AI visibility platform.** A paid service that asks AI models a fixed set of questions on a schedule and records whether your brand is named or cited.

**API.** A way for two programs to talk, like a waiter carrying orders between you and the kitchen. Most SEO and analytics platforms let a script pull data through one.

**API key.** A long password that lets a program use a service on your account's behalf. Treat it like a bank password.

**Bing Webmaster Tools.** Microsoft's free report of how your site appears in Bing search, the second independent source for search direction.

**Capability ledger.** One file per workstream that lists what the workstream can do right now and what proves it, like an inventory sheet for abilities.

**Capture point.** The single script that pulls one paid or limited data source and saves the result. Everything else reads the saved file.

**Check-up.** The command `python3 support/doctor.py team-operations`. It tests the basics of your setup and prints one support code.

**Claude Code.** A program from Anthropic that you type to in a terminal. It reads your project's files, runs commands and edits things for you.

**Clarity.** Microsoft Clarity, a free tool that records how visitors behave on a site and labels AI-assistant referrals.

**CMS.** Content management system, the program your team publishes pages through.

**Commit.** One saved snapshot of a repository, with a short note on what changed.

**Compaction.** What Claude Code does when a conversation gets too long. It replaces the earlier conversation with a shorter summary so the work can continue. Details can be lost in the summary.

**Context window.** The amount of text an AI model can hold in mind at one time, like the size of a desk. When the desk is full, something has to go.

**CRM.** Customer relationship management system, where leads and opportunities live.

**Cron.** The scheduler built into Mac and Linux computers. A crontab is its list of jobs and times.

**Design gate.** A check you run before shipping a website change. A script lays the changed pages out in a real browser, and a reviewer who did not build them judges the rest.

**Environment variable.** A named setting that lives in your computer's session rather than in a file you share, such as an alert address.

**GA4.** Google Analytics 4, Google's analytics tool for visits, events and conversions.

**Git.** The free program that tracks the history of a repository.

**Handoff.** Passing unfinished work to a fresh session, with a brief that tells it everything it needs.

**JSON.** A plain text format for settings, written as names and values inside curly braces.

**Looker Studio.** Google's free dashboard tool, often used to show leaders GA4 and Search Console numbers.

**Marketplace.** A list of plugins that Claude Code can install from, like an app store with a single shelf.

**Outcome row.** One line in a log that says how a scheduled run ended: it worked, it found nothing, or it failed and why.

**Plugin.** A bundle of skills that installs in one step.

**Python.** The programming language the kit's small programs are written in.

**Quota.** A limit a vendor sets on how many requests or units of data you may use in a period.

**Registry.** The file (`jobs.json`) that lists every scheduled job: its command, schedule, grace period, timeout and whether it is safe to repeat.

**Repository.** A project folder whose history of changes is tracked. People often say "repo."

**Retry.** Running a failed or missed job again, for the same slot.

**Routing table.** A short file that says "when the work is about X, go to folder Y," so a session knows where to start.

**Scheduled job.** A script that runs by itself at set times, such as every Sunday at 10 p.m.

**Scheduler.** The part of a computer or hosting service that starts scheduled jobs at their times.

**Search Console.** Google's free report of how your site appears in Google search.

**Session.** One continuous conversation with Claude Code about one task, from start to handoff.

**Session brief.** A short file that holds a session's purpose, settled decisions and next step, so none of it depends on the chat.

**Single-source.** A figure confirmed on only one platform. The metric check labels it as such and does not let it carry a cause.

**Skill.** A folder of instructions (and sometimes small programs) that teaches Claude Code one job, like a recipe card it pulls out when the job comes up.

**Slot.** One scheduled run time of a scheduled job. "Sunday at 10 p.m." is a slot, and a job that skips it has missed the slot.

**Step ID.** The printed code at the start of every numbered step, such as TO-FU-02-3.

**Support code.** The one-line code the check-up prints, which tells a helper which step failed and why.

**Terminal.** A window where you type lines of instruction instead of clicking. On a Mac it is the Terminal app, and on Windows it is PowerShell.

**Webhook.** A web address that accepts a message from a program, such as a chat channel's incoming-message address.

**Workstream.** One body of recurring work with its own owner, repository and data, such as "organic reporting for the US site" or "AI visibility tracking."
