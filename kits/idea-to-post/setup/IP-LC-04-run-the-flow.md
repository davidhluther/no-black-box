# IP-LC-04: Run a Post From Idea to Live

You will take one idea all the way through using your [Project](../glossary.md#project) and the kit's [skills](../glossary.md#skill), with the Sheet as your tracker. This is the weekly rhythm. The first run takes an afternoon; later runs go faster.

1. **IP-LC-04-1.** Choose one Screened idea from the [Queue](../glossary.md#queue) and ask the [AI model](../glossary.md#ai-model) to run seo-research and then content-brief for it. Give it the idea, your [sitemap](../glossary.md#sitemap)'s list of posts, and the real search rows from the SearchData tab.
   You'll know it worked when you get a brief with a verdict and eight or more statistics with sources. Open every source yourself. A source you cannot open comes out of the brief; this is E08.

2. **IP-LC-04-2.** Save the brief as a Google Doc in your briefs folder, paste its link into the Queue row, and set the stage to Planned. Ask the AI model to run the brief-layer skill over the brief and fix what it finds.
   You'll know it worked when brief-layer reports the target search, the title direction, question headings, and the link map all present.

3. **IP-LC-04-3.** Ask for the draft with seo-draft. Copy it into a Google Doc, add the Draft check menu from guide IP-FR-04, and run it.
   You'll know it worked when the draft check shows no banned words and no long paragraphs.

4. **IP-LC-04-4.** Ask the AI model to run article-check, tell-scorer, and copy-lint on the draft, or use [prompts](../glossary.md#prompt) 9 through 11. Apply the fixes you agree with. Open every source yet again for any number the checks flag.
   You'll know it worked when the checks come back clean or only list items you have decided to keep. Set the stage to Review.

5. **IP-LC-04-5.** Ask for images with hero-image, infographic-brief, and visual-assets. In the low-cost version these produce a designer brief and [alt text](../glossary.md#alt-text); you make or find the picture.
   You'll know it worked when each image has alt text, a caption, and a source line if it shows figures. Garbled words inside an image are E18.

6. **IP-LC-04-6.** Ask for the package with linkedin-content, cta-inject, and docx-export. Open the Word file to see the single package (post, shares, image briefs, brief).
   You'll know it worked when the file opens and holds every part. Set the stage to Ready to publish.

7. **IP-LC-04-7.** Publish by hand in your website editor, exactly as in guide IP-FR-05. Record the live address and date, set the stage to Live, and request [indexing](../glossary.md#indexing) in [Search Console](../glossary.md#search-console).
   You'll know it worked when the live page matches your preview.

8. **IP-LC-04-8.** At two, six, and 12 weeks, run gsc-read-style review with prompt 17 against the SearchData tab, record the numbers on the Measure tab, and decide on a [refresh](../glossary.md#refresh) with prompt 18.
   You'll know it worked when each checkpoint has a row on the Measure tab.

If a step here fails, go to the [fixes table](../fixes.md).
