# IP-FR-05: Images, Packaging, and Publishing

You will make or choose an image, write the shares, add a [call to action](../glossary.md#call-to-action), and put the post live yourself. A person always makes the final click. Allow about 90 minutes.

1. **IP-FR-05-1.** Run [prompt](../glossary.md#prompt) 12 for banner ideas and alt text (a description of an image that screen readers say aloud). Pick one idea.
   You'll know it worked when you have a short description, an image prompt, and alt text for one idea.

2. **IP-FR-05-2.** Make or find the image. Use your own photo, a free image library, or a free image generator, and keep words and numbers out of the picture because generators spell badly. Save it in your images folder.
   You'll know it worked when the file is in your images folder. If the image contains garbled words, it's E18.

3. **IP-FR-05-3.** If the post has real figures, run prompt 13 to plan a simple infographic (a picture that explains a few facts). Build it in a free design tool, or hand the brief to a designer.
   You'll know it worked when each fact in the infographic matches the post and has a source line.

4. **IP-FR-05-4.** Run prompt 15 and add the two calls to action it suggests. Use the same one action your Setup tab names.
   You'll know it worked when one call to action sits after the second or third section and one at the end.

5. **IP-FR-05-5.** Run prompt 16 to produce the title, summary, web address ending (the [slug](../glossary.md#slug)), and alt text to paste into your website editor.
   You'll know it worked when the page title is under 60 characters and the summary under 155.

6. **IP-FR-05-6.** Log into your website editor. Create a new post and paste in the text, image, alt text, and links. Save it as a draft, not published. Use the preview.
   You'll know it worked when you can open a preview link.

7. **IP-FR-05-7.** Open the preview on your phone and on a computer. Click every link. Check that images show and the headings look right.
   You'll know it worked when nothing is broken. Fix anything that is.

8. **IP-FR-05-8.** Press publish yourself. Then open the live page in a private browser window to see what a stranger sees.
   You'll know it worked when the live page matches the preview.

9. **IP-FR-05-9.** Record the live web address and date in the [Queue](../glossary.md#queue) row and set the stage to Live. In [Search Console](../glossary.md#search-console), paste the address into the inspection bar at the top and choose Request indexing (asking Google to add the page to its catalog).
   You'll know it worked when Search Console confirms the request. If the page still does not appear in search after several weeks, it's E21.

10. **IP-FR-05-10.** Run prompt 14 for LinkedIn posts. Edit them so they sound like you, add the live link, and post them yourself.
    You'll know it worked when each post names a specific detail from the article and links to it.
