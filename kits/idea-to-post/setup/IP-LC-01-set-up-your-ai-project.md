# IP-LC-01: Set Up Your AI Project

The low-cost version adds one paid AI plan so your rules and files stay in place and you stop pasting them into every chat. You will keep the Google Sheet from the free version. Allow about an hour. Menu names in AI products change often, so where a step names a menu, the vendor's own help page is the final word.

1. **IP-LC-01-1.** Finish guide [IP-FR-01](IP-FR-01-make-your-workspace.md) first, so you have the Sheet, the folders, and a passing [check-up](../glossary.md#check-up). Then change the version row on the Setup tab from FR to LC.
   You'll know it worked when the Sheet's check-up (Help, then Run check-up) shows a code beginning IP-LC. If it does not, see E04.

2. **IP-LC-01-2.** Choose one AI product for the paid plan: Claude, ChatGPT, or Gemini. Do not pay for two. Review the price on the vendor's pricing page and the account steps in the [keys and accounts guide](../../../guides/keys-and-accounts.md). Claude Pro is $20 a month when billed monthly (checked 11/13/2026).
   You'll know it worked when you can sign in and the plan shows as active on your account page.

3. **IP-LC-01-3.** Make a Project (a workspace that stores instructions and files for every chat inside it) in Claude or ChatGPT, or a Custom GPT (a version of ChatGPT you set up once with your own instructions and files) in ChatGPT. Name it "Idea to Live Post".
   You'll know it worked when the new Project or GPT opens with empty instruction and file areas.

4. **IP-LC-01-4.** Open [chatgpt/instructions.md](../chatgpt/instructions.md), copy the text, fill in the bracketed parts about your organization, and paste it into the Project's or Custom GPT's instructions area.
   You'll know it worked when the instructions save without a warning. If the product says the text is too long or cuts it off, it's E23.

5. **IP-LC-01-5.** Upload the files listed in [chatgpt/knowledge-files.md](../chatgpt/knowledge-files.md) as knowledge files (documents the [AI model](../glossary.md#ai-model) can read every time). Include your own style guide Doc.
   You'll know it worked when each file shows in the Project's file list. If a file fails to upload, it's E12.

6. **IP-LC-01-6.** (Claude only.) To use the kit's [skills](../glossary.md#skill), zip each skill folder from the kit's skills folder (the zip's folder name must match the skill name, for example topic-screen) and upload it in your Claude account's skills area. Code execution must be turned on in your account settings for skills that run scripts.
   You'll know it worked when each skill appears in the skills list as enabled. If an upload is rejected or the skill does not appear, it's E22.

7. **IP-LC-01-7.** Test it. Start a chat in the Project and type "What is our organization, who are our readers, and what do we want readers to do?"
   You'll know it worked when the answer matches your instructions. If it answers generically or forgets your rules, it's E07.

Next, [IP-LC-02, automate ideas and the queue](IP-LC-02-automate-ideas-and-queue.md).

If your kit has a check-up button or command, run it and copy the [support code](../glossary.md#support-code) it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
