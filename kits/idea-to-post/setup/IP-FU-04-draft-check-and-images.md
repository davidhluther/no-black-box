# IP-FU-04: Draft, Check, and Images

You will draft from the brief, run the quality checks by command, and make the image briefs and the package. A person reads the final draft. Allow about two hours.

1. **IP-FU-04-1.** Say to [Claude Code](../glossary.md#claude-code): "Run draft-queue for <title>." It checks the brief, drafts with seo-draft, and sets the [Queue](../glossary.md#queue) stage. It never publishes.
   You'll know it worked when a draft_<keyword-slug>.md file appears in the drafts folder. If it stops with needs input, read the note it wrote and fix that one thing.

2. **IP-FU-04-2.** Run the quality checks: "Run article-check, tell-scorer, and copy-lint on the draft." Read each result.
   You'll know it worked when each check reports its findings by line. Fix errors; read warnings and decide.

3. **IP-FU-04-3.** Open every source behind every number in the draft and confirm it. Ask: "List every number in the draft with its source sentence."
   You'll know it worked when each number is tied to a source you opened or has been cut (E08).

4. **IP-FU-04-4.** Ask a person who did not write it to read the draft top to bottom.
   You'll know it worked when they can say what the post helps them do.

5. **IP-FU-04-5.** Say: "Run hero-image, infographic-brief, and visual-assets for this draft." If you have no image service, you get a designer brief and [alt text](../glossary.md#alt-text).
   You'll know it worked when each image has alt text, a caption, and a source line. Garbled text inside an image is E18.

6. **IP-FU-04-6.** Say: "Run cta-inject, linkedin-content, and docx-export." Open the Word file to see the full package.
   You'll know it worked when the file opens and holds the post, the shares, the image briefs, and the brief.

7. **IP-FU-04-7.** Set the Queue stage to Ready to publish.
   You'll know it worked when the Queue row reads Ready to publish.
