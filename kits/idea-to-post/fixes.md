# Fixes

Find the code the [check-up](glossary.md#check-up) printed, or match what you see. Each row says what is going on, why, and what to do. [Step IDs](glossary.md#step-id) look like IP-FR-01-3: kit, version, guide, step.

| Code | What you see | Why | The fix | Step |
|---|---|---|---|---|
| E01 | Google keeps sending you back to the sign-in page, or you cannot make a file or folder | A work or school account is blocking it, or you are signed in to two accounts at once | Open a private browser window, sign in with one account, and try again. If it is a work account, ask whoever runs it to allow new files. | IP-FR-01-1, IP-FR-01-2 |
| E02 | The check-up says a tab is missing or renamed | A tab was not imported, or its name has a typo or an extra space | Add the tab and name it exactly Ideas, [Queue](glossary.md#queue), Measure, or Setup, with a capital first letter and no spaces. | IP-FR-01-3 |
| E03 | The check-up says a header is missing | Row 1 was edited or deleted along with the example row | Copy the header row from the matching [CSV](glossary.md#csv) file in the free folder into row 1 of that tab. | IP-FR-01-4 |
| E04 | The check-up says a Setup value is empty, or site_url should start with https:// | A required row on the Setup tab was left blank | Fill the value column for org_name, audience, voice_notes, site_url, blog_path, and one_call_to_action. Start the site address with https://. | IP-FR-01-5 |
| E05 | No Help menu appears | The script was not saved, the page was not reloaded, or the code has an error | Open Extensions, [Apps Script](glossary.md#apps-script), and confirm the code is pasted and saved. Reload the sheet and wait ten seconds. | IP-FR-01-6 |
| E06 | Google says "this app isn't verified" when you allow the script | You wrote the script into your own sheet, and Google warns about any script it has not reviewed | Click Advanced, then the link at the bottom to continue to your script, then Allow. Only do this for scripts you pasted yourself. | IP-FR-01-7 |
| E07 | The [AI model](glossary.md#ai-model) answers generically or forgets your rules | The context block was not pasted, or the chat got long and the start scrolled out of view | Start a new chat and paste [prompt](glossary.md#prompt) 0 first. In a [Project](glossary.md#project) or [Custom GPT](glossary.md#custom-gpt), check the instructions saved. | IP-FR-02-1 |
| E08 | A statistic, study, or quote cannot be found at its source | AI models sometimes write convincing numbers and sources that do not exist | Open the source yourself. If you cannot find the number there, cut it. Never publish a figure you could not trace. | IP-FR-03-7, IP-FR-04-6 |
| E09 | A [feed](glossary.md#feed) returns nothing, an error, or FAILED in the Log tab | The feed address is wrong, the site blocks automated readers, or the site is down | Open the address in your browser. If you see a page of code, it works; if not, find the right feed address or drop the source. | IP-FR-02-3, IP-LC-02-4, IP-FU-03-1 |
| E10 | [Search Console](glossary.md#search-console) shows no data, or will not verify your site | Verification is not finished, the property name is wrong, or the site is new | Finish verification. Copy the property name exactly. A new property needs days before data shows. | IP-FR-03-1, IP-LC-03-1, IP-FU-02-2 |
| E11 | The search data pull fails with a permission or "[API](glossary.md#api) not enabled" message | The script lacks permission for Search Console, or the Google project behind the script has not turned the Search Console service on | Re-check the five permission lines in the manifest (guide IP-LC-03, step 3). If it still fails, switch the script to a Google Cloud project you control and enable the Search Console service there. Or skip the script and use Search Console's own export. | IP-LC-03-5 |
| E12 | The chat says your message is too long, or a file will not upload | Free plans limit how much you can paste at once | Send the material in two or three parts, or trim to the part the prompt needs. | IP-FR-02-7, IP-LC-01-5 |
| E13 | No Draft check menu in your Google Doc | The script is not saved in that Doc, or the Doc was not reloaded | Open Extensions, Apps Script in that Doc, paste the script, save, and reload. | IP-FR-04-3 |
| E14 | The [command line](glossary.md#command-line) says "command not found" | [Python](glossary.md#python) or [Claude Code](glossary.md#claude-code) is not installed, or the window was open during installation | Close the command window, open a new one, and try again. If it still fails, repeat the install steps. | IP-FU-01-1, IP-FU-01-2, IP-FU-01-8 |
| E15 | A [skill](glossary.md#skill) is missing or does not respond after install | The [plugin](glossary.md#plugin) did not install, or you started Claude Code before installing | Run the install lines again, restart Claude Code, and ask it to list its skills. | IP-FU-01-4 |
| E16 | A message about config.[json](glossary.md#json) missing, unreadable, or a key not found | The file was not copied, has a typo, or has a missing comma or quote | Copy config.example.json again and re-enter your values. Check commas and quote marks. Keys never go in this file. | IP-FU-01-5, IP-FU-02-4, IP-FU-05-1 |
| E17 | The topic screen says INCOMPLETE sources | A [sitemap](glossary.md#sitemap), queue file, or briefs folder was not configured, or could not be read | Set the missing path in config.json. A source that did not run is never a clean result. | IP-FU-03-3 |
| E18 | An image has garbled or misspelled words | Image generators cannot spell reliably | Remove all words and numbers from the image and put them in the page text and the caption. | IP-FR-05-2, IP-LC-04-5, IP-FU-04-5 |
| E19 | The publish practice run stops and names a missing field | A title, [slug](glossary.md#slug), summary, or image description is missing | Add the field named in the message and run the practice again. | IP-FU-05-2 |
| E20 | The Log has no new row on a day it should have one | The schedule was removed, the script lost permission, or the computer was asleep | Run the fetch or pull by hand, then set up the schedule again. Check the Log every Monday. | IP-LC-02-5, IP-LC-03-6, IP-FU-05-7 |
| E21 | The live post does not show in search results after weeks | The page was not indexed, is blocked, or has no links pointing to it | In Search Console, inspect the address and read the reason it gives. Add links to the post from two or more of your own pages, and request [indexing](glossary.md#indexing) again. | IP-FR-05-9, IP-FU-05-4 |
| E22 | A skill upload is rejected, or the skill does not show as enabled | The folder name does not match the skill name, or code execution is off | Rename the zip's folder to the skill's name, turn on code execution in your account settings, and upload again. | IP-LC-01-6 |
| E23 | Your instructions were cut off in a Custom GPT or Project | The text is longer than the product allows | Use the shorter instructions file, and put the rest in a [knowledge file](glossary.md#knowledge-file). | IP-LC-01-4 |
| E24 | The brief check says BRIEF PARTIAL | The brief is missing a required section or has too few words | Re-run content-brief for that post. Never edit a brief by hand to pass the check. | IP-FU-03-6 |

## When none of these fit

Write down the [step ID](glossary.md#step-id) where you got stuck and the [support code](glossary.md#support-code) from the check-up. Then send both to Pigasus Group through the [contact page](https://pigasus.group/contact). Setup questions are free. New problems get added to this table so the next person does not hit them.
