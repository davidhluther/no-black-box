# Choose Your Version

All three versions run the same ten-step flow. They differ in how much the tools do for you and how much you do by hand. Pick the lightest one that works, and move up only when the work gets heavy.

## Side by side

| | Free | Low cost | Full |
|---|---|---|---|
| Code | FR | LC | FU |
| What you need | A Google account and a free AI model (ChatGPT, Claude, or Gemini) | The free version plus one paid AI plan | Claude Code (a program that runs on your computer) and the low-cost setup |
| Cost | $0 for this kit's own files and scripts; see each vendor's page for current free-plan limits | One paid AI plan, for example Claude Pro at $20 a month when billed monthly (checked 11/13/2026); see the vendor's pricing page for the current price | Everything in low cost, plus any paid search tool or image service you choose |
| Ideas | You paste news items into a [prompt](glossary.md#prompt); Google Sheets can pull [feeds](glossary.md#feed) with a built-in formula | A script in your Google Sheet pulls feeds into the Ideas tab every Monday | A program fetches feeds and writes a dated, source-checked note |
| Screening | A prompt compares lists | Same, with your [Queue](glossary.md#queue) tab exported to a file | A script checks your [sitemap](glossary.md#sitemap), queue, and briefs |
| Briefs and drafts | Prompts, one chat per step | [Skills](glossary.md#skill) or a [Project](glossary.md#project) hold your rules, so you do not paste them each time | The same skills run in Claude Code with files read for you |
| Quality checks | A draft-check menu in Google Docs plus a prompt | The same, plus the article-check skill | [Validators](glossary.md#validator) run by command and score every post |
| Images | A prompt writes the brief and the [alt text](glossary.md#alt-text) | The same | Images made through a service you connect, with a brief as backup |
| Publishing | You paste into your website editor | You paste, with a packaged file ready | A publish step with a practice run and a human confirmation |
| Measuring | Export from [Search Console](glossary.md#search-console), paste into a prompt | A script pulls Search Console into your sheet | Scheduled pulls, plus AI-traffic and behavior reports |
| Time to set up | About an hour | An afternoon | A day, and some typing in a command window |
| Best for | One person, a post or two a month | Several posts a month, or a few people sharing | A team publishing steadily, or anyone who wants checks run automatically |

Claude Code, the paid plans, and any paid search tool are optional. Everything in the free column is complete on its own.

## What you give up in the free version

Depth, not honesty. The free version has no automatic check of your sitemap, no automatic data pulls, and no scoring across many posts. You do those by hand with the checklist. The method is the same.

## How to switch later

Your files do not change between versions. The Google Sheet from the free version is the Sheet the low-cost scripts write into. The briefs and drafts you saved are the same files the full version reads. To move up, follow the first guide of the next version and keep working. To move down, stop using the extras; nothing breaks.

## Room to choose

- **Your AI model.** Any of the free AI models works. Pick the one you already have an account with.
- **Your measuring tools.** Search Console is the core. [Bing Webmaster Tools](glossary.md#bing-webmaster-tools), Google Analytics, and [Microsoft Clarity](glossary.md#microsoft-clarity) add other views, and each can be skipped at first.
- **Your publishing step.** A simple site is fine with a paste into the editor. A larger site can use the publish step in the full version.
- **Your pace.** Each stage can run on its own schedule. Many small organizations do ideas monthly and drafts weekly.
