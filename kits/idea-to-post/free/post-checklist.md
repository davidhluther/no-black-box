# Post Checklist, Idea to Live to Measured

Copy this page into a Google Doc, one copy per post. Tick each box as you finish it. The post's row in your [Queue](../glossary.md#queue) tab should always show the stage of the last box you ticked.

**Main search**
**Owner**
**Queue row number**

## 1. Idea

- [ ] The idea is on the Ideas tab with its source link
- [ ] I opened the original source and read it (a newsletter's summary does not count)
- [ ] I gave it a trust rating: A, B, C, or D (never use D)
- [ ] I wrote one line on why our readers care

## 2. Screened

- [ ] Compared against every existing and planned post ([prompt](../glossary.md#prompt) 2)
- [ ] Monthly search number found, or a written reason to do it anyway
- [ ] Moved to "Screened" in the Queue tab, or dropped with a note

## 3. Briefed

- [ ] Search facts gathered (prompt 4)
- [ ] Brief written (prompt 6) and structure checked (prompt 7)
- [ ] Each statistic has a named source I opened
- [ ] Brief saved in the briefs folder and linked in the Queue tab
- [ ] Stage set to "Planned"

## 4. Drafted

- [ ] Draft written from the brief (prompt 8)
- [ ] Stage set to "In production"

## 5. Checked

- [ ] Draft check menu run in the Google Doc (see guide IP-FR-04)
- [ ] Plain-language check done (prompt 9) and fixes applied (prompt 10)
- [ ] Fact check done (prompt 11) and every source opened
- [ ] One person who did not write it read it start to finish
- [ ] Stage set to "Review"

## 6. Images

- [ ] Banner image chosen, with [alt text](../glossary.md#alt-text)
- [ ] [Infographic](../glossary.md#infographic) or chart, if the post has real figures, with caption and source
- [ ] No words or numbers baked into images

## 7. Packaged

- [ ] Social posts written (prompt 14)
- [ ] [Call to action](../glossary.md#call-to-action) added once mid-post and once at the end (prompt 15)
- [ ] Publishing details written (prompt 16)
- [ ] Stage set to "Ready to publish"

## 8. Live

- [ ] A person (not an [AI model](../glossary.md#ai-model)) pressed publish
- [ ] The live page opened and checked on a phone
- [ ] Every link on the live page works
- [ ] Live address and date recorded in the Queue tab
- [ ] Stage set to "Live"
- [ ] Address submitted for [indexing](../glossary.md#indexing) in [Search Console](../glossary.md#search-console)

## 9. Measured

- [ ] Week 2 checkpoint added to the Measure tab
- [ ] Week 6 checkpoint added
- [ ] Week 12 checkpoint added
- [ ] Decision recorded: leave, [refresh](../glossary.md#refresh), or merge (prompt 18)
- [ ] If refreshed, the date changed only alongside a real change
