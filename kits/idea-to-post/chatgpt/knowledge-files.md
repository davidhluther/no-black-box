# Knowledge Files to Upload

Upload these files to your [Custom GPT](../glossary.md#custom-gpt) or [Project](../glossary.md#project) as knowledge files (documents the [AI model](../glossary.md#ai-model) can read every time). ChatGPT accepts up to 20 files per GPT, according to OpenAI's own figures; check OpenAI's current help page for today's limit.

| File | Why it is there |
|---|---|
| free/prompts.md | The paste-in [prompt](../glossary.md#prompt) for each stage |
| free/post-checklist.md | The stage-by-stage checklist |
| glossary.md | Plain definitions for every technical term |
| fixes.md | Problem codes and their fixes |
| config.example.json | The settings shape (upload your filled-in copy instead, with no keys) |
| [skills](../glossary.md#skill)/content-brief/reference/brief-template.md | The ten-heading brief shape |
| skills/seo-draft/SKILL.md | The drafting rules in full |
| skills/brief-layer/SKILL.md | The structure rules for briefs |
| skills/topic-screen/SKILL.md | The screening method |
| skills/industry-intel/SKILL.md | How to grade and read ideas |
| Your own style guide | Your voice and banned words |
| Your existing post list | One title per line, so the screen can compare |

Do not upload passwords, keys, or anything private about your clients, donors, or members.

If the instructions get cut off in the instructions box, use the shorter wording in instructions.md and move the detail into the knowledge files; this is E23 in the [fixes table](../fixes.md).
