# Glossary

Every technical term used in this kit, in plain words. Each page of the kit links the first use of a term here.

**AI model.** A computer program trained on huge amounts of text that can write, summarize, and answer questions. ChatGPT, Claude, and Gemini are products built on AI models. <a id="ai-model"></a>

**Alt text.** A short description of an image that a screen reader says aloud for people who cannot see it, and that shows if the image fails to load. Like a caption written for the ears. <a id="alt-text"></a>

**Anchor text.** The clickable words of a link. "Our open hours" is better anchor text than "click here". <a id="anchor-text"></a>

**API.** A way for two programs to talk to each other, like a waiter carrying orders between you and the kitchen. <a id="api"></a>

**API key.** A long secret password that proves a program is allowed to use a service. Treat it like a house key and never paste it into a shared document or screenshot. <a id="api-key"></a>

**Apps Script.** Google's free tool for adding small programs to Google Sheets and Docs, such as a menu button that fetches news items for you. <a id="apps-script"></a>

**Average position.** Where your page usually appears in search results. Position 1 is the top of the first page; position 11 or lower means page two or beyond. <a id="average-position"></a>

**Bing Webmaster Tools.** Microsoft's free service that shows how your site performs in Bing search, the way Search Console does for Google. <a id="bing-webmaster-tools"></a>

**Call to action.** The one thing you ask a reader to do next, such as "Find our open hours". <a id="call-to-action"></a>

**Check-up.** A built-in test that looks at your setup and prints a short support code, so someone helping you can see where a step went wrong. <a id="check-up"></a>

**Claude Code.** A program from Anthropic that runs on your own computer, takes typed instructions, and can read and write files and run tools for you. It is part of the full version of this kit. <a id="claude-code"></a>

**CMS.** Short for content management system, the software behind your website where you type, edit, and publish pages. WordPress and Squarespace are examples. <a id="cms"></a>

**Command line.** A plain text window where you type instructions to your computer instead of clicking. Also called the terminal. The full version asks you to type a few lines there, and the steps show exactly which. <a id="command-line"></a>

**Config file.** A small settings file that holds the details specific to your organization (name, website, folders). Short for configuration file. This kit's is called config.json. <a id="config-file"></a>

**Content brief.** A one- or two-page plan for a single post. It names the search it answers, the reader, the outline, the sources, and the links, so the writer does not have to guess. <a id="content-brief"></a>

**CSV.** A plain table saved as text, with one row per line and commas between columns. Google Sheets and Excel can open and save them. <a id="csv"></a>

**Custom GPT.** A version of ChatGPT you set up once with your own instructions and files, so it starts every chat already knowing your rules. <a id="custom-gpt"></a>

**Dry run.** A practice pass that shows what would happen without doing it. Like reading the recipe aloud before you turn on the stove. <a id="dry-run"></a>

**Environment variable.** A named setting stored outside your files, usually where a secret like an API key is kept so it never appears in a document. <a id="environment-variable"></a>

**Feed.** A web address that publishes a site's newest posts in a form programs can read, so you can collect news without visiting each site. Also called an RSS feed. <a id="feed"></a>

**GA4.** Short for Google Analytics 4, Google's free tool that counts visits to your site and what visitors do there. <a id="ga4"></a>

**Harness.** The program that runs an AI model and its tools together. Claude Code is one. Casual speech calls this "the thing that runs the AI"; the official term is harness. <a id="harness"></a>

**Hero image.** The large banner picture at the top of a post. <a id="hero-image"></a>

**Impressions.** How many times your page appeared in someone's search results, whether or not they clicked. <a id="impressions"></a>

**Indexing.** Search engines adding a page to their catalog. A page that is not indexed cannot appear in search results. <a id="indexing"></a>

**Infographic.** A single image that explains a few facts with simple graphics and short text. <a id="infographic"></a>

**Internal link.** A link from one page of your site to another page of your site. <a id="internal-link"></a>

**JSON.** A plain text format for settings and data, with names and values in curly braces. Config files in this kit use it. <a id="json"></a>

**Keyword.** The words a person types or says when they search. Here it means the main search a post is written to answer. <a id="keyword"></a>

**Keyword difficulty.** A score from a keyword tool estimating how hard it is to reach page one for a search. Treat it as a rough hint. <a id="keyword-difficulty"></a>

**Knowledge file.** A document you upload to a Custom GPT or Project so the AI model can read it every time. <a id="knowledge-file"></a>

**Microsoft Clarity.** A free tool from Microsoft that records how visitors use your pages (where they click, where they get stuck) without identifying them. <a id="microsoft-clarity"></a>

**Plugin.** An add-on that gives a program new abilities. In Claude Code, a plugin bundles this kit's skills so you can install them in one step. <a id="plugin"></a>

**Project.** A workspace in ChatGPT or Claude where you store instructions and files that apply to every chat inside it. <a id="project"></a>

**Prompt.** The instructions you type to an AI model. <a id="prompt"></a>

**Python.** A programming language. The full version uses a few small Python programs, and the steps tell you exactly how to run them. <a id="python"></a>

**Queue.** The list of every post you are working on and the stage each is at, kept on the Queue tab of your Google Sheet. <a id="queue"></a>

**Redundancy check.** Looking to see whether you already have, or already planned, a post on the same topic before you spend time on a new one. <a id="redundancy-check"></a>

**Refresh.** Updating a published post with real improvements, such as new facts and a clearer answer, instead of writing a new one. <a id="refresh"></a>

**Scheduled job.** A task your computer or a service runs by itself at set times, such as every Monday morning. <a id="scheduled-job"></a>

**Schema markup.** Hidden labels in a page's code that tell search engines what the content is, such as a list of questions and answers. <a id="schema-markup"></a>

**Search Console.** Google's free tool that shows which searches bring people to your site, how often you appear, and how often people click. <a id="search-console"></a>

**Search intent.** What a person actually wants when they type a search: to learn something, compare options, do a task, or learn what it costs. <a id="search-intent"></a>

**Search volume.** How many times a month people search for a phrase. Estimates vary between tools. <a id="search-volume"></a>

**SEO.** Short for search engine optimization, the work of making your pages easy for search engines, and the people who use them, to find and understand. <a id="seo"></a>

**Sitemap.** A list of every page on your site, kept at a web address that search engines and tools can read. <a id="sitemap"></a>

**Skill.** A folder of instructions (and sometimes small programs) that teaches an AI model one job. The official file name inside is SKILL.md. <a id="skill"></a>

**Slug.** The last part of a page's web address, such as "what-to-bring" in example.org/blog/what-to-bring. <a id="slug"></a>

**Step ID.** The printed label on each numbered step, such as IP-FR-01-3, that you can quote when you ask for help. <a id="step-id"></a>

**Support code.** A short code the check-up prints. It tells a helper which step failed, the problem, and the kit version. <a id="support-code"></a>

**Terminal.** Another name for the command line window. <a id="terminal"></a>

**Validator.** A checker that reads a draft and lists rule breaks, the way a spell checker lists misspellings. <a id="validator"></a>
