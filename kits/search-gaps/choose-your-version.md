# Choose Your Version

This kit is the full team version. It has no free or low-cost edition, because the point of it is to run on a schedule, across several sites or markets, with owners and a record. That needs [Claude Code](glossary.md#claude-code) and a few files on disk.

## Which kit fits your team

| Your situation | Use | Why |
|---|---|---|
| One site, one person, no budget for tools | [Website check-up, free version](../website-checkup/choose-your-version.md) | Google Sheet and prompts, no install |
| One site, one person, a paid AI plan | [Website check-up, low-cost version](../website-checkup/choose-your-version.md) | Adds a saved project and a monthly speed pull |
| Customer wording and competitor content only | [Customer-language research](../customer-research/choose-your-version.md) | Same skills, sheet-based |
| Several sites or markets, a paid [SEO](glossary.md#seo) platform, leaders who ask for evidence | This kit | Schedule, [run log](glossary.md#run-log), [gap register](glossary.md#gap-register), owners |

The skills are the same in all of them. What differs is who runs them, how often, and what happens to the results.

## What this kit adds to the small-business versions

| | Small-business kits | This kit |
|---|---|---|
| Who runs it | One owner, by hand | A team, with a named owner for each slot |
| How many sites | One | A list in one [config file](glossary.md#config-file), each with its own competitors and folder |
| When it runs | When someone remembers | A set cadence, with a [run log](glossary.md#run-log) that records every slot |
| What a miss looks like | Nothing | A row with the reason, a retry date, and who was told |
| Where results go | A report for the owner | A [gap register](glossary.md#gap-register) and a one-page summary for leaders |
| Paid platforms | Optional | Expected for the competitor link view |

## What works without a paid platform

Everything except the competitor side of `backlink-gap`. You can still run the technical audit, [cannibalization](glossary.md#cannibalization), consolidation, internal links, metadata, [structured data](glossary.md#structured-data), speed, crawler access, competitor content, and all the customer-language skills. The shopping list marks each item as skippable or not.

## How to switch later

- Start with one site. Add the others to `config.json` once the first cycle has run cleanly, so you find your problems on one site and not five.
- Start without a paid link database. When you add one, only the `backlink-gap` report changes, and it says on its first line which path it used.
- If the team shrinks, the skills carry over unchanged to the small-business kits, which run them from a spreadsheet and a chat window. Keep the [baseline](glossary.md#baseline) and the quote lists, since they are plain tables.
