# Fixes

Find the code the check-up or a guide gave you, read what you see, and follow the fix. Codes E90 to E95 come from the check-up tool and are explained in [Getting help](../../guides/getting-help.md). If a fix here doesn't work, send the code and the [step ID](glossary.md#step-id) to Pigasus Group at https://pigasus.group/contact. Setup questions are free.

| Code | What you see | Why it happens | The fix | Step |
|---|---|---|---|---|
| E01 | A scheduled check has no report and no row in the [run log](glossary.md#run-log) | The owner was out, the export wasn't ready, or nobody was named for the slot | Record the miss in the run log with a reason, rerun the same day if the cause is on your side, and tell the owner and the person who reads the summary. Never leave the row blank | SG-FU-02-6 |
| E02 | A check warns that the [baseline](glossary.md#baseline) is old, or says it has none | No one refreshed it this cycle, or two people wrote different copies | Export fresh queries and pages and refresh it. Name one writer per site | SG-FU-02-4 |
| E03 | The query list from [Search Console](glossary.md#search-console) stops at a round number | The interface export has a row cap, so the list is a slice, not the whole | Say so in the report, narrow the date range or split by country to get the rest, or pull the same data through the Search Console data service | SG-FU-01-7, SG-FU-02-4 |
| E04 | Search Console, Bing, [Ahrefs](glossary.md#ahrefs), or [GA4](glossary.md#ga4) point in different directions | Different samples, date ranges, filters, and counting rules | Match the date range, page set, country, and device first. Then write one line saying why they differ, or label the row unexplained. Don't choose the number you prefer | SG-FU-02-7, SG-FU-03-4 |
| E05 | The link database says the key is invalid, missing, or over its limit | The key was typed wrongly, was never set in this [terminal](glossary.md#terminal) window, or the plan's quota ran out | Set it again under the exact name `AHREFS_API_KEY`. Check the plan's allowance on the vendor's page. Wait for a reset, or run the free path | SG-FU-01-2, SG-FU-02-5 |
| E06 | The [backlink](glossary.md#backlink) report covers only your own links | No link database was available, which the [skill](glossary.md#skill) reports on its first line | If this is expected, nothing is wrong. Otherwise fix E05 and rerun | SG-FU-02-5 |
| E07 | The [crawl](glossary.md#crawl) export looks scrambled, or the script can't read it | It was re-saved from a spreadsheet, or a title containing a pipe character split the columns | Use the original export from the crawler, untouched | SG-FU-02-3 |
| E08 | The crawl is partial, a site blocks it, or logged-in pages are missing | The crawler was rate-limited, a firewall refused it, the site is too large for one pass, or the pages need a login | Crawl one section at a time, ask your web team to allow the crawler for the run, and list what was missed in the report. A missing page is a gap in the evidence, not a finding | SG-FU-02-3 |
| E09 | The [Common Crawl](glossary.md#common-crawl) check times out or returns server errors, or shows that its crawler is refused | The public servers are slow at times. A refusal means a rule at the edge of your site blocks the crawler | Wait an hour and rerun, since one failed run says nothing about your site. If the live test shows a refusal for the crawler and a normal page for a browser, send the result to whoever manages your site's edge settings | SG-FU-02-5 |
| E10 | Two pages are flagged as competing, but one is a service page and the other a how-to | They serve different needs, so merging would remove a page people use | Don't merge. Make each page's title and heading aim at its own need, and link them to each other | SG-FU-03-3 |
| E11 | The [AI model](glossary.md#ai-model) gives a number or fact you didn't supply, or a figure with no source | AI models fill gaps with plausible-sounding guesses | Discard that answer. Rerun the [prompt](glossary.md#prompt) and add "Mark anything you could not check as unknown. Do not invent numbers." Check each number against its source | SG-FU-01-7, SG-FU-02-5, SG-FU-03-1 |
| E12 | A competitor's site, or a review site, refuses the read or slows it | The site rate-limits or blocks automated reading | The skill skips it and says so. Don't work around the block. Paste the reviews yourself, or leave that competitor out and note it. Never report a zero for a read that failed | SG-FU-02-5 |
| E13 | A merged page lost traffic, or the old address still shows the old page | The [redirect](glossary.md#redirect) isn't live, points at the wrong page, or search engines haven't re-read it yet | Open the old address in a browser and confirm it lands on the winning page. Fix the redirect if not. Judge the result at the check-back date, not the next day | SG-FU-03-7 |
| E14 | Two copies of the baseline, the run log, or the register disagree | Several people each keep a local copy | Keep one shared copy of each file. Name one writer for each baseline, and let everyone else read | SG-FU-01-5, SG-FU-02-2 |
| E15 | The [terminal](glossary.md#terminal) says "command not found", or [Claude Code](glossary.md#claude-code) can't find the marketplace | Claude Code or [Python](glossary.md#python) isn't installed, the terminal was open before you installed it, or the address has a typo | Close the terminal and open a new one. Follow the install guide again. Copy the marketplace address from the GitHub page | SG-FU-01-1, SG-FU-01-3 |
| E16 | `config.json` won't load, or the check-up says a key is empty | A missing quote or comma, or `team_name` or `sites` was left blank | Check that every value sits in straight quotes and every line but the last in a block ends with a comma. Fill in `team_name` and at least one site | SG-FU-01-4 |
| E17 | The `persona-jury` skill approves every draft | The simulated customers lean agreeable | Treat unanimous approval as a warning. Add a [persona](glossary.md#persona) who has an objection from real quotes, and show the draft to real customers | SG-FU-03-5 |
| E18 | The speed check has no [field data](glossary.md#field-data) for a page, or says the request limit was reached | Too few Chrome visitors on that page, or the free allowance ran out for the moment | Mark field data unknown for that page and don't judge severity from [lab data](glossary.md#lab-data). Wait an hour for limits, or set the optional key | SG-FU-02-5 |
| E19 | This cycle's numbers can't be compared with last cycle's | The competitor set, the crawl scope, or the date range changed | Freeze the competitor set for the quarter. When something must change, say so on the first line of the report and don't compare across the break | SG-FU-02-1, SG-FU-03-6 |
| E20 | A skill seems to run twice, or Claude Code lists two skills with one name | Both this kit and a small-business [plugin](glossary.md#plugin) are installed | Remove the small-business plugins and keep this one | SG-FU-01-3 |
