Every account in this list is covered in the shared guide [keys and accounts](../../guides/keys-and-accounts.md): where to sign up, what's free, and how to keep your sign-in details out of shared files and screenshots. Nothing in this kit asks you for a password or a key.

## A note on ChatGPT

OpenAI's own documents describe the same skill format that Claude uses, but this kit has not confirmed which ChatGPT plans accept a skill upload or run the [scripts](glossary.md#script) inside one. If you use ChatGPT, try the upload in guide `PW-LC-01`. If it isn't offered on your plan, use a Project or a [Custom GPT](glossary.md#custom-gpt) instead (guide `PW-LC-02`). They do the same job for the writing rules.

## What to buy first

Nothing. Start with the free version. If you find yourself pasting the same prompt every day, that's the signal to try low cost. If you want a program to catch mistakes so a person doesn't have to, that's the signal for full.

## What this kit never needs

It never needs a website host, a database, or an email account. It never asks for your donor lists, client files, or passwords. If a guide ever seems to, stop and ask for help at the contact link in the guide's help box.
