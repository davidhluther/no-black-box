# Visual Design

## Design Process (In Order)

1. **Choose a tone.** Quirky? Polished? Serious? Playful? Premium? Every choice below must support this tone. Decide before picking a single color.

2. **Choose a palette.** Colors should feel designed for THIS topic. If you could swap the colors into a completely different presentation and they'd still work, you haven't made specific enough choices.

3. **Choose fonts.** Pick a header font with personality and pair it with a clean body font. Do not default to Arial.

4. **Commit to a visual motif.** One distinctive element repeated across every slide — rounded image frames, icons in colored circles, thick single-side borders, etc. Carry it through consistently.

5. **Plan layout variety.** Sketch (or list) the layout type for each slide before building. No two consecutive slides should use the same layout.

## Color

### Palette Rules
- **Dominance over equality.** One color gets 60-70% visual weight. 1-2 supporting tones. One sharp accent. Never give all colors equal weight.
- **Dark/light contrast.** Dark backgrounds for title + conclusion slides, light for content ("sandwich" structure). Or commit to dark throughout for premium feel.
- **Accessibility.** 8% of males and 0.8% of females have color deficiency. Use blues, oranges, and grays as primary differentiators. Limit greens and reds as the sole distinction between elements.
- **Match venue lighting.** Light background + dark text for bright rooms. Dark background + light text for dim rooms. If unknown, default to light background.

### Size Scale

| Element | Size |
|---------|------|
| Slide title / assertion headline | 36-44pt bold |
| Section header | 20-24pt bold |
| Body text | 14-16pt |
| Captions / sources | 10-12pt muted |

Minimum readable size when projected: 18pt. If you can't read it from the back of the room, it's too small.

## Layout

### Available Patterns (vary across slides)

- **Two-column:** Text left, illustration/image right (or reversed)
- **Icon + text rows:** Icon in colored circle, bold header, description below
- **2x2 or 2x3 grid:** Image on one side, grid of content blocks on the other
- **Half-bleed image:** Full left or right side image with content overlay
- **Large stat callout:** Big number (60-72pt) with small label below
- **Comparison columns:** Before/after, pros/cons, side-by-side options
- **Timeline / process flow:** Numbered steps with arrows or connecting lines
- **Outcome tiles:** 4-6 mini-cases in a grid (replaces logo walls)

### Spacing

- 0.5" minimum margins from slide edges
- 0.3-0.5" between content blocks — pick one and use it consistently
- Leave breathing room. Not every inch needs to be filled.
- Include occasional "glanceable" slides — simple visual + short text — to give the audience a breath.

## What NOT to Do

- **No accent lines under titles.** This is the hallmark of AI-generated slides.
- **No text-only slides.** Every slide needs a visual element.
- **No repeated layouts on consecutive slides.** Vary columns, cards, callouts.
- **No centered body text.** Left-align paragraphs and lists. Center only titles.
- **No random spacing.** Choose 0.3" or 0.5" gaps and commit.
- **No low-contrast elements.** Icons AND text need strong contrast against backgrounds.
- **No style inconsistency.** If you style one slide, commit fully across the deck.
- **No bullet overload.** If a slide has more than 5-6 bullets, split it.
- **No "show all bullets at once" in live presentations.** Use reveal animations and gray-out after discussion. (Note: this applies to delivery, not to the .pptx file itself.)
- **No stock/patriotic filler images.** Remove unless directly tied to a Message.

## Using Brand Assets

When brand colors, logos, or fonts are provided:

1. Use brand primary color as the dominant color (60-70%)
2. Build secondary and accent colors that complement the brand palette
3. Place logo consistently — typically bottom-left or bottom-right, small, on every slide
4. Use brand fonts if specified; if not, choose a pairing that matches the brand's tone
5. Don't override the brand with your own design preferences
