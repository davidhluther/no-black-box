# Glossary

Every technical term used in this kit, in plain words. The first time a term appears on any page, it links here or is defined right there.

**AI model.** A program trained on very large amounts of text that can answer questions and write. ChatGPT, Claude, and Gemini are products built on AI models. <a id="ai-model"></a>

**AI tell.** A habit in writing that makes a reader suspect a machine wrote it, such as a stiff opener, an unneeded recap, or a favorite word like "seamless." <a id="ai-tell"></a>

**AP style.** The rules for writing used by most newsrooms, from the Associated Press. This kit borrows its rules for numbers, commas, and capital letters. <a id="ap-style"></a>

**Apps Script.** A free tool built into Google Docs and Sheets that lets you add small programs to a document. Think of it as a set of extra buttons you write yourself. <a id="apps-script"></a>

**Command line.** A window where you type instructions to your computer instead of clicking. It's like texting your computer. Also called the terminal. <a id="command-line"></a>

**Config file.** A small text file that holds your organization's own details, such as its name and where its house style lives, so the programs don't have this written into them. <a id="config-file"></a>

**CSV.** A plain table saved as text, with commas between the columns. Google Sheets and Excel can open and save it. <a id="csv"></a>

**Custom GPT.** A version of ChatGPT you set up with your own instructions and files, so it behaves the same way each time. <a id="custom-gpt"></a>

**Em-dash.** The long dash (—) used to set off a phrase. This kit asks for it rarely, with a space on each side. <a id="em-dash"></a>

**Gate.** A check that must pass before something goes out. A pre-publish gate is a program that reads a draft and refuses to say "ready" if it finds errors. <a id="gate"></a>

**Git.** A free tool that keeps a history of changes to files, like the version history in Google Docs but for any folder. <a id="git"></a>

**Hook.** A small program that Git runs automatically at a set moment, such as just before a change is saved. A pre-commit hook can run the gate for you. <a id="hook"></a>

**House style.** One short file that holds the writing rules particular to your organization, such as its name, voice, and preferred spellings. It sits on top of the shared rules and can only make them stricter. <a id="house-style"></a>

**JSON.** A way of writing settings as plain text with labels and values, for example `"organization_name": "Example Co"`. A program reads it the way you read a form. <a id="json"></a>

**Knowledge file.** A document you give a Custom GPT or a Project so it can read it before answering. <a id="knowledge-file"></a>

**Linter.** A program that reads text or code and lists the places that break your rules, like a spell-checker for style. <a id="linter"></a>

**Markdown.** A way to write formatted text in a plain file, using symbols such as `#` for a heading and `-` for a list item. Files end in `.md`. GitHub shows them as formatted pages. <a id="markdown"></a>

**Plugin.** An add-on that gives a program new abilities. In Claude Code, a plugin can bundle several skills. <a id="plugin"></a>

**Project.** A workspace inside Claude or ChatGPT where you keep instructions and files that apply to every chat in it. <a id="project"></a>

**Prompt.** The instruction you give an AI model. A good prompt says who the reader is, what you want, and what rules to follow. <a id="prompt"></a>

**Python.** A free programming language. The checkers in the full version are written in it, and you need it installed to run them. <a id="python"></a>

**Script.** A short program, usually in one file, that does one job. <a id="script"></a>

**Selector.** A short pattern that picks out one part of a web page, such as the article text, so a program can ignore menus and footers. <a id="selector"></a>

**Sentence case.** Capitalizing only the first word and proper names, as in "How we changed our sign-up sheet." <a id="sentence-case"></a>

**Sitemap.** A list of every page on a website, kept in a file that programs can read. <a id="sitemap"></a>

**Skill.** A folder of instructions, and sometimes programs, that an AI model reads when a task matches. Think of it as a recipe card the model pulls out when you ask for that dish. <a id="skill"></a>

**Step ID.** The code printed at the start of each step in a guide, such as PW-FR-01-3. If you get stuck, you tell us the step ID and we know exactly where you are. <a id="step-id"></a>

**Style guide.** A written set of rules for how an organization writes. <a id="style-guide"></a>

**Support code.** A short code the check-up button or command prints. It tells whoever is helping you which step failed and what kind of problem it was, without sharing your documents. <a id="support-code"></a>

**Threshold.** A limit. In the tell-scorer, a threshold is the highest score a draft can have and still pass. <a id="threshold"></a>

**Title case.** Capitalizing the main words, as in "How We Changed Our Sign-Up Sheet." This kit uses it for page titles only. <a id="title-case"></a>

**Upload.** Sending a file from your computer to a website, such as dropping a file into a chat. <a id="upload"></a>

**Validator.** A program that checks a document against a set of rules and reports what fails. article-check is a validator. <a id="validator"></a>

**Zip file.** A single file that holds a whole folder, squeezed smaller. Claude uploads skills as zip files. <a id="zip-file"></a>
