# PW-FR-01: Set Up the Rules Prompt

You'll end with a free AI chat that follows plain-writing rules every time you paste one [prompt](../glossary.md#prompt). It takes about ten minutes and needs no install.

Before you start, you need a free account with one AI chat: ChatGPT (chatgpt.com), Claude (claude.ai), or Gemini (gemini.google.com). If you don't have one, see [keys and accounts](../../../guides/keys-and-accounts.md).

1. **PW-FR-01-1.** Open your AI chat of choice in a web browser and sign in.
   You'll know it worked when you see an empty chat with a box to type in. If a sign-in screen keeps coming back, it's E03.
2. **PW-FR-01-2.** Get the file [prompts.md](../free/prompts.md) from this kit. The simplest way is to open it on GitHub in your browser, where it shows as a formatted page. If you would rather have the kit's files on your computer, follow [get the kit files](../../../guides/get-the-files.md) to download them from https://github.com/davidhluther/no-black-box, then open the file in kits, plain-writing, free.
   You'll know it worked when you see a heading called Prompt 1: the rules prompt, and a gray box underneath.
3. **PW-FR-01-3.** Move your pointer over the gray box under Prompt 1. A small copy icon appears at its top right corner. Click it.
   You'll know it worked when the icon changes to a check mark or says "Copied."
4. **PW-FR-01-4.** Go back to your AI chat, click the box where you type, paste (Ctrl+V on Windows, Command+V on a Mac), and press Enter.
   You'll know it worked when the [AI model](../glossary.md#ai-model) replies, usually with a short "Understood" or a question about what you're writing. If it says the message is too long, it's E05.
5. **PW-FR-01-5.** Ask for something small: "Write a three-sentence note telling neighbors our pantry is closed next Monday for a holiday."
   You'll know it worked when the note is short and plain, and it has none of these: "I hope this message finds you well," "we are delighted to inform you," or a closing line that repeats the first.
6. **PW-FR-01-6.** Save the prompt for next time. Open a new Google Doc (docs.google.com), title it "Rules prompt," and paste the same text into it.
   You'll know it worked when the Doc shows the text and the title appears in your Google Drive. Next time, copy from your Doc instead of going back to GitHub.

> **How to get help.** Write down the [step ID](../glossary.md#step-id) where you got stuck (it looks like PW-FR-01-3). The free version has no check-up button because nothing is installed, so also write what you see on the screen in a sentence or two, and take a screenshot if you can. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
