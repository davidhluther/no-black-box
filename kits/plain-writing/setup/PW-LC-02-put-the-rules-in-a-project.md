# PW-LC-02: Put the Rules in a Project

You'll end with a Project (a workspace that keeps your instructions and files for every chat inside it) that follows your plain-writing rules without any pasting. It works in Claude, ChatGPT, and Gemini, and it's the best choice if [skill](../glossary.md#skill) [upload](../glossary.md#upload) isn't available to you. It takes about 15 minutes.

1. **PW-LC-02-1.** In your paid AI plan, create a new Project. In Claude, choose Projects, then New project. In ChatGPT, choose Projects, then New project. Name it "Plain writing."
   You'll know it worked when you see an empty Project with a place for instructions and a place for files.
2. **PW-LC-02-2.** Open [instructions.md](../chatgpt/instructions.md) from this kit. Copy the text inside the gray box, and paste it into the Project's instructions field. Save.
   You'll know it worked when the instructions field shows the full text and the Project reports it saved.
3. **PW-LC-02-3.** [Upload](../glossary.md#upload) the files named in [the upload list](../chatgpt/knowledge-files.md). Start with the [style guide](../glossary.md#style-guide) and your [house style](../glossary.md#house-style) from guide `PW-FR-03`. Upload `.md` files only. If it says it can't use a file, it's E04.
   You'll know it worked when the files appear in the Project's file list.
4. **PW-LC-02-4.** Open a new chat inside the Project. Ask: "Review the draft below against our rules," and paste [example-draft.md](../free/example-draft.md).
   You'll know it worked when you get a table of findings that names the rules.
5. **PW-LC-02-5.** Optional. To share the setup with a colleague, create a [Custom GPT](../glossary.md#custom-gpt) from the same instructions and files (ChatGPT, Explore GPTs, Create). Turn off web browsing if you want it to stay on your documents. Don't upload donor lists or private notes.
   You'll know it worked when your colleague can open the GPT and get the same review table.
