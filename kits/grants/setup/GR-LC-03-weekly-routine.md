# GR-LC-03: The Weekly Routine

**What you'll have.** A 15-minute habit that turns the Sweep (a search that runs by itself every week) tab into real Pipeline rows without losing anything. **Time.** 15 minutes a week. **You need.** The working weekly search from [GR-LC-02](GR-LC-02-add-the-weekly-search.md).

If you get stuck, the check-up (a button or command that tests your setup) prints a support code (a short code that tells a helper which step failed and holds none of your information). The last box on this page says how to use it.

1. **GR-LC-03-1.** Open the SweepLog tab. Look at the last line.
   You'll know it worked when the last line says done or partial and is dated this week. If it says failed or the date is older than a week, read the failure and look at E21.

2. **GR-LC-03-2.** Open the Sweep tab and read the rows marked "Tier 2: look now". Click each link and read the notice on Grants.gov (the US government's public list of grant opportunities) itself.
   You'll know it worked when you have decided, for each, whether your organization is eligible. Read the eligibility section of the notice yourself. The score is only a guide.

3. **GR-LC-03-3.** For each good notice, add a row to the Pipeline tab with Status Prospect. Write the notice link in the Funder link column. Change the Status cell on the Sweep tab to "added" or "not a fit".
   You'll know it worked when the Pipeline row's calculated columns fill in. If a status word is spelled differently from the Rubric tab, the check-up shows E12.

4. **GR-LC-03-4.** Run the check-up (Help, then Run check-up) and glance at the Dashboard.
   You'll know it worked when the code shows E00 and the Dashboard's deadline count matches your calendar.

> **How to get help.** Write down the step ID where you got stuck (it looks like GR-LC-01-3). If your kit has a check-up button or command, run it and copy the support code it prints. Then send both to Pigasus Group at https://pigasus.group/contact. Setup questions are free.
