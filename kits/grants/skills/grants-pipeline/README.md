# grants-pipeline

The grants pipeline engine. `SKILL.md` is the process, `engine/` is the code (every script takes `--config`), `templates/` has the blank starting files, and `orgs/example.json` is a complete example config with invented values.

Copy `orgs/example.json` to `orgs/<your-slug>.json`, change every value, and run the scripts as `SKILL.md` describes. Fix problems in this one copy of the engine so every organization you set up gets the fix.
