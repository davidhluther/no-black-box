# Glossary

Every technical or specialist term used anywhere in the Grants and Giving kit, in plain words. Each page of the kit also explains a term the first time it appears on that page.

**AI model.** A computer program that reads and writes text when you give it a message. ChatGPT, Claude and Gemini are products that let you talk to AI models.

**API.** A way for two programs to talk to each other, like a waiter carrying orders between you and the kitchen. Grants.gov has one so other programs can ask it questions.

**Apps Script.** A free tool inside Google Sheets that lets you add small programs to a spreadsheet, such as a menu button. You paste the program in; you don't need to write any.

**bequest.** A gift to a charity left in someone's will.

**CAPTCHA.** The "prove you are human" test on some websites, such as picking pictures of traffic lights. Never try to get a program past one.

**check-up.** The Help menu button in your tracker that tests whether the spreadsheet is set up correctly and prints a support code.

**claims register.** A table of every fact you may state about your organization, each with its source and how sure you are of it. A grant draft may use only facts from this table.

**command line.** A screen where you type instructions to the computer instead of clicking. The free and low-cost versions of this kit never use it.

**config file.** A small settings file that holds your organization's details, such as its name and tax ID, in one place so nothing else has to be changed.

**CSV file.** A plain table saved as text, with commas between the columns. Google Sheets can import one into a new tab.

**donor-advised fund.** A charitable account a donor holds at a sponsor, such as a community foundation or a brokerage's charity arm. The donor recommends grants from it to charities. Often shortened to DAF.

**dossier.** A short file of everything you have learned about one funder, with sources and dates.

**EIN.** Employer Identification Number, the nine-digit federal tax ID of an organization. It looks like 00-0000000 and is on your IRS letter.

**formula.** A calculation typed into a spreadsheet cell, starting with an equals sign. The tracker uses formulas to work out tiers and totals.


**Form 990-PF.** The yearly tax return a private foundation files with the IRS. It lists every grant the foundation paid in that year, so it shows who a foundation really funds.


**GitHub.** A website where programmers keep project files. This kit's files live there, and you can download them as one ZIP file without an account.

**Google Docs.** The free word processor from Google, for letters, checklists and drafts.

**Google Drive.** Free online file storage from Google, where your Docs and Sheets live.

**Google Sheets.** Google's free spreadsheet app, where your tracker lives.

**Google Workspace for Nonprofits.** Google's offer of its office apps, including Sheets, Docs and Drive, at no cost to nonprofits that Google verifies as eligible.


**Grants.gov.** The US government's public website that lists federal grant opportunities.

**JSON.** A way of writing settings as text with curly braces. The full version of the kit stores your organization's details in a JSON file. You edit it in any text editor.

**knowledge file.** A document you upload to a ChatGPT Project or Custom GPT so the AI model can read it when it answers.

**letter of inquiry.** A short first letter, often one page, that some funders ask for before they will invite a full application. Often shortened to LOI.

**matching gift.** A gift from an employer that matches an employee's own donation, so the charity receives double.


**plugin.** An add-on that gives a program new abilities. In Claude Code, a plugin can bundle a set of skills.


**ProPublica Nonprofit Explorer.** A free website that shows the IRS tax filings of nearly any US nonprofit, including each foundation's assets and grants.

**prompt.** The message you type to an AI model.

**Python.** A programming language. The full version of the kit uses small Python programs, which Claude Code can run for you.

**QCD.** Qualified charitable distribution, a gift sent straight from a donor's IRA to a charity by someone aged 70½ or older, which is not counted as taxable income for the donor.

**scheduler.** A part of your computer that runs a program on a timetable, such as every Thursday morning. On a Mac or Linux computer it is called cron.


**skill.** A folder of written instructions that an AI model can follow to do one kind of job, such as researching a funder.

**support code.** A short code, like GR-FR-01-4-E02-v0.1.0-7KQ, that the check-up prints. It tells the helper which step you were on, what went wrong, and which version of the kit you have. It contains none of your information.

**sweep.** A search that runs on its own every week and lists new grant opportunities for you to read.


**terminal.** The program on a computer where you type instructions. It is the same thing as the command line.



**trigger.** An instruction that tells Google Sheets to run a script on a schedule, such as every Thursday at 8 a.m.

**ZIP file.** One file that holds many other files squeezed together. Double-click it to open the folder inside.
