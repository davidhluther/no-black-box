# Fixes

Find the code the check-up (the Kit help menu button that tests your sheet's setup) printed, or the code a step pointed you to. Each row says what you see, why it happens, what to do, and which step it belongs to. A support code (the short code the check-up prints, such as GR-FR-01-4-E02-v0.1.0-7KQ) contains one of these problem codes in the middle. If a fix does not work, send the support code and your step ID to Pigasus Group at https://pigasus.group/contact. Setup questions are free.

| Code | What you see | Why it happens | The fix | Step |
|---|---|---|---|---|
| E00 | The check-up says everything checks out. | Nothing is wrong. | Nothing to do. Keep the code if anyone asks for it. | GR-FR-02-7 |
| E01 | The check-up says a tab (a labelled page along the bottom of the sheet) is missing. | The CSV file (a plain table saved as text) for that tab was not imported, or the tab has a different name. Tab names must match exactly, including capital letters. | Import the missing file again as a new sheet, or double-click the tab's name and type the exact name. The step number in the code tells you which tab. | GR-FR-01-3 to GR-FR-01-9 |
| E02 | The check-up says a tab's headings differ from the template. | The wrong file was imported into that tab, a heading was typed over, or the file was opened and saved in another program first. | Delete the tab and import its CSV file again (a CSV file is a plain table saved as text). Or retype the headings in row 1 exactly as they appear in the CSV file. | GR-FR-01-4 to GR-FR-01-9 |
| E03 | The check-up says the Settings rows were moved. | A row was inserted, deleted or renamed on the Settings tab. Formulas (a calculation typed into a spreadsheet cell) read fixed rows there. | Press Ctrl+Z (Command+Z on a Mac) to undo, or delete the Settings tab, import Settings.csv again and retype your details. | GR-FR-01-3 |
| E04 | Cells show #REF!, #ERROR!, #NAME? or #VALUE!, or the calculated columns on Pipeline are blank. | One of three causes. The Settings tab was renamed. The conversion box was unticked at import, so formulas stayed plain text. Or the spreadsheet's region is not the United States, and formulas use US punctuation. | Check that the tab is named Settings. Click File, then Settings, and set Locale to United States. Then delete the tab and import its CSV file again with "Convert text to numbers, dates, and formulas" ticked. | GR-FR-01-4 or GR-FR-01-7 |
| E05 | The check-up says required Settings cells are empty. | Some of your organization's details were not typed in. | Fill the Value column beside short name, legal name, EIN (the nine-digit tax ID), grants contact name and email, both tier minimums and the fiscal-year start. | GR-FR-01-11 |
| E06 | The check-up says the EIN is not nine digits. | The tax ID has a typing error or extra characters. | Retype it from your IRS letter, like 00-0000000. | GR-FR-01-11 |
| E07 | The check-up says the tier minimums must be numbers with Tier 1 larger. | A minimum contains words, or Tier 1 is not larger than Tier 2. | Type plain numbers such as 25000 and 5000. | GR-FR-01-11 |
| E08 | The check-up says the fiscal-year start is not a date. | The date was typed in a different style. | Type it as mm/dd/yyyy, such as 07/01/2026. A real date lines up on the right of the cell. | GR-FR-01-11 |
| E09 | Importing a CSV replaced a tab you had, or all the columns landed in column A. | "Replace current sheet" was chosen, or the import did not split at the commas. | Press Ctrl+Z (Command+Z) to undo. Import again, choose "Insert new sheet(s)", and under "Separator type" choose Comma. | GR-FR-01-3 |
| E10 | There is no Kit help menu after you paste the check-up, or there is no Apps Script (a free Google tool that runs small programs inside a spreadsheet) under Extensions. | The page was not reloaded, the code did not save, or your organization's Google account has Apps Script switched off. | Reload the page and wait ten seconds. Open Extensions, Apps Script, and check that the code is still there and saved. If Apps Script is missing, ask whoever manages your Google account to turn it on, or use a personal Google account. | GR-FR-02-1 or GR-FR-02-5 |
| E11 | Google shows "Google hasn't verified this app" and offers no way past it. | Your Google account's administrator blocks scripts that are not published. | Ask the administrator to allow it, or copy the sheet to a personal Google account (File, then Make a copy) and run the steps there. | GR-FR-02-6 |
| E12 | The check-up says some Pipeline rows use a Status word the Dashboard does not count. | A status was typed with different spelling, extra spaces or a new word. | Use exactly the words on the Rubric tab, such as Prospect, Submitted, Awarded. | GR-FR-03-4 |
| E13 | The check-up says verified claims have no Source. | A claim marked source-verified or external-verified has an empty Source cell. | Add the document name and page, or the web address and date, or change the status to unverified. | GR-FR-04-2 |
| E14 | The check-up says the Kit version cell does not match. | The Settings cell was edited, or the check-up file is from a different release of the kit. | Retype the version printed in the check-up window into Settings, or download the newest kit and reinstall the check-up. | GR-FR-01-3 |
| E15 | "Check draft numbers" is not in the Kit help menu. | The draft-check file was not added, was not saved, or the page was not reloaded. | Redo the install, saving the file, then reload the sheet. The draft checker needs the check-up file in the same Apps Script project. | GR-FR-04-3 |
| E16 | The DraftCheck results are empty or say no numbers were found. | The draft is not in cell B1, or the draft has no numbers over ten. | Paste the whole draft into cell B1 only, not into a lower cell. A very long draft over about 50,000 characters needs splitting in two. | GR-FR-04-5 |
| E17 | Google keeps returning you to the sign-in page. | Several Google accounts are signed in at once, or old cookies conflict. | Close all Google tabs. Open a private browser window and sign in to only the one account you want. | GR-FR-01-1 |
| E18 | Google Workspace for Nonprofits (Google's free offer of its office apps to eligible nonprofits) says your application is waiting or was not approved. | Google verifies each organization first, and the check can take days. | Use a regular Google account in the meantime. You can copy the sheet to the organization account later. | GR-FR-01-1 |
| E19 | You can't find the tracker folder, or the CSV files open as text in a browser. | The ZIP file (one file that holds many files) was not opened, or the file was viewed on GitHub (the website where the kit's files live) instead of downloaded. | Download the ZIP using the green Code button, double-click it to open it, and use the files from your computer's folders. | GR-FR-01-2 |
| E20 | The Project says the instructions are too long. | Some products allow fewer characters than others. | Paste only the sections "What you may rely on" and "Rules for every answer", and upload the rest of instructions.md as a knowledge file (a document the chat program can read when it answers). | GR-LC-01-3 |
| E21 | SweepLog shows "failed", or a failure email arrived. | Grants.gov (the US government's public list of grant opportunities) was busy or down, or a search word has odd punctuation. | Read the log line. Wait an hour and run runWeeklySweep again. If it still fails, remove punctuation other than letters and spaces from the search words. | GR-LC-02-4 |
| E22 | The Sweep (the weekly search) tab is empty although the log says "done". | The search words are too narrow for Grants.gov. | Try broader words such as "community" or "food". Compare with a search by hand at grants.gov. | GR-LC-02-5 |
| E23 | No scheduled jobs are listed under the clock icon. | installSweepTriggers did not finish, or permission was not given. | Run installSweepTriggers again and allow the permissions. | GR-LC-02-6 |
| E24 | The test alert email never arrives. | The email in Settings is blank or wrong, the message went to spam, or sending email was not allowed. | Check the Grants contact email cell, look in spam, and run the function again, allowing the permission. | GR-LC-02-7 |
| E25 | The terminal (the screen where you type instructions) says "command not found" for python3. | Python (a programming language) is not installed, or on Windows it is named py. | Install Python 3 from python.org. On Windows, try py in place of python3. | GR-FU-01-1 |
| E26 | The install of the plugin (an add-on that bundles the kit's instruction folders) fails. | The repository address is wrong, or Claude Code is out of date. | Check that the address matches https://github.com/davidhluther/no-black-box, update Claude Code, and try again. Copy the exact message when you ask for help. | GR-FU-01-2 |
| E27 | A settings file will not load, or the `json.tool` command prints an error. | A comma, quotation mark or bracket is missing. | The error names the line. Fix that line, and compare with the example file. | GR-FU-01-4 |
| E28 | A builder stops with "list index out of range" or "could not convert string to float". | A CSV has no data rows, or a number column has a dollar sign or comma in it. | Add at least one row to each CSV, and write amounts as plain numbers such as 10000. | GR-FU-01-5 or GR-FU-02-1 to GR-FU-02-3 |
| E29 | A builder refuses because an excluded name appears. | A name from "exclude_names" is in your data. | Remove it from the data, or remove it from the list if it was listed by mistake. | GR-FU-02-2 |
| E30 | The sweep reports a failed source. | The website was down, changed, or blocked the request. | Try again later. The wrapper keeps the old results and alerts you; never try to get around a block. | GR-FU-03-1 |
| E31 | The ALERT file appears but no email arrives. | The scheduler (the part of a computer that runs programs on a timetable) cannot see your email settings, because it does not use your normal environment. | Put the five email settings at the top of the scheduler's own file, keep that file private to you, and run the wrapper by hand to test. | GR-FU-03-3 |
| E32 | The scheduled job does not run. | The computer was asleep, a path is wrong, or the scheduler lacks permission. | Use full paths, keep the computer awake at that time, and read wrapper.jsonl. The daily freshness check will alert you to a missed week. | GR-FU-03-4 |
