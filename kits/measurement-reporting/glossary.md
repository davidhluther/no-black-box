# Glossary

Every technical term used in this kit, in plain words, listed alphabetically.

**AI referral traffic.** <a id="ai-referral-traffic"></a>Visits that arrive by clicking a link inside an AI tool such as ChatGPT, Perplexity, Gemini, Claude or Copilot. It is a floor, not the total, because many AI visits carry no sign of where they came from.

**AI visibility.** <a id="ai-visibility"></a>How often and how favorably AI answers mention or cite your brand and pages. Platforms and manual question sets measure it, and they rarely agree on size.

**API.** <a id="api"></a>A way for two programs to talk, like a waiter carrying orders between you and the kitchen. A program asks for numbers and the service sends them back.

**API key.** <a id="api-key"></a>A long secret that tells a service which account is asking, and which account to bill. Treat it like a bank card number.

**Bing Webmaster Tools.** <a id="bing-webmaster-tools"></a>Microsoft's free report of how your site appears in Bing. It is the second search source in most direction checks.

**change log.** <a id="change-log"></a>A dated list of everything the team changed or that changed around it: launches, edits, tracking changes, campaigns, outages and search engine updates. Reports compare it against the numbers.

**channel group.** <a id="channel-group"></a>A way of sorting visits into labeled buckets such as Organic Search, Direct and Email. A custom channel group adds your own bucket, such as AI Traffic.

**Clarity.** <a id="clarity"></a>Microsoft Clarity, a free tool that shows how visitors click and scroll on a site and reports visits from AI tools.

**CMS.** <a id="cms"></a>Content management system, the program your team publishes pages through.

**container.** <a id="container"></a>In Google Tag Manager, the box that holds all of one site's tracking pieces. Its name looks like GTM-XXXXXXX.

**CRM.** <a id="crm"></a>Customer relationship management system, where leads, accounts and pipeline are recorded.

**CSV.** <a id="csv"></a>A plain table saved as text, one row per line with commas between columns. Any spreadsheet opens it.

**data-through date.** <a id="data-through-date"></a>The last day a source's figures cover. Search Console lags by a few days, so two sources can both be right and still differ.

**direction disputed.** <a id="direction-disputed"></a>The label for a figure where two comparable sources disagree about up, down or flat. Nobody acts on it until the gap is explained.

**environment variable.** <a id="environment-variable"></a>A named setting your computer holds for programs to read, so a secret never has to be written in a file.

**evidence card.** <a id="evidence-card"></a>A short record for one finding: source, corroboration, contradiction, how to check it, other explanations and a grade.

**event.** <a id="event"></a>One thing GA4 records, such as a page view, a download click or a form being sent.

**floor.** <a id="floor"></a>A count that is "at least this many", never the total. AI referral traffic and flagged AI queries are floors.

**GA4.** <a id="ga4"></a>Google Analytics 4, Google's tool that counts visits to a website and what visitors do there.

**Google Tag Manager.** <a id="google-tag-manager"></a>A Google tool where you add and change tracking pieces for a website without editing the site itself.

**grade.** <a id="grade"></a>A verdict on a cause: holds, weakened or refuted. A grade names its evidence. A cause without one is not allowed in the report.

**impression.** <a id="impression"></a>One time a page was shown in a search result, whether or not anyone clicked.

**key event.** <a id="key-event"></a>An event you tell GA4 counts as a goal reached, such as a completed contact form. GA4 used to call it a conversion.

**Looker Studio.** <a id="looker-studio"></a>Google's dashboard tool. It draws charts from a sheet or other data source and updates when the data does.

**marketing automation.** <a id="marketing-automation"></a>The platform that captures form fills, scores leads and passes them to the CRM.

**Python.** <a id="python"></a>A common programming language. The kit's helper scripts are written in it.

**run log.** <a id="run-log"></a>A plain file or sheet tab that records each scheduled job: when it ran, whether it worked and what it wrote. A missing line is a missed slot.

**scheduler.** <a id="scheduler"></a>The part of your computer or server that runs a command at a set time, such as every Monday at 7 a.m.

**script.** <a id="script"></a>A small program saved as a file that does one job when you run it.

**Search Console.** <a id="search-console"></a>Google Search Console, a free report of how your site appears in Google search: which searches showed it, how often and how many people clicked.

**service account.** <a id="service-account"></a>A login that belongs to a program instead of a person. You give it read permission and it can do nothing else.

**session.** <a id="session"></a>One visit to your site, from arriving to leaving or going quiet.

**single-source.** <a id="single-source"></a>A figure confirmed on only one platform. Reports label it and nobody acts on it until another independent source agrees.

**skill.** <a id="skill"></a>A folder of written instructions, and sometimes small programs, that an AI tool such as Claude follows to do one job the same way each time.

**source map.** <a id="source-map"></a>A one-page table of which platforms measure which question, and which of them share upstream data and so count as one source.

**tag.** <a id="tag"></a>In Google Tag Manager, one instruction to send a piece of information, such as "tell GA4 a download was clicked".

**token.** <a id="token"></a>A long secret code that proves a program may read your data, like a key card. Treat it like a password.
