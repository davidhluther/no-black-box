# Choose Your Version

This kit is the full team version. It assumes Claude Code, read access to your platforms, scheduled pulls and more than one person involved. There is no free or low-cost edition of it, because the point of the team kit is scale: many pages, several sources, owners and a cadence leaders can count on.

A smaller team has a good path already. The [Measure what matters kit](../measure/choose-your-version.md) has a free version built on a Google Sheet and exports, and a low-cost version that adds one AI plan and small scripts inside the sheet. The method is the same, including the second-source rule and the graded causes. If you are one person with one site, start there. The tabs and settings carry over when you move up.

| | Small-team kits | This kit |
|---|---|---|
| Who runs it | One person | A team with named owners |
| Data collection | Exports, or small scripts in a sheet | Scheduled read-only pulls with a [run log](glossary.md#run-log) |
| Sites and markets | One | Many, one settings file each |
| Source checks | [Search Console](glossary.md#search-console) plus one more | A written [source map](glossary.md#source-map) per question |
| Reporting | One report to a board or boss | A cycle that reaches leaders, with an evidence gate |
| Failure handling | You notice | A missed slot is logged and flagged the same day |
| Check-up | Help menu in the sheet, or `doctor.py measure` | `python3 support/doctor.py measurement-reporting` |

## Moving up from the small-business kit

1. Keep your sheet, tabs and headers. [Looker Studio](glossary.md#looker-studio) keeps working.
2. Copy your `config.json` into this kit and add the team fields in [MR-FU-01](setup/MR-FU-01-set-up-the-team-and-the-source-map.md).
3. Add the source map and owners, then the schedule in [MR-FU-02](setup/MR-FU-02-connect-the-data-and-schedule-the-pulls.md).

If something here does not fit your setup, send the step ID using the help box at the end of any setup guide. Setup questions are free.
