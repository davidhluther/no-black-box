# Books Kit Glossary

Every technical term used anywhere in this kit, in plain words. Terms are listed in alphabetical order, and each one links back here the first time it appears on a page.

**Access token.** A short-lived pass (about an hour) that QuickBooks gives a program so it can read your books. Think of a visitor badge that stops working the same day. <a id="access-token"></a>

**Accrual basis.** A way of keeping books that counts money when it is earned or owed, not when it moves. A bill dated in June counts in June even if you pay it in July. <a id="accrual-basis"></a>

**API.** A way for two programs to talk to each other, like a waiter carrying orders between you and the kitchen. QuickBooks has one so other programs can ask for reports. <a id="api"></a>

**Apps Script.** A small programming tool built into Google Sheets that can add menus and run checks. It is free with a Google account. <a id="apps-script"></a>

**Balance sheet.** A snapshot of what the organization owns, owes, and has left over on one date. <a id="balance-sheet"></a>

**Bank feed.** The automatic download of your bank's transactions into QuickBooks, where someone approves or matches each one. <a id="bank-feed"></a>

**Cash basis.** A way of keeping books that counts money only when it moves in or out of the bank. Compare it with accrual basis. <a id="cash-basis"></a>

**Chart of accounts.** The master list of every account in your books, such as checking, rent, or donations. <a id="chart-of-accounts"></a>

**Check-up.** A button in the kit's Google Sheet, under a Help menu, that tests whether your sheet is set up correctly and prints one support code. <a id="check-up"></a>

**Client ID.** A public label for your Intuit developer app, like a username for the app. <a id="client-id"></a>

**Client secret.** The private password that goes with a client ID. Never paste it into a chat, a shared file, or a screenshot. <a id="client-secret"></a>

**Company ID.** The number that identifies one company inside QuickBooks. Intuit shows it, labeled "Realm ID", when you sign in through the OAuth Playground. <a id="company-id"></a>

**Connector.** An add-on that lets an AI model such as Claude look inside another service, here QuickBooks, using your own sign-in. <a id="connector"></a>

**CSV.** A plain text file that holds a table, one row per line with commas between the cells. Google Sheets opens and saves them. <a id="csv"></a>

**Custom GPT.** A version of ChatGPT you set up once with standing instructions and files, so you do not repeat them in every chat. <a id="custom-gpt"></a>

**Developer app.** A free entry you create on Intuit's developer website. It stands for your own small program and gives you the keys that program needs to sign in to your books. <a id="developer-app"></a>

**Environment variable.** A named setting stored on your computer outside any file you share, like a sticky note only your programs can read. This kit uses them to hold your keys. <a id="environment-variable"></a>

**General ledger.** The full list of every entry in the books, grouped by account, in date order. It is the most complete report QuickBooks makes. <a id="general-ledger"></a>

**GET request.** A message to a service that says "show me this" and nothing more. It cannot add, edit, or delete anything. <a id="get-request"></a>

**Journal entry.** A hand-made entry that moves money between accounts in the books without any invoice, bill, or bank transaction behind it. <a id="journal-entry"></a>

**JSON.** A plain text format programs use to hand data to each other. The full version's script saves reports as JSON and can turn them into CSV. <a id="json"></a>

**Knowledge file.** A document you upload to a Custom GPT or an AI Project so the model can read it in every chat. <a id="knowledge-file"></a>

**OAuth Playground.** Intuit's own web page for signing in to your books once and getting the keys a program needs. It runs on Intuit's site, so your password never goes to any other program. <a id="oauth-playground"></a>

**Opening Balance Equity.** A holding account QuickBooks creates when an account is first set up with a starting balance. It should end up near zero once the books are cleaned up. <a id="opening-balance-equity"></a>

**Plugin.** The ChatGPT name for an add-on that connects it to another service. It does the same job as a connector. <a id="plugin"></a>

**Production keys.** The client ID and client secret that work on your real company file, as opposed to a practice company. <a id="production-keys"></a>

**Profit and loss report.** A report of income and expenses over a stretch of time, also called a P&L or an income statement. <a id="profit-and-loss-report"></a>

**Prompt.** The message you type or paste to an AI model. <a id="prompt"></a>

**Python.** A common programming language. The full version's script is written in it and needs it installed on your computer. <a id="python"></a>

**Read-only.** Able to look but not touch. A read-only tool can show you your books and cannot add, change, send, or delete anything in them. <a id="read-only"></a>

**Reconciliation.** The monthly job of matching every line on the bank statement to the books and marking each match, so you know which balance is right. <a id="reconciliation"></a>

**Redirect URI.** The web address Intuit sends you back to after you approve a sign-in. For this kit it is an address on Intuit's own site. <a id="redirect-uri"></a>

**Refresh token.** A longer-lived pass that lets a program get a new access token without you signing in again. Intuit swaps it for a new one every time it is used, so the script saves the newest copy. <a id="refresh-token"></a>

**Register.** The line-by-line list of everything that went through one account, with a running balance, like a checkbook. <a id="register"></a>

**Restricted funds.** Money a donor or grant says can be spent only on a named purpose. It sits inside your bank balance but is not free to spend. <a id="restricted-funds"></a>

**Runway.** How many months the organization can keep operating at its current pace before the cash runs out. <a id="runway"></a>

**Sandbox.** A practice company with made-up data that Intuit gives developers, so mistakes touch nothing real. <a id="sandbox"></a>

**Scope.** The kind of access a sign-in asks for. This kit asks only for the accounting scope, and its script only uses it to read. <a id="scope"></a>

**Script.** A small program saved as a text file. <a id="script"></a>

**Support code.** A short code like BK-FR-03-2-E14-v0.1.0-7KQ that tells a helper which step failed, what went wrong, and which kit version you have. It holds none of your data. <a id="support-code"></a>

**Tab.** One page inside a Google Sheet, shown as a label along the bottom. <a id="tab"></a>

**Terminal.** A window where you type short text commands instead of clicking. On a Mac it is the Terminal app, and on Windows it is PowerShell. <a id="terminal"></a>

**Undeposited Funds.** A QuickBooks holding account for payments received but not yet matched to a bank deposit. <a id="undeposited-funds"></a>

**Variance.** The gap between what was budgeted and what actually happened. <a id="variance"></a>
