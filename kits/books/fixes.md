# Fixes

Find the code on your screen or in your [support code](glossary.md#support-code), then follow the fix. Every guide step points here with "it's E__". All dollar figures in this kit are invented examples.

If a fix does not work, send the step ID and your support code to Pigasus Group at https://pigasus.group/contact. Setup questions are free.

| Code | What you see | Why | The fix | Step |
|---|---|---|---|---|
| E01 | You can't find an Export button on a QuickBooks report | QuickBooks moves buttons between versions, or you are on a screen that is not a report | Open Reports from the left menu, run the report, then look near the top right for a small icon or the word Export. If there is none, use the printer icon, save as PDF, and paste the text into your AI model | BK-FR-01-4 |
| E02 | Amounts show as text with a dollar sign, or a total shows zero | Google Sheets imported the amounts as text because of the symbols or your locale | Select the amount cells, click Format, then Number, then Number. If that fails, use Find and replace to delete the dollar sign and commas | BK-FR-01-5 |
| E03 | Red errors such as #REF!, #NAME?, or #VALUE! in the cash and [runway](glossary.md#runway) sheet | A [tab](glossary.md#tab) was renamed, a formula was typed over, or a formula arrived as text | Check the seven tab names (E04), then retype the formula from `free/cash-runway-formulas.md` | BK-FR-02-4 |
| E04 | The [check-up](glossary.md#check-up) says a tab is missing | A tab name differs, for example ".[csv](glossary.md#csv)" on the end or a different capital letter | Double-click the tab name at the bottom and type it exactly as listed in `free/cash-runway-formulas.md` | BK-FR-02-1 |
| E05 | A Google page won't load, you are stuck in a sign-in loop, or the Help menu does not appear | A browser cache problem, several Google accounts signed in at once, or the [script](glossary.md#script) has not been authorized | Open a private browser window, sign in to one Google account only, reload the sheet, and wait ten seconds. If the Help menu is still missing, repeat BK-FR-03-3 | BK-FR-01-1, BK-FR-03-4 |
| E06 | Google warns "hasn't verified this app", or the run fails after you decline permission | Every personal [Apps Script](glossary.md#apps-script) shows this warning, because Google has not reviewed it | Click Advanced, then Go to the project name, then Allow. The code is short and only reads the sheet. If you do not want to allow it, skip the check-up and send your step ID instead | BK-FR-03-3 |
| E07 | The check-up says a Settings value is empty | One of the six cells in column B of the Settings tab is blank | Fill in Settings rows 2 to 7 (see `free/cash-runway-formulas.md`) | BK-FR-02-3 |
| E08 | The check-up says a header row is different | A header was edited, or a column was deleted or moved | Compare row 1 with the list in `free/cash-runway-formulas.md` and retype it | BK-FR-02-2 |
| E09 | The AI model quotes a number that is not in your report | AI models guess when asked a question they cannot answer from what you gave them | Ask: "Quote the row you got that from." If it cannot, discard the number. Start the chat again with the standing instruction in `free/prompts.md` | BK-FR-03-6 |
| E10 | The AI model says the report is too long or cannot read the file | Free plans limit how much you can paste | Paste only the section you need, such as the cash accounts, or export the report for a shorter date range | BK-FR-03-6 |
| E11 | QuickBooks is not in Claude's list of [connectors](glossary.md#connector) | The connector is not offered on your plan or region yet, or the list has not refreshed | Reload the page, check Intuit's announcement for current availability, and confirm your plan at https://claude.com/pricing | BK-LC-01-3 |
| E12 | The connector shows a different company than you expected | You signed in to QuickBooks with a login that manages several companies and the wrong one was chosen | Disconnect the connector, connect again, and pick the right company on the screen that follows | BK-LC-01-3, BK-LC-02-3 |
| E13 | You can't find the QuickBooks [plugin](glossary.md#plugin) in ChatGPT | It may not be offered on your plan, or the menu is named something else on your version | Search Apps, Plugins, and Connectors for "Intuit QuickBooks". Check your plan at https://chatgpt.com/pricing. Use the free version meanwhile | BK-LC-02-2 |
| E14 | The AI model offers to create, send, or delete something in QuickBooks, or a box asks you to approve it | The connector or plugin includes tools that change things. This kit never uses them | Click Deny every time. Say: "Do not use any tool that changes anything." Block those tools in the connector settings if you can (BK-LC-01-6). If something was changed, open QuickBooks, check the Audit log, and tell your bookkeeper the same day | BK-LC-01-5, BK-LC-02-5 |
| E15 | The connector's profit and loss does not match your QuickBooks report | The connector reports on a different basis (in one version, cash only), so figures differ from an accrual report | Run the same report in QuickBooks on both bases and see which one the connector matches. Never mix reports on different bases | BK-LC-01-7, BK-LC-02-6, BK-LC-03-3 |
| E16 | QuickBooks says you do not have permission | Your QuickBooks user role cannot see reports or approve connections | Ask the QuickBooks administrator to give you a role with report access | BK-LC-01-1, BK-LC-02-1 |
| E17 | The answer disagrees with the QuickBooks screen | The date range or basis is not what you assumed | Type exact dates and the basis in every question, then compare again | BK-LC-03-1, BK-LC-03-2 |
| E21 | You can't sign up at the Intuit developer site | The email is already used for a different Intuit product, or the sign-up asks for a company check | Sign in with your existing Intuit login instead of creating a new one. If it still fails, ask us | BK-FU-01-1 |
| E22 | [Production keys](glossary.md#production-keys) stay locked, or Intuit asks for details you do not have | Intuit reviews apps before it allows production keys, and asks for web addresses and questionnaire answers | Complete every field that applies, keep answers honest, and ask for help rather than inventing web addresses. Practice with the [sandbox](glossary.md#sandbox) meanwhile | BK-FU-02-2 |
| E23 | The [OAuth Playground](glossary.md#oauth-playground) says the redirect address does not match | The address on your app's [Redirect URIs](glossary.md#redirect-uri) list differs from the one the Playground shows | Copy the address from the Playground page, paste it exactly into your app's Redirect URIs for the same tab (Development or Production), and save | BK-FU-02-4 |
| E24 | The Playground does not offer your company | You are signed in as a user who cannot see it, or you used Development keys with a real company | Sign in as the administrator, and use Production keys for a real company | BK-FU-02-6 |
| E31 | The script says a setting is missing | An [environment variable](glossary.md#environment-variable) is not set in this [terminal](glossary.md#terminal) window | Run the `source` line again from BK-FU-03-3, and check the five names are spelled exactly | BK-FU-03-3 |
| E32 | Intuit refused the sign-in (HTTP 401 or invalid_grant) | The [refresh token](glossary.md#refresh-token) is old, was pasted wrong, or a newer one was issued elsewhere | Get a fresh refresh token from the Playground (BK-FU-02-6 and 7), update QBO_REFRESH_TOKEN, and run again | BK-FU-03-6 |
| E33 | "Could not save the newest token" | The script cannot write to the settings folder | Make sure the folder `.config/books-check` in your home folder exists and is yours, or set QBO_TOKEN_FILE to another path you own | BK-FU-03-7 |
| E34 | HTTP 403 from QuickBooks | The login that authorized the app cannot see that company, or you mixed sandbox and production | Check QBO_ENV, the [company ID](glossary.md#company-id), and which keys you used | BK-FU-03-6 |
| E35 | "command not found" for python3, or a version below 3.9 | [Python](glossary.md#python) is not installed or is old | Install Python from https://www.python.org/downloads/ and open a new terminal. On Windows type python instead of python3 | BK-FU-03-1 |
| E36 | HTTP 429, too many requests | Too many pulls in a short time | Wait a few minutes. For bracket, lower --max-calls | BK-FU-04-3 |
| E37 | The self-test says SELFTEST FAILED | The script file was edited or damaged | Delete it and download a fresh copy. Do not run any other command until the self-test passes | BK-FU-03-5 |
| E38 | A report comes back empty or has no rows | The date range has no entries, or the report name is misspelled | Widen the dates and check the spelling against the list printed by the script when you mistype a name | BK-FR-01-3, BK-FU-04-1 |
| E39 | Two pulls that should agree don't, or bracket totals look odd | The two pulls used different dates or a different basis | Pull both again with the same --start, --end, and --method | BK-FR-01-7, BK-FU-04-3 |
| E40 | "No such file or directory" | The terminal is in a different folder from the script | Run the `cd` line from BK-FU-03-4, then check the file is there with `ls` (or `dir` on Windows) | BK-FU-03-2 |
| E00 | The check-up code ends E00 before the version | Every check passed | Nothing to fix | BK-FR-03-5 |
