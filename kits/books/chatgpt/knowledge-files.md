# Knowledge Files for the Custom GPT

Upload these files from this kit as [knowledge files](../glossary.md#knowledge-file) (documents a [Custom GPT](../glossary.md#custom-gpt) or ChatGPT Project can read in every chat). OpenAI's limit is 20 files per Custom GPT, and this list is 11. Each file is a plain text or Markdown file.

| Upload | Why |
|---|---|
| `free/prompts.md` | The questions pack the GPT uses and the standing instruction |
| `free/cash-runway-formulas.md` | The sheet layout, so it can help fix formulas |
| `free/monthly-routine-checklist.md` | The monthly [read-only](../glossary.md#read-only) routine |
| `free/treasurer-report-template.md` | The monthly report to fill in |
| `free/meeting-prep-memo-template.md` | The board prep memo |
| `free/controls-review-prompts.md` | The policy review questions |
| `fixes.md` | Lets it look up an E-code |
| `glossary.md` | Plain definitions of every term |
| `setup/BK-FR-01-export-reports-to-sheets.md` | The export steps |
| `setup/BK-LC-03-safe-habits-and-connector-traps.md` | The [connector](../glossary.md#connector) traps |
| `setup/BK-FU-04-run-the-recipes.md` | The cash check and bracketing recipes |

Do not upload `free/checkup.gs` (the GPT cannot run it), any real report, or `config.json` with real details.

If you use a ChatGPT Project instead of a Custom GPT, add the same files to the Project and paste the instructions into the Project's instructions.
