# Glossary

Every technical term used in this kit, in plain words. Each page of the kit links a term to this page the first time it appears.

<a id="ahrefs"></a>
**Ahrefs.** A paid website that records which sites link to which. It is the usual source for comparing your links with a competitor's. Its free tool for site owners shows only your own site.

<a id="ai-model"></a>
**AI model.** The program behind a chat tool such as ChatGPT, Claude, or Gemini. You type a request, and it writes a reply.

<a id="anchor-text"></a>
**Anchor text.** The clickable words of a link. A link that says "emergency plumber in Springfield" has that phrase as its anchor text.

<a id="api"></a>
**API.** A way for two programs to talk to each other, like a waiter carrying orders between you and the kitchen.

<a id="api-key"></a>
**API key.** A long password-like string that tells a service which account is asking, like a library card number. Keep it private.

<a id="apps-script"></a>
**Apps Script.** The free tool built into Google Sheets that lets you add small programs and custom menus to a sheet.

<a id="backlink"></a>
**Backlink.** A link from another website to yours. Search engines count backlinks a bit like votes of confidence.

<a id="baseline"></a>
**Baseline.** The starting set of basics a business should have in place. Also used for the saved snapshot of numbers that the checks share.

<a id="bing-webmaster-tools"></a>
**Bing Webmaster Tools.** Microsoft's free report for site owners, the Bing counterpart of Google Search Console. It shows how your site appears in Bing and the search results of tools that use Bing.

<a id="cannibalization"></a>
**Cannibalization.** When two pages on one site compete for the same search, so neither wins cleanly. The casual term for a site competing with itself.

<a id="canonical"></a>
**Canonical.** The one web address a page says is its official home, used when the same content appears at more than one address.

<a id="chrome-ux-report"></a>
**Chrome UX Report.** Google's collection of speed measurements from real people using Chrome, often shortened to CrUX. It is the source of the real-world numbers in PageSpeed Insights.

<a id="citation"></a>
**Citation.** Any place on the web that lists your business's name, address, and phone number, such as a directory or map listing.

<a id="claude-code"></a>
**Claude Code.** A program from Anthropic that runs the Claude AI model on your own computer and can read and write files there. Used in the full version of this kit.

<a id="cls"></a>
**CLS.** Cumulative Layout Shift. How much a page jumps around while it loads. Lower is better, and 0.1 or less is good.

<a id="command-line"></a>
**Command line.** A window where you type instructions to your computer instead of clicking. Only the full version uses it, and the guides show every line to type.

<a id="common-crawl"></a>
**Common Crawl.** A nonprofit that copies much of the public web into a free archive. Many AI models learn from archives like it.

<a id="config-file"></a>
**Config file.** A small settings file holding the details that are particular to your business, such as your name and web address.

<a id="core-web-vitals"></a>
**Core Web Vitals.** Google's three measures of how a page feels to use. Loading (LCP), responsiveness (INP), and visual stability (CLS).

<a id="crawl"></a>
**Crawl.** A robot visiting every page of a site and noting what it finds, the way a search engine does.

<a id="csv"></a>
**CSV.** A plain table saved as text, with commas between the columns. Spreadsheets open and save it.

<a id="custom-gpt"></a>
**Custom GPT.** A version of ChatGPT that you set up once with your own instructions and files, so it starts every chat already knowing them.

<a id="dns"></a>
**DNS.** The internet's address book. It tells browsers which computer holds your website and where your email goes.

<a id="domain"></a>
**Domain.** Your web address, such as example.org, without the page names after it.

<a id="domain-rating"></a>
**Domain Rating.** A zero to 100 score Ahrefs gives a website for the strength of the sites linking to it. It is Ahrefs' own measure, not Google's.

<a id="favicon"></a>
**Favicon.** The tiny icon shown in the browser tab next to your page title.

<a id="field-data"></a>
**Field data.** Speed measurements taken from real visitors. Google uses these. A page without enough visitors has none.

<a id="google-business-profile"></a>
**Google Business Profile.** Your free business listing on Google Search and Google Maps, with your hours, address, photos, and reviews.

<a id="google-sheet"></a>
**Google Sheet.** Google's free online spreadsheet.

<a id="h1"></a>
**H1.** The main heading at the top of a page, the biggest line of text on it.

<a id="https"></a>
**HTTPS.** The secure version of a web address. The padlock beside the address in the browser shows it.

<a id="indexed"></a>
**Indexed.** Saved in Google's catalog of pages. A page that isn't indexed can't appear in search results.

<a id="inp"></a>
**INP.** Interaction to Next Paint. How long a page takes to respond after someone taps or clicks. 200 milliseconds or less is good.

<a id="json"></a>
**JSON.** A tidy way of writing information as labeled items, readable by people and programs. Think of a form with the blanks filled in.

<a id="json-ld"></a>
**JSON-LD.** The JSON format used to put structured data into a web page.

<a id="lab-data"></a>
**Lab data.** Speed measurements from a simulated test on a deliberately slow phone and network. Good for finding causes, less good for judging how bad a problem is.

<a id="lcp"></a>
**LCP.** Largest Contentful Paint. How long until the main part of the page is visible. 2.5 seconds or less is good.

<a id="llms-txt"></a>
**llms.txt.** A plain-text file some sites place at their root to summarize themselves for AI tools. It's new, and its value is not proven.

<a id="map-pack"></a>
**Map pack.** The short list of three businesses with a map that Google shows above regular results for local searches.

<a id="meta-description"></a>
**Meta description.** The short summary of a page that search engines may show under its title.

<a id="nap"></a>
**NAP.** Name, address, and phone number. The three details that must match everywhere your business is listed.

<a id="noindex"></a>
**Noindex.** A note on a page asking search engines not to list it.

<a id="orphan-page"></a>
**Orphan page.** A page that no other page on your site links to, so visitors and search engines struggle to find it.

<a id="outside-in"></a>
**Outside-in.** Checking a business from the position of a stranger, using only what anyone can see, with no logins to its accounts.

<a id="pagespeed-insights"></a>
**PageSpeed Insights.** Google's free page-speed test at pagespeed.web.dev. It shows both real-visitor and simulated results.

<a id="plugin"></a>
**Plugin.** An add-on package for a program. In Claude Code, this kit installs as a plugin.

<a id="project"></a>
**Project.** A saved workspace in ChatGPT or Claude where you store instructions and files, so each new chat in it starts with them already loaded.

<a id="prompt"></a>
**Prompt.** The instruction you type or paste to an AI model.

<a id="python"></a>
**Python.** A programming language. The full version uses small Python programs that come with the kit.

<a id="redirect"></a>
**Redirect.** An automatic forward from one web address to another. A 301 redirect says the move is permanent.

<a id="referring-domain"></a>
**Referring domain.** One website that links to yours. Ten links from the same site count as one referring domain.

<a id="rich-results"></a>
**Rich results.** Search results that show extra details such as star ratings or question lists, made possible by structured data.

<a id="robots-txt"></a>
**robots.txt.** A plain file at the root of your site that tells crawlers which parts they may visit.

<a id="scorecard"></a>
**Scorecard.** The table of checks and results that this kit produces for your site.

<a id="screaming-frog"></a>
**Screaming Frog.** A desktop program that crawls a website and lists every page and problem. Its free version crawls up to 500 addresses.

<a id="search-console"></a>
**Search Console.** Google's free report for site owners. It shows which searches show your pages, how many clicks they get, and which pages Google has saved.

<a id="seo"></a>
**SEO.** Search engine optimization. Making a website easier for search engines and people to find and understand.

<a id="service-area-business"></a>
**Service area business.** A business that goes to its customers instead of receiving them, such as a plumber. Google lets it hide its address and list areas served.

<a id="sitemap"></a>
**Sitemap.** A list of your site's pages, usually at your-site/sitemap.xml, that helps search engines find them.

<a id="skill"></a>
**Skill.** A saved set of instructions, sometimes with small programs, that an AI model follows to do one job the same way each time.

<a id="spf-dkim-and-dmarc"></a>
**SPF, DKIM, and DMARC.** Three settings in your web address's records that prove email from your domain is really yours. Without them, mail often lands in spam.

<a id="structured-data"></a>
**Structured data.** Labeled facts hidden in a page for computers to read, such as the business name, address, and opening hours. Also called schema markup.

<a id="support-code"></a>
**Support code.** A short code that the check-up prints. It tells whoever helps you which step failed, which problem it was, and which version you have.

<a id="terminal"></a>
**Terminal.** The program that gives you a command line on your computer.

<a id="title-tag"></a>
**Title tag.** The page title shown in the browser tab and as the blue headline in search results.

<a id="trigger"></a>
**Trigger.** A setting that makes a Google Sheet script run by itself on a schedule, such as the first of each month.

<a id="web-manifest"></a>
**Web manifest.** A small file that tells phones how to show your site if someone saves it to their home screen.
