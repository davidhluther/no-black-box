# Shopping List

Most of what you need is free, and you may already have it. For each item, this page says what it is, why the kit uses it, what it costs, a cheaper or free alternative, whether you can skip it, and where you have room to choose. Every account or key mentioned here is explained step by step in [Keys and accounts](../../guides/keys-and-accounts.md).

Prices change. Where a price is written below, it was checked on the date shown, on the vendor's own page. Where it says "see the current price", look at the page named before you decide.

## Free version

### A Google account

- **What it is.** The sign-in you use for Gmail, Google Docs, and [Google Sheets](glossary.md#google-sheet). A work or nonprofit Workspace account works too.
- **Why you need it.** It holds your [Google Sheet](glossary.md#google-sheet), your [Search Console](glossary.md#search-console) report, and your [Google Business Profile](glossary.md#google-business-profile). See [Keys and accounts](../../guides/keys-and-accounts.md) if you have to make one.
- **Cost.** A personal account has no charge. See Google's page for current terms.
- **Skip it?** No.
- **Room to choose.** Use the same account that owns your business listing, so one login can see everything. Avoid an employee's personal account, because if that person leaves you lose access.

### Search Console

- **What it is.** Google's free report for site owners.
- **Why.** It is the only source that shows which searches reach your site and whether Google has saved your pages.
- **Cost.** See Google's page at search.google.com/search-console for current terms.
- **Skip it?** You can run the [scorecard](glossary.md#scorecard) without it. Search visibility checks V1 to V4 then show "unknown". It's worth the 15 minutes.
- **Room to choose.** Add the whole [domain](glossary.md#domain) if you can edit your address records (the [DNS](glossary.md#dns)). Add just the page address otherwise.

### Bing Webmaster Tools

- **What it is.** Microsoft's version of Search Console. See [Bing Webmaster Tools](glossary.md#bing-webmaster-tools).
- **Why.** It reports on Bing and on tools built on Bing. It can import your Search Console setup in one step.
- **Cost.** See the current terms at bing.com/webmasters.
- **Skip it?** Yes, if you are short on time. Mark check V2 unknown.
- **Room to choose.** None needed.

### PageSpeed Insights

- **What it is.** Google's page-speed test at pagespeed.web.dev. It shows real-visitor numbers from the [Chrome UX Report](glossary.md#chrome-ux-report) and a simulated test.
- **Why.** Speed is one of the scorecard sections.
- **Cost.** The website needs no account. See the page for current use limits.
- **Skip it?** No. It's the easiest check in the kit.

### A free AI chat

- **What it is.** ChatGPT, Claude, or Gemini, in the free tier, to read your results and draft fixes.
- **Why.** The [prompts](glossary.md#prompt) in `free/prompts.md` need an [AI model](glossary.md#ai-model) to read and explain.
- **Cost.** Free tiers exist at each. See each vendor's page for current limits, because they change often. See [Keys and accounts](../../guides/keys-and-accounts.md) for sign-up steps.
- **Skip it?** You could do every check by hand with the checklists, but it takes much longer.
- **Room to choose.** Any of the three works. If one runs out of free messages, switch to another.

## Low-cost version (adds)

### One AI plan with Projects

- **What it is.** A paid plan at ChatGPT or Claude that includes [Projects](glossary.md#project), where you load files and instructions once.
- **Why.** Each new chat starts already knowing the kit's method, so you paste less.
- **Cost.** See the current price on the vendor's plan page, since it changes.
- **Free alternative.** Stay on the free chat and paste the prompts.
- **Skip it?** Yes. It saves time, nothing more.
- **Room to choose.** Pick the one you already use.

### A PageSpeed key, optional

- **What it is.** A free [API key](glossary.md#api-key) from Google, so the monthly speed pull isn't rate-limited. See [Keys and accounts](../../guides/keys-and-accounts.md) for where to get one and how to keep it private.
- **Cost.** See Google's page for current terms.
- **Skip it?** The pull may work without it for a few pages. The check-up button tells you if it doesn't.

## Full version (adds)

### Claude Code

- **What it is.** [Claude Code](glossary.md#claude-code), a program that runs the Claude AI model on your own computer.
- **Why.** It runs the scripts, saves reports, and reads your settings file. See [Keys and accounts](../../guides/keys-and-accounts.md) and the [install guide](../../guides/install-claude.md).
- **Cost.** It needs a paid Claude plan or [API](glossary.md#api) credit. See the current price at anthropic.com.
- **Skip it?** Yes. The free and low-cost versions do the main job.

### Python 3

- **What it is.** The programming language the two scripts are written in. See [Python](glossary.md#python).
- **Cost.** No charge.
- **Skip it?** Only if you skip the two scripts.

### Screaming Frog SEO Spider

- **What it is.** A desktop crawler. See [Screaming Frog](glossary.md#screaming-frog).
- **Why.** The technical audit and the internal-links audit use its export.
- **Cost.** The free version [crawls](glossary.md#crawl) up to 500 addresses. The paid license was 245 euros a year for one to four licenses (checked 11/13/2026 at screamingfrog.co.uk/seo-spider/pricing).
- **Free alternative.** The Search Console Pages report and prompt 8.
- **Skip it?** Yes. Most small sites fit under 500 addresses, so you likely never need the paid version.

### Ahrefs, optional

- **What it is.** A paid link database. See [Ahrefs](glossary.md#ahrefs).
- **Why.** Only the competitor comparison in the `backlink-gap` [skill](glossary.md#skill) needs it.
- **Cost.** See the current plans at ahrefs.com/pricing. See [Keys and accounts](../../guides/keys-and-accounts.md) for how to connect it.
- **Free alternative.** Search Console's Links report and Bing's inbound links show your own links. Ahrefs offers a free tool for verified site owners, with terms on its own site.
- **Skip it?** Yes. Most local businesses do better spending an hour finding local sites that should mention them.

## The real cost

Time. Plan an afternoon for the first run and 15 minutes a month after that. If you find yourself paying for something not on this list, stop and check whether you need it.
