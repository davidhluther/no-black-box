# WC-LC-01: Load the Kit Into a Project

You will set up a saved workspace in ChatGPT or Claude (a [Project](../glossary.md#project)) that already knows the kit's method, so you paste less. About 20 minutes. You need the free version finished first, and one AI plan that includes Projects.

If you get stuck, the check-up button in your sheet prints a [support code](../glossary.md#support-code), a short code that tells a helper which step failed. The box at the bottom says where to send it.

1. **WC-LC-01-1.** Choose where you'll work, ChatGPT or Claude, and sign in. Use the one you already pay for. See [Keys and accounts](../../../guides/keys-and-accounts.md) for sign-up steps and the current plans page.
   You'll know it worked when you see a "Projects" item in the left menu. If you don't, your plan may not include them, and it's E11.

2. **WC-LC-01-2.** Make a new Project and call it "Website check-up".
   You'll know it worked when an empty project page opens with a place for instructions and a place for files.

3. **WC-LC-01-3.** Open `chatgpt/instructions.md` from the kit, copy all of it, and paste it into the Project's instructions box.
   You'll know it worked when the instructions box shows the text and saves. If the box refuses it as too long, you copied the notes at the top by mistake, and it's E11.

4. **WC-LC-01-4.** Open `chatgpt/knowledge-files.md`. Upload each file it lists into the Project's files area.
   You'll know it worked when each file shows in the list without an error. If an upload fails, check that the file isn't empty, and see E11.

5. **WC-LC-01-5.** Start a chat in the Project and type: "Run the quick [scorecard](../glossary.md#scorecard) for my business." Then answer its questions about your business, or paste the contents of your Config tab.
   You'll know it worked when it asks for your business name, site, and competitors, and later gives a table of results with a list titled "What this check could not see". If it invents a number you didn't give it, it's E12.

6. **WC-LC-01-6.** In your sheet, open the Config tab and change the `version` value from FR to LC.
   You'll know it worked when the value reads LC. The check-up button now also tests for the monthly speed key from [WC-LC-02](WC-LC-02-monthly-speed-pulls.md).

> **How to get help.** Write down the step ID where you got stuck (it looks like WC-LC-01-3). If your kit has a check-up button or command, run it and copy the support code it prints. Then send both to Pigasus Group at [https](../glossary.md#https)://pigasus.group/contact. Setup questions are free.
