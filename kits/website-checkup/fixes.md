# Fixes

Find the code the check-up or a guide gave you, read what you see, and follow the fix. If a fix doesn't work, send the code and the step ID to Pigasus Group at [https](glossary.md#https)://pigasus.group/contact. Setup questions are free.

| Code | What you see | Why it happens | The fix | Step |
|---|---|---|---|---|
| E01 | You keep landing on the Google sign-in page, or Google asks for a code that never arrives | Two accounts are signed in at once, or the browser blocks cookies, or a work account has sign-in rules | Open a private (incognito) window and sign in there. Pick one account and sign out of the others. If a code is the problem, choose "Try another way" | WC-FR-01-1 |
| E02 | [Search Console](glossary.md#search-console) says "No data available", or the [sitemap](glossary.md#sitemap) says "Couldn't fetch" | A new property takes a few days to collect data. A sitemap error is often a typo in its address, or the site has no sitemap | Wait three to seven days. Open your-site/sitemap.xml in a browser. If it doesn't open, ask your web person to turn on a sitemap, or try `sitemap_index.xml` | WC-FR-01-4, WC-FR-01-7, WC-FR-03-5 |
| E03 | "Ownership not verified", or the address is rejected | The proof isn't in the right place yet, or you typed the address differently from the site's real address | Copy the address from your browser's address bar. Check whether your site starts with https and whether it uses www. Try the "HTML tag" method and wait ten minutes. Ask your web person for help with the proof | WC-FR-01-2, WC-FR-01-3 |
| E04 | Bing's import button is greyed out or fails | The Google and Microsoft accounts aren't linked, or the Google site isn't verified yet | Verify the site in Search Console first. Then retry the import and allow access when asked. If it still fails, add the site by hand and use Bing's own proof options | WC-FR-01-5 |
| E05 | [PageSpeed Insights](glossary.md#pagespeed-insights) says there isn't enough real-world data | Too few Chrome visitors to measure | This is normal for small sites. Use the simulated (lab) score, mark checks S2 to S4 Unknown, and test again in a month | WC-FR-03-1 |
| E06 | PageSpeed Insights can't load the page or shows an error | The address is wrong, the page [redirects](glossary.md#redirect), or the site blocked the test | Open the address in your own browser first. Use the final address after any redirect. Try again in a few minutes. If it still fails, mark the check Unknown. A failed test is not a finding | WC-FR-03-1 |
| E07 | The check-up says a tab is missing or a heading differs from the template | A tab name is misspelled, a heading was edited, or a tab holds the wrong file | Rename the tab to match exactly, with capital letters. Re-import the matching `-tab.csv` file with "Replace current sheet". The check-up tells you the column number that differs | WC-FR-02-2, WC-FR-02-3 |
| E08 | The check-up says a Config setting is empty | A required setting is blank | Fill in business_name, site_url, business_type, and city_region in the Value column of the Config tab | WC-FR-02-4 |
| E09 | Google says "This app isn't verified" or "Authorization required" and won't let you continue | Every script you write yourself shows this warning | Click "Advanced", then "Go to Website check-up (unsafe)", then Allow. The script only touches this sheet. If "Advanced" isn't offered, your organization's settings block scripts. Ask the person who runs your Google account | WC-FR-02-6, WC-LC-02-5 |
| E10 | The Help menu never appears, or the editor shows a red error | The script wasn't saved, only part of it was pasted, or the sheet wasn't reloaded | Reopen Extensions, [Apps Script](glossary.md#apps-script). Paste the whole `checkup.gs` file over everything else and save. Reload the sheet and wait ten seconds | WC-FR-02-5, WC-FR-02-6, WC-LC-02-3 |
| E11 | The [AI model](glossary.md#ai-model) says it can't open web pages, or [Projects](glossary.md#project) aren't available, or a file won't upload, or the instructions are too long | Free chats often can't browse. Some plans don't include Projects. The instructions file has notes above the instructions | Open the page yourself and paste the text. Check your plan page for Projects. Paste only the instructions, from the line that starts the instructions to the end | WC-FR-03-4, WC-LC-01-1, WC-LC-01-3, WC-LC-01-4 |
| E12 | The AI model gives numbers or facts you didn't supply, or a score with no source | AI models fill gaps with plausible-sounding guesses | Discard that answer. Rerun the [prompt](glossary.md#prompt), and add: "Mark anything you could not check as unknown. Do not invent numbers." Check each number against the page it came from | WC-FR-03-4, WC-LC-01-5, WC-FU-01-6 |
| E13 | You can't find your business on Google Maps | The listing doesn't exist yet, is hidden because it's a service-area business, or is under another name | Search your phone number and your address. | E14 | The Summary tab shows `#REF!`, `#DIV/0!`, or similar | A tab was renamed after the formulas were made, or no checks in that section have results yet | Check that the [Scorecard](glossary.md#scorecard) tab is named exactly Scorecard. Re-import the summary file. Fill in the Result column for the section | WC-FR-02-3, WC-FR-03-7 |
| E15 | The [crawl](glossary.md#crawl) export looks scrambled, or the script can't read it | It was re-saved from a spreadsheet, or a title containing a pipe character split the columns | Use the original export from the crawler, untouched | WC-FU-02-1, WC-FU-02-2 |
| E16 | The [terminal](glossary.md#terminal) says "command not found" | [Claude Code](glossary.md#claude-code) or [Python](glossary.md#python) isn't installed, or the terminal was open before you installed it | Close the terminal window and open a new one. Follow the install guide again | WC-FU-01-1, WC-FU-01-2 |
| E17 | Claude Code can't find the marketplace or the [plugin](glossary.md#plugin), or `config.json` won't load | A typo in the address, or a missing quote or comma in the file | Copy the address from the GitHub page. Open `config.json`, check that every value sits in straight quotes and every line but the last ends with a comma | WC-FU-01-3, WC-FU-01-4 |
| E18 | The check-up says no speed key is saved, or the speed pull says HTTP 429 or 403 | The key wasn't saved under the exact name, the key was typed wrongly, or the free allowance ran out for the moment | Save it again under the name `PAGESPEED_API_KEY` in Script Properties. Check the key in the keys guide. Wait an hour for limits to reset. Never paste the key into a cell | WC-LC-02-1, WC-LC-02-2, WC-LC-02-5 |
| E19 | The schema validator or [Rich Results](glossary.md#rich-results) Test reports errors in your markup | A missing required field, a placeholder left in, or a trailing comma | Replace each `TODO_` placeholder with a real value. Check the commas and quotes. Test again at validator.schema.org | WC-FR-03-4 |
| E20 | The [Common Crawl](glossary.md#common-crawl) check shows timeouts or server errors | Common Crawl's index server is busy | Wait an hour and rerun. One failed run says nothing about your site | WC-FU-02-3 |
| E21 | The check-up says the site address isn't in the right shape | The address is missing https://, has spaces, or is only a name | Write the address as `https://www.example.org`, matching what your browser shows | WC-FR-02-4 |
| E22 | A Points cell stays blank, or the check-up says a Result cell holds another word | The Result column accepts only Pass, Partial, Fail, or Unknown | Retype the result using one of those four words, with a capital first letter | WC-FR-03-3, WC-FR-03-7 |

## Reading a support code

A code such as `WC-FR-02-3-E07-v0.1.0-7KQ` means: this kit (WC), the free version (FR), setup guide 02, step 3, problem E07, kit version 0.1.0, and a three-character check value. `WC-FR-00-0-E00-v0.1.0-XXX` means the check-up found nothing wrong.
